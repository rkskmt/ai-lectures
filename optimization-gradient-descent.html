scikitの設計

fit() で学習を完了させる

fit() はモデルのパラメータを決める

  • fit() の仕事：データから、モデル内部のパラメータを決めること
  • 多くのモデルでは、評価基準が最も良くなるパラメータを探す最適化として表せる

学習とはパラメータという数字を決めること

  • 損失（loss）：ダメさを測る物差し。低いほど良い。
  • パラメータ：モデル（深さ2の決定木とか3-meansとか）の学習中に更新されていく値。学習が終われば固定
  • 損失関数（loss function）：パラメータを入力したらlossを返す関数
  • 最適化(optimization)：lossを最小化する良い感じのパラメータを決める行為。最適や最小化とはいっているが、本当に最も適した最もよい値ではなく、それっぽい値でも最適化と呼ぶ
  • 学習：データからパラメータを決めること。多くのモデルでは最適化によって実現される

損失関数を図で見る

  • 以下は、サケとスズキの分類のパラメータを変えた場合の損失関数の推移
    • 横軸：パラメータ（しきい値）
    • 縦軸：損失（誤分類の数）
      • しきい値を1つ決めると、損失が1つ決まる

最適化問題とは

機械学習の中心課題

これまで学んだ手法も、裏ではすべて最適化問題を解いていた：

  • しきい値による分類: 誤分類が最も少なくなる場所にしきい値を置く
  • k-means: 各点から中心までの距離の合計（inertia）を最小にする
  • 境界: 損失関数を最小にするパラメータを探す

機械学習 = 最適化

「どうパラメータを調整すれば、最も良い結果が得られるか？」を数値的に解く

勾配降下法

進め方

  1. 目的関数（objective function）の意味を説明
  2. 勾配降下法（gradient descent）を1ステップずつ手計算
  3. Pythonで実装
  4. 調整値「学習率（learning rate）」を変えて、収束・発散の違いを確かめる

この関数の最小値を求める（目的関数）

\[f(x) = x^2 - 4x + 3\]

数学的には簡単だが、今回は数値的に（コンピュータのアプローチ）解く

目的関数（objective function）

最小化または最大化の対象となる関数

勾配降下法には滑らかな損失関数が必要

  • 今回は、目的関数 \(f(x)\) ＝ 損失関数
    • \(x\)：パラメータ
    • \(f(x)\)：損失関数
  • 勾配降下法では、傾きを計算できる滑らかな損失関数を使う
    • 滑らか = 微分ができるという意味

参考：分類で使う代理損失

  • 分類の学習では、予測の外れ方を連続的に測る滑らかな関数を使う
  • 誤分類数などの評価基準の代わりに最小化するため、代理損失（surrogate loss）と呼ぶ
  • 学習では代理損失を最小化し、評価には誤分類数や正答率を使える

基本方針：今いる位置から徐々に谷底を目指す

  • 今回の \(f(x) = x^2 - 4x + 3\) なら、グラフを描けば最小値は \(x = 2\) と一目で分かる
  • しかし実際の機械学習では、パラメータが多数ある。損失関数のグラフは描けない
  • グラフ全体が見えなくても、いまの位置 \(x\) で計算できる値はある：
    • 関数の値 \(f(x)\)
    • 傾き \(f'(x) = 2x - 4\)

今回の主題

足元の傾き（勾配, gradient）だけを頼りに、一歩ずつ谷底へ降りるのが勾配降下法

傾きの符号で進む方向が決まる

  • \(x = 0\) から出発する（別にどこからでもいい。今回はたまたま0）
  • ここでの傾きは \(f'(0) = 2 \cdot 0 - 4 = -4\)
  • 傾きが負 ＝ この場所では、右へ少し動くと \(f(x)\) が下がる（下り坂は右）
  • 谷底に近づくには、傾きの逆方向（傾きが負なら右）へ少し進めばよい

要するに

進んだ先でまた傾きを測れば、次の一歩も決まる。繰り返せば谷底に近づく

更新式

「傾きの逆方向に、少し進む」を式で書く：

\[x_{\text{new}} = x - \alpha \cdot f'(x)\]

  • \(x\): 現在の位置
  • \(f'(x)\): 傾き（勾配）
  • \(\alpha\): 学習率。1歩の大きさを決める正の数
  • \(x_{\text{new}}\): 次の位置

ノート

学習率 \(\alpha\) は自分で決める必要がある（これが難しい）

一旦、傾き0を目指す

更新式 \(x_{\text{new}} = x - \alpha \cdot f'(x)\) を、傾きの符号で場合分けする：

  • 傾きが負（下り坂は右）→ \(-\alpha \cdot f'(x)\) は正 → 右へ進む
  • 傾きが正（下り坂は左）→ \(-\alpha \cdot f'(x)\) は負 → 左へ進む
  • 傾きが0（谷底）→ \(-\alpha \cdot f'(x)\) も \(0\) → 動かない
    • 傾き0は山頂の可能性もあるが、下がってきて山頂は内という前提
      • ただ、初期値がいきなり山頂だと詰むので注意

要するに

同じ式を繰り返すだけで谷底に近づいていく

ステップ1：現在の位置

\[x = 0\]

ステップ2：関数値を計算

\[f(0) = 0^2 - 4 \times 0 + 3 = 3\]

ステップ3：勾配を計算

\[f'(0) = 2 \times 0 - 4 = -4\]

意味: 傾きが\(-4\)（負）なので、右に行くほど値が小さくなる

ステップ4：更新

更新式: \[x_{\text{new}} = x - \alpha \cdot f'(x)\]

代入: \[x_{\text{new}} = 0 - 0.3 \times (-4)\]

計算: \[\begin{align} &= 0 - (-1.2) \\ &= 0 + 1.2 \\ &= 1.2 \end{align}\]

重要

反復1の結果: \(x = 0 \rightarrow x = 1.2\)

\[x = 1.2\]

ステップ2：関数値

\[f(1.2) = 1.2^2 - 4 \times 1.2 + 3 = 1.44 - 4.8 + 3 = -0.36\]

ステップ3：勾配

\[f'(1.2) = 2 \times 1.2 - 4 = 2.4 - 4 = -1.6\]

ステップ4：更新

\[x_{\text{new}} = 1.2 - 0.3 \times (-1.6) = 1.2 + 0.48 = 1.68\]

勾配降下法の実装例

  • 手計算で使った更新式を、そのまま for 文で繰り返す
def f(x):
    return x**2 - 4*x + 3

def f_prime(x):
    return 2*x - 4

x = 0.0
lr = 0.3
max_iter = 10
tolerance = 0.01

for iteration in range(1, max_iter + 1):
    gradient = f_prime(x)
    x = x - lr * gradient
    print(f"反復{iteration}: x = {x:.4f}")

    if abs(f_prime(x)) < tolerance:
        print("ほぼ収束（|f'(x)| < 0.01）")
        break

print(f"最終 x = {x:.4f}")
print(f"最終 f(x) = {f(x):.4f}")

反復5: x = 1.9795
反復6: x = 1.9918
反復7: x = 1.9967

学習率で挙動が変わる

振動と発散は別

  • \(\alpha=0.75\)：谷をまたいで振動するが、振幅は小さくなり収束する
  • \(\alpha=1.1\)：谷をまたぐたびに振幅が大きくなり発散する

学習率以外にも決める値がある

  • 初期値：どこから探索を始めるか
  • 学習率：1回の更新でどれだけ進むか
  • 最大反復回数：終わらない場合に何回で打ち切るか
  • 停止条件：\(|f'(x)| < 0.01\) など、いつ収束したと判断するか

今回注目する値

勾配降下法の動きを大きく変える学習率を中心に比較する

2変数では傾きが勾配ベクトルになる

  • 2変数では、それぞれの方向の傾きを偏微分（partial derivative）で求める
  • 偏微分を並べたベクトルが勾配

\[ f(w_1,w_2)=w_1^2+3w_2^2, \qquad \nabla f(w_1,w_2)= \begin{pmatrix} 2w_1 \\ 6w_2 \end{pmatrix} \]

\[ \begin{pmatrix}w_1\\w_2\end{pmatrix}_{\mathrm{new}} = \begin{pmatrix}w_1\\w_2\end{pmatrix} -\alpha\nabla f(w_1,w_2) \]

1変数との共通点

パラメータが増えても、各パラメータを個別に計算するだけ。１次元と変わらない。

\(f(w_1,w_2)=w_1^2+3w_2^2\) 最適化の可視化

  • \(w_1\) は谷の同じ側から近づき、\(w_2\) は谷をまたいで振動しながら収束する
  • 実際の機械学習の損失地形はこのさらに高次元版
    • グラフでは描けなくても、勾配ベクトルを使って各パラメータを地道に更新する

勾配降下法は主力アルゴリズム

  • 弱点（学習率の調整・遅さ）があるのに、勾配降下法はメインウェポン
  • 理由：パラメータが多数あっても、勾配を計算できれば更新できる
  • 実用では、パラメータごとに更新幅を調整する改良法（Adam など）も使われる

参考資料

  • もっと賢く進む手法もある → Newton法（2次微分で一気にジャンプ）
  • 谷が複数あるとき、どの谷に落ちるかは初期値しだい → ローカルミニマムの罠

まとめ

  • 最適化：評価基準が最も良くなるパラメータを探すこと。多くの fit() の中心にある
  • 勾配降下法：傾きを測り、逆方向に少し進む、を繰り返す

\[x_{\text{new}} = x - \alpha \cdot f'(x)\]

  • 学習率 \(\alpha\) は主な調整値：小さいと遅く、大きすぎると発散する
  • 初期値・最大反復回数・停止条件も決める必要がある
  • シンプルで軽く、大規模問題（ディープラーニング）の標準エンジンとなっている

次回予告

  • 今日手に入れた勾配降下法が、fit() の中身を開ける鍵になる
  • 次回、本物のモデル（線形回帰）を、この道具で自分の手で fit する
  • その先に分類モデル、そしてニューラルネットワークが続く。勾配降下法はディープラーニングを動かしている本物のエンジン

準備
