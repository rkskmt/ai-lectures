今回の主題

候補を全部試さずに、多くの手法に共通して使える探し方はあるか

損失（Loss）

  • 損失：結果のダメさを測る物差し
    • 小さいほど良い
  • 最適化（optimization）：損失が最小になるパラメータを探すこと
    • 本当の最小値に届かなくても、十分に小さい値が見つかれば最適化と呼ぶことが多い
手法 損失 測っているダメさ
しきい値で分類 総コスト 誤分類にかかる費用の合計
決定木 加重平均ジニ不純度 分けた左右にクラスが混ざっている度合い
k-means SSE 各点から自分の重心までの距離の2乗の合計

パラメータ

  • パラメータ：学習がデータから決める値
    • 学習が終われば固定
  • 学習：データからパラメータを決めること
    • 多くのモデルでは、最適化でパラメータを決める

「パラメータ」の呼び分け

  • プログラミングでは、関数に渡す値もパラメータと呼ぶ
    • k-means の k はこの意味ではパラメータだが、機械学習ではハイパーパラメータ
  • 学習で決まる側は、学習可能パラメータ（trainable parameter / learnable parameter）やモデルパラメータ（model parameter）とも呼ばれる
    • 普通は単にパラメータと呼ぶ

損失関数（Loss Function）

  • 損失関数：パラメータを入力すると損失を返す関数
    • 例：Salmon と Sea bass の分類では、しきい値を決めると誤分類の数が決まる

要するに

損失の最小化は、損失関数のグラフの谷底探し

斜めの直線のパラメータは、傾きと切片の2個

  • 斜めの直線で分けられそうに見えた境界は、傾きと切片で決まる

要するに

パラメータを変えると境界線が動き、正答率が変わる

総当たりは、パラメータが増えると試しきれない

  • パラメータ1個につき、候補を100個試すとする
パラメータの数 試す組み合わせ
1個（しきい値） \(100\) 通り
2個（傾きと切片） \(100 \times 100 = 10^4\) 通り
10個 \(100^{10} = 10^{20}\) 通り

勾配降下法

目的関数（Objective Function）

  • 目的関数：最適化で最小化または最大化する関数
    • 損失関数は、最小化する目的関数
  • 今回は \(x\) をパラメータ、\(f(x)\) を損失として、次の関数を最小化する

\[f(x) = x^2 - 4x + 3\]

  • 数学的には簡単だが、今回は数値的解法（numerical method）で解く
    • コンピュータが計算を繰り返して答えに近づく方法

ノート

数値的解法の逆は、解析的解法（analytical method）：式変形で答えを直接求める方法

基本方針：今いる位置から徐々に谷底を目指す

  • \(f(x) = x^2 - 4x + 3\) なら、グラフを描けば最小値は \(x = 2\) と一目で分かる
  • 実際の機械学習はパラメータが多く、損失関数のグラフを描けない
  • グラフ全体が見えなくても、いまの位置 \(x\) で計算できる値はある
    • 関数の値 \(f(x)\)
    • 傾き \(f'(x) = 2x - 4\)

勾配降下法（Gradient Descent）

足元の傾き（勾配, gradient）だけを手がかりに、一歩ずつ谷底へ降りる手法

傾きの符号で進む方向が決まる

  • 出発点を \(x = 0\) とする（どこから始めてもよい）
  • ここでの傾きは \(f'(0) = 2 \cdot 0 - 4 = -4\)
  • 傾きが負なので、右へ少し動くと \(f(x)\) が下がる
  • 谷底に近づくには、傾きの逆方向へ少し進めばよい

要するに

  • 進んだ先でまた傾きを測れば、次の一歩も決まる
  • 繰り返せば谷底に近づく

更新式

「傾きの逆方向に、少し進む」を式で書く：

\[x_{\text{new}} = x - \alpha \cdot f'(x)\]

  • \(x\)：現在の位置
  • \(f'(x)\)：傾き（勾配）
  • \(\alpha\)：学習率（learning rate）（1歩の大きさを決める正の数）
  • \(x_{\text{new}}\)：次の位置

ノート

学習率 \(\alpha\) はデータからは決まらず、人間が決めるハイパーパラメータ

傾きが0になると止まる

更新式 \(x_{\text{new}} = x - \alpha \cdot f'(x)\) を、傾きの符号で場合分けする：

傾き \(f'(x)\) 移動量 \(-\alpha \cdot f'(x)\) 動き
負（下り坂は右） 正 右へ進む
正（下り坂は左） 負 左へ進む
\(0\) \(0\) 止まる

傾きが0でも谷底とは限らない

  • 山頂でも傾きは \(0\) になる
  • 下りながら進むので途中で山頂に止まることはまずないが、初期値が山頂だとそこから動かない

勾配降下法：手計算で実行

  • 設定
  • 反復1
  • 反復2
  • 関数：\(f(x) = x^2 - 4x + 3\)
  • 1次微分：\(f'(x) = 2x - 4\)
  • 初期値：\(x_0 = 0\)
  • 学習率：\(\alpha = 0.3\)
  • 反復（iteration）：更新を繰り返すこと（反復1は1回目の更新）

ステップ1：現在の位置

\[x = 0\]

ステップ2：関数値を計算

\[f(0) = 0^2 - 4 \times 0 + 3 = 3\]

ステップ3：勾配を計算

\[f'(0) = 2 \times 0 - 4 = -4\]

傾きが \(-4\)（負）なので、右へ進むと値が小さくなる

ステップ4：更新

更新式： \[x_{\text{new}} = x - \alpha \cdot f'(x)\]

代入： \[x_{\text{new}} = 0 - 0.3 \times (-4)\]

計算： \[\begin{align} &= 0 - (-1.2) \\ &= 0 + 1.2 \\ &= 1.2 \end{align}\]

重要

反復1の結果：\(x = 0 \rightarrow x = 1.2\)

ステップ1：現在の位置

\[x = 1.2\]

ステップ2：関数値

\[f(1.2) = 1.2^2 - 4 \times 1.2 + 3 = 1.44 - 4.8 + 3 = -0.36\]

ステップ3：勾配

\[f'(1.2) = 2 \times 1.2 - 4 = 2.4 - 4 = -1.6\]

ステップ4：更新

\[x_{\text{new}} = 1.2 - 0.3 \times (-1.6) = 1.2 + 0.48 = 1.68\]

勾配降下法の実装例

  • 手計算で使った更新式を、そのまま for 文で繰り返す
def f(x):
    return x**2 - 4*x + 3

def f_prime(x):
    return 2*x - 4

x = 0.0            # 初期値
lr = 0.3           # 学習率
max_iter = 10      # 最大反復回数
tolerance = 0.01   # 傾きの大きさがこれ未満になったら止める

for iteration in range(1, max_iter + 1):
    gradient = f_prime(x)
    x = x - lr * gradient
    print(f"iter {iteration:2d}: x = {x:.4f}")

    if abs(f_prime(x)) < tolerance:
        print("ほぼ収束（|f'(x)| < 0.01）")
        break

print(f"最終 x = {x:.4f}")
print(f"最終 f(x) = {f(x):.4f}")
iter  1: x = 1.2000
iter  2: x = 1.6800
iter  3: x = 1.8720
iter  4: x = 1.9488
iter  5: x = 1.9795
iter  6: x = 1.9918
iter  7: x = 1.9967
ほぼ収束（|f'(x)| < 0.01）
最終 x = 1.9967
最終 f(x) = -1.0000

結果

\(x\) が最小値 \(x = 2\) に近づき、ほとんど動かなくなった：収束（convergence）

Tweak 学習率を変更

  • 実装例のコード の lr を書き換えて実行
やりたいこと コード
歩幅を小さくする lr = 0.01
歩幅を大きくする lr = 0.75
さらに大きくする lr = 1.0
もう少しだけ大きくする lr = 1.1

チェックポイント

  • lr = 0.01：10回の更新では谷底 \(x=2\) に届かない
  • lr = 1.0：谷底をはさんだ同じ2点を往復し続ける

学習率で挙動が変わる

振動と発散は別

  • \(\alpha=0.75\)：谷をまたいで振動（oscillation）するが、振幅は小さくなり収束する
  • \(\alpha=1.1\)：谷をまたぐたびに振幅が大きくなり発散（divergence）する

学習率以外にも決める値がある

  • 初期値：どこから探索を始めるか
  • 学習率：1回の更新でどれだけ進むか
  • 最大反復回数：終わらない場合に何回で打ち切るか
  • 停止条件：\(|f'(x)| < 0.01\) など、いつ収束したと判断するか

勾配降下法には滑らかな損失関数が必要

  • 勾配降下法は傾きを手がかりにするので、滑らかな損失関数を使う
    • 滑らか：微分できること
  • 誤分類の数は階段状で、傾きが手がかりにならない

（参考）分類で使う代理損失

  • 代理損失（surrogate loss）：誤分類数などの評価基準の代わりに最小化する、滑らかな損失
  • 学習では代理損失を最小化し、評価には誤分類数や正答率を使う

2変数では軸ごとの傾きを並べた勾配ベクトルを使う

  • パラメータが \(w_1, w_2\) の2個なら、それぞれの方向の傾きを偏微分（partial derivative）で求める
  • 勾配 \(\nabla f\)（\(\nabla\) はナブラ）：偏微分を並べたベクトル

\[ f(w_1,w_2)=w_1^2+3w_2^2, \qquad \nabla f(w_1,w_2)= \begin{pmatrix} 2w_1 \\ 6w_2 \end{pmatrix} \]

\[ \begin{pmatrix}w_1\\w_2\end{pmatrix}_{\mathrm{new}} = \begin{pmatrix}w_1\\w_2\end{pmatrix} -\alpha\nabla f(w_1,w_2) \]

1変数との共通点

パラメータが増えても、各パラメータの更新は1変数のときと同じ

2変数の勾配降下法：手計算で実行

  • 関数：\(f(w_1,w_2)=w_1^2+3w_2^2\)
  • 初期値：\((w_1,w_2)=(-4,2)\)
  • 学習率：\(\alpha=0.25\)

勾配：

\[ \underbrace{\frac{\partial f}{\partial w_1}=2w_1}_{w_2\text{ を定数と見て微分}} \qquad \underbrace{\frac{\partial f}{\partial w_2}=6w_2}_{w_1\text{ を定数と見て微分}} \]

\[ \nabla f(-4,2)= \begin{pmatrix}2\times(-4)\\6\times2\end{pmatrix} = \begin{pmatrix}-8\\12\end{pmatrix} \]

更新：

\[ \begin{pmatrix}w_1\\w_2\end{pmatrix}_{\mathrm{new}} = \begin{pmatrix}-4\\2\end{pmatrix} -0.25\begin{pmatrix}-8\\12\end{pmatrix} = \begin{pmatrix}-2\\-1\end{pmatrix} \]

結果

\(f\) の値は \(f(-4,2)=28\) から \(f(-2,-1)=7\) に下がる

2変数の勾配降下法の実装例

  • 1変数の実装と同様に、\(w_1\) と \(w_2\) をそれぞれ更新する
def f2(w1, w2):
    return w1**2 + 3 * w2**2

w1 = -4.0
w2 = 2.0
lr = 0.25
max_iter = 6

for iteration in range(1, max_iter + 1):
    grad_w1 = 2 * w1   # df/dw1
    grad_w2 = 6 * w2   # df/dw2
    w1 = w1 - lr * grad_w1
    w2 = w2 - lr * grad_w2
    print(f"iter {iteration}: w1={w1:7.4f} w2={w2:7.4f} f={f2(w1, w2):.4f}")

iter 4: w1=-0.2500 w2= 0.1250 f=0.1094

2変数の勾配降下法の軌跡

\[f(w_1,w_2)=w_1^2+3w_2^2\]

要するに

  • \(w_1\) は谷の同じ側から近づく
  • \(w_2\) は谷をまたぎ、振動しながら収束する
  • 実際の機械学習はパラメータがさらに多いが、更新のしかたは同じ

勾配降下法は機械学習の主力

  • 強み：パラメータが多くても、勾配を計算できれば更新できる
  • 弱点：学習率の調整が必要で、収束が遅いことがある
  • 実用では、パラメータごとに更新幅を調整する改良法（Adam など）も使われる

参考資料

  • Newton法：2次微分を使い、少ない反復で最小値に近づく
  • ローカルミニマムの罠：谷が複数あると、どの谷に着くかは初期値で決まる

まとめ

  • 最適化：損失が最小になるパラメータを探すこと
    • 候補を全部試す探し方は、パラメータが増えると使えない
  • 勾配降下法：傾きの逆方向へ少し進むことを繰り返す手法

\[x_{\text{new}} = x - \alpha \cdot f'(x)\]

  • 学習率 \(\alpha\)：小さいと収束が遅く、大きすぎると発散する
  • 初期値、最大反復回数、停止条件も決める必要がある
  • パラメータが増えても、偏微分を並べた勾配で同じように更新する
  • 計算が軽く、ディープラーニングのような大規模な問題でも標準的に使われる

練習問題

\(f(x) = x^2 + 6x + 5\) を、初期値 \(x_0 = 0\)、学習率 \(\alpha = 0.2\) の勾配降下法で最小化する過程を、紙に書いて求めよ。

  1. \(f'(x)\) の導出
  2. 3回の更新（各回の \(f'(x)\) と \(x\) を記載）

（参考）Newton法の練習問題では、同じ関数を別の手法で解いて速さを比べる

練習問題の解答例

準備

\[f(x) = x^2 + 6x + 5\]

1次微分： \[f'(x) = 2x + 6\]

  • 反復1
  • 反復2
  • 反復3

現在：\(x = 0\)

\[f'(0) = 2(0) + 6 = 6\]

更新： \[x_{\text{new}} = 0 - 0.2 \times 6 = 0 - 1.2 = -1.2\]

現在：\(x = -1.2\)

\[f'(-1.2) = 2(-1.2) + 6 = -2.4 + 6 = 3.6\]

更新： \[x_{\text{new}} = -1.2 - 0.2 \times 3.6 = -1.2 - 0.72 = -1.92\]

現在：\(x = -1.92\)

\[f'(-1.92) = 2(-1.92) + 6 = -3.84 + 6 = 2.16\]

更新： \[x_{\text{new}} = -1.92 - 0.2 \times 2.16 = -1.92 - 0.432 = -2.352\]

結果

\(x\) は最小値 \(x=-3\) に近づいているが、まだ収束していない

演習：4次関数で初期値を変える

\(f(x) = x^4 - 2x^2\) を学習率 \(\alpha = 0.05\) の勾配降下法で最小化する過程を、紙に書いて求めよ。

  1. \(f'(x)\) の導出
  2. 初期値 \(x_0 = 2\) から2回の更新（各回の \(f'(x)\) と \(x\) を記載）
  3. 初期値 \(x_0 = -2\) から2回の更新（各回の \(f'(x)\) と \(x\) を記載）
  4. 初期値 \(x_0 = 0\) から1回の更新
  5. \(f'(x) = 0\) となる \(x\) を求めて \(y = f(x)\) の概形を描き、2〜4 の結果の違いを説明

演習：2変数関数を更新する

\(f(w_1, w_2) = w_1^2 + 2w_2^2 - 2w_1 + 4w_2\) を、初期値 \((w_1, w_2) = (0, 0)\)、学習率 \(\alpha = 0.2\) の勾配降下法で最小化する過程を、紙に書いて求めよ。

  1. \(\dfrac{\partial f}{\partial w_1}\) と \(\dfrac{\partial f}{\partial w_2}\) の導出
  2. 3回の更新（各回の勾配と \((w_1, w_2)\) を記載）
  3. 両方の偏微分を \(0\) とおいて求めた、\(f\) が最小になる \((w_1, w_2)\)
  4. \(w_1\) と \(w_2\) のどちらが速く最小点に近づくかの比較
