勾配降下法

今回はこの関数を最小化しよう：目的関数（objective function)

\[f(x) = x^2 - 4x + 3\]

数学的には簡単だが、今回は数値的に（コンピュータのアプローチ）解く（数値的解法、numerical method）

ノート

数値的解法の逆は、解析的解法（analytical method）

目的関数は最小化する場合と最大化する場合がある

勾配降下法には滑らかな損失関数が必要

  • 今回は、目的関数 \(f(x)\) ＝ 損失関数
    • \(x\)：パラメータ
    • \(f(x)\)：損失関数
  • 勾配降下法では、傾きを計算できる滑らかな損失関数を使う
    • 滑らか = 微分ができるという意味

参考：分類で使う代理損失

  • 分類の学習では、予測の外れ方を連続的に測る滑らかな関数を使う
  • 代理損失（surrogate loss）：誤分類数などの評価基準の代わりに最小化する損失
  • 学習では代理損失を最小化し、評価には誤分類数や正答率を使える

基本方針：今いる位置から徐々に谷底を目指す

  • 今回の \(f(x) = x^2 - 4x + 3\) なら、グラフを描けば最小値は \(x = 2\) と一目で分かる
  • しかし実際の機械学習では、パラメータが多数ある。損失関数のグラフは描けない
  • グラフ全体が見えなくても、いまの位置 \(x\) で計算できる値はある：
    • 関数の値 \(f(x)\)
    • 傾き \(f'(x) = 2x - 4\)

今回の主題

足元の傾き（勾配, gradient）だけを頼りに、一歩ずつ谷底へ降りるのが勾配降下法

傾きの符号で進む方向が決まる

  • \(x = 0\) から出発する（別にどこからでもいい。今回はたまたま0）
  • ここでの傾きは \(f'(0) = 2 \cdot 0 - 4 = -4\)
  • 傾きが負 ＝ この場所では、右へ少し動くと \(f(x)\) が下がる（下り坂は右）
  • 谷底に近づくには、傾きの逆方向（傾きが負なら右）へ少し進めばよい

要するに

進んだ先でまた傾きを測れば、次の一歩も決まる。繰り返せば谷底に近づく

更新式

「傾きの逆方向に、少し進む」を式で書く：

\[x_{\text{new}} = x - \alpha \cdot f'(x)\]

  • \(x\): 現在の位置
  • \(f'(x)\): 傾き（勾配）
  • \(\alpha\): 学習率。1歩の大きさを決める正の数
  • \(x_{\text{new}}\): 次の位置

ノート

学習率 \(\alpha\) は自分で決める必要がある（これが難しい）

一旦、傾き0を目指す

更新式 \(x_{\text{new}} = x - \alpha \cdot f'(x)\) を、傾きの符号で場合分けする：

  • 傾きが負（下り坂は右）→ \(-\alpha \cdot f'(x)\) は正 → 右へ進む
  • 傾きが正（下り坂は左）→ \(-\alpha \cdot f'(x)\) は負 → 左へ進む
  • 傾きが0（谷底）→ \(-\alpha \cdot f'(x)\) も \(0\) → 動かない
    • 傾き0は山頂の可能性もあるが、下がってきて山頂は内という前提
      • ただ、初期値がいきなり山頂だと詰むので注意

要するに

同じ式を繰り返すだけで谷底に近づいていく

勾配降下法の実装例

  • 手計算で使った更新式を、そのまま for 文で繰り返す
def f(x):
    return x**2 - 4*x + 3

def f_prime(x):
    return 2*x - 4

x = 0.0
lr = 0.3
max_iter = 10
tolerance = 0.01

for iteration in range(1, max_iter + 1):
    gradient = f_prime(x)
    x = x - lr * gradient
    print(f"反復{iteration}: x = {x:.4f}")

    if abs(f_prime(x)) < tolerance:
        print("ほぼ収束（|f'(x)| < 0.01）")
        break

print(f"最終 x = {x:.4f}")
print(f"最終 f(x) = {f(x):.4f}")

チェックポイント

  • lr = 0.01：10回の更新では谷底 \(x=2\) に届かない
  • lr = 1.0：谷底をはさんだ同じ2点を往復し続ける

学習率で挙動が変わる

振動と発散は別

  • \(\alpha=0.75\)：谷をまたいで振動するが、振幅は小さくなり収束する
  • \(\alpha=1.1\)：谷をまたぐたびに振幅が大きくなり発散する

学習率以外にも決める値がある

  • 初期値：どこから探索を始めるか
  • 学習率：1回の更新でどれだけ進むか
  • 最大反復回数：終わらない場合に何回で打ち切るか
  • 停止条件：\(|f'(x)| < 0.01\) など、いつ収束したと判断するか

今回注目する値

勾配降下法の動きを大きく変える学習率を中心に比較する

2変数では軸ごとの傾きを並べた勾配ベクトルを使う

  • 2変数では、それぞれの方向の傾きを偏微分（partial derivative）で求める
  • 偏微分を並べたベクトルが勾配

\[ f(w_1,w_2)=w_1^2+3w_2^2, \qquad \nabla f(w_1,w_2)= \begin{pmatrix} 2w_1 \\ 6w_2 \end{pmatrix} \]

\[ \begin{pmatrix}w_1\\w_2\end{pmatrix}_{\mathrm{new}} = \begin{pmatrix}w_1\\w_2\end{pmatrix} -\alpha\nabla f(w_1,w_2) \]

1変数との共通点

パラメータが増えても、各パラメータを個別に計算するだけ。１次元と変わらない。

2変数の勾配降下法：手計算で実行

  • 関数：\(f(w_1,w_2)=w_1^2+3w_2^2\)
  • 初期値：\((w_1,w_2)=(-4,2)\)
  • 学習率：\(\alpha=0.25\)

勾配:

\[ \underbrace{\frac{\partial f}{\partial w_1}=2w_1}_{w_2\text{ を定数と見て微分}} \qquad \underbrace{\frac{\partial f}{\partial w_2}=6w_2}_{w_1\text{ を定数と見て微分}} \]

\[ \nabla f(-4,2)= \begin{pmatrix}2\times(-4)\\6\times2\end{pmatrix} = \begin{pmatrix}-8\\12\end{pmatrix} \]

更新:

\[ \begin{pmatrix}w_1\\w_2\end{pmatrix}_{\mathrm{new}} = \begin{pmatrix}-4\\2\end{pmatrix} -0.25\begin{pmatrix}-8\\12\end{pmatrix} = \begin{pmatrix}-2\\-1\end{pmatrix} \]

結果

\(f\) の値は \(f(-4,2)=28\) から \(f(-2,-1)=7\) に下がる

2変数の勾配降下法の実装例

  • 1変数の実装と同様に、\(w_1\) と \(w_2\) をそれぞれ更新する
def f2(w1, w2):
    return w1**2 + 3 * w2**2

w1 = -4.0
w2 = 2.0
lr = 0.25
max_iter = 6

for iteration in range(1, max_iter + 1):
    grad_w1 = 2 * w1   # df/dw1
    grad_w2 = 6 * w2   # df/dw2
    w1 = w1 - lr * grad_w1
    w2 = w2 - lr * grad_w2
    print(f"iter {iteration}: w1={w1:7.4f} w2={w2:7.4f} f={f2(w1, w2):.4f}")

\(f(w_1,w_2)=w_1^2+3w_2^2\) 最適化の可視化

  • \(w_1\) は谷の同じ側から近づき、\(w_2\) は谷をまたいで振動しながら収束する
  • 実際の機械学習の損失地形はこのさらに高次元版
    • グラフでは描けなくても、勾配ベクトルを使って各パラメータを地道に更新する

勾配降下法は主力アルゴリズム

  • 弱点（学習率の調整・遅さ）があるのに、勾配降下法はメインウェポン
  • 理由：パラメータが多数あっても、勾配を計算できれば更新できる
  • 実用では、パラメータごとに更新幅を調整する改良法（Adam など）も使われる

参考資料

  • もっと賢く進む手法もある → Newton法（2次微分で一気にジャンプ）
  • 谷が複数あるとき、どの谷に落ちるかは初期値しだい → ローカルミニマムの罠

まとめ

  • 最適化：損失が最小になるパラメータを探すこと
    • 候補を全部試す探し方は、パラメータが増えると使えない
  • 勾配降下法：傾きを測り、逆方向に少し進む、を繰り返す

\[x_{\text{new}} = x - \alpha \cdot f'(x)\]

  • 学習率 \(\alpha\) は主な調整値：小さいと遅く、大きすぎると発散する
  • 初期値・最大反復回数・停止条件も決める必要がある
  • シンプルで軽く、大規模問題（ディープラーニング）の標準エンジンとなっている

練習問題

以下の問題を紙で解け。

関数 \(f(x) = x^2 + 6x + 5\) について：

  1. 1次微分を求めよ
  2. 初期値 \(x_0 = 0\)、学習率 \(\alpha = 0.2\) で勾配降下法を実行せよ
  3. 反復1、反復2、反復3を手計算で示せ

発展課題：Newton法（参考資料）の練習問題で、同じ関数を別の手法で解いて速さを比較する。

練習問題の解答例

準備

\[f(x) = x^2 + 6x + 5\]

1次微分: \[f'(x) = 2x + 6\]

  • 反復1
  • 反復2
  • 反復3

現在: \(x = 0\)

\[f'(0) = 2(0) + 6 = 6\]

更新: \[x_{\text{new}} = 0 - 0.2 \times 6 = 0 - 1.2 = -1.2\]

現在: \(x = -1.2\)

\[f'(-1.2) = 2(-1.2) + 6 = -2.4 + 6 = 3.6\]

更新: \[x_{\text{new}} = -1.2 - 0.2 \times 3.6 = -1.2 - 0.72 = -1.92\]

現在: \(x = -1.92\)

\[f'(-1.92) = 2(-1.92) + 6 = -3.84 + 6 = 2.16\]

更新: \[x_{\text{new}} = -1.92 - 0.2 \times 2.16 = -1.92 - 0.432 = -2.352\]

まだ収束していない（理論値は\(x=-3\)）

演習：4次関数で初期値を変える

\(f(x) = x^4 - 2x^2\) を学習率 \(\alpha = 0.05\) の勾配降下法で最小化する過程を、紙に書いて求めよ。

  1. \(f'(x)\) の導出
  2. 初期値 \(x_0 = 2\) から2回の更新（各回の \(f'(x)\) と \(x\) を記載）
  3. 初期値 \(x_0 = -2\) から2回の更新（各回の \(f'(x)\) と \(x\) を記載）
  4. 初期値 \(x_0 = 0\) から1回の更新
  5. \(f'(x) = 0\) となる \(x\) を求めて \(y = f(x)\) の概形を描き、2〜4 の結果の違いを説明

演習：2変数関数を更新する

\(f(w_1, w_2) = w_1^2 + 2w_2^2 - 2w_1 + 4w_2\) を、初期値 \((w_1, w_2) = (0, 0)\)、学習率 \(\alpha = 0.2\) の勾配降下法で最小化する過程を、紙に書いて求めよ。

  1. \(\dfrac{\partial f}{\partial w_1}\) と \(\dfrac{\partial f}{\partial w_2}\) の導出
  2. 3回の更新（各回の勾配と \((w_1, w_2)\) を記載）
  3. 両方の偏微分を \(0\) とおいて求めた、\(f\) が最小になる \((w_1, w_2)\)
  4. \(w_1\) と \(w_2\) のどちらが速く最小点に近づくかの比較
