勾配を全パラメータに届ける仕組み

rkskmt

前回の振り返り

  • 変換を重ねると曲がる境界が作れる（ReLU の折り目）
  • 学習に必要なのは、全パラメータの勾配 \(\partial L / \partial \theta\)
  • 前回は「誤差が逆向きに流れる」とだけ言って、仕組みの説明を保留した

今回の問い

パラメータが5個、100個、100万個 — 全部の勾配をどうやって計算する？

この回で1往復する道筋

  1. 往路：入力から予測と損失を計算し、途中の値を保存する
  2. 復路：損失から出力側へ、局所的な微分を掛けて戻る
  3. 各パラメータの勾配を取り出す
  4. 勾配降下法で全パラメータを1ステップ更新する
  5. もう一度往路を計算し、損失が下がったか確認する

backprop だけで学習が終わるわけではない。往路 → 復路 → 更新で1ステップ

合成した式を直接微分すると長くなる

  • 前回の2層ネット。\(\alpha_1\) の勾配を直接書き下すと：

\[\frac{\partial L}{\partial \alpha_1} = \frac{\partial}{\partial \alpha_1} \left[ -\log \sigma\!\Big( w \cdot \mathrm{ReLU}(\alpha_1 x_1 + \alpha_2 x_2 + b) + c \Big) \right]\]

質問

パラメータは5個。この調子で5本の式を全部展開する？ 100層・100万パラメータになったら？

  • 実は、展開しなくていい
  • 鍵は高校数学で習った合成関数の微分（連鎖律）

連鎖律：微分は掛け算でつなげる

  • 関数が数珠つなぎなら、微分も数珠つなぎ：

\[y = f(g(x)) \quad \Rightarrow \quad \frac{dy}{dx} = \frac{dy}{dg} \cdot \frac{dg}{dx}\]

質問（高校の道具の再確認）

\(y = (3x+1)^2\) を、展開せずに微分すると？

  • 外側 \(u^2\) の微分は \(2u\)、内側 \(3x+1\) の微分は \(3\)。掛けて \(\dfrac{dy}{dx} = 2(3x+1) \times 3 = 18x + 6\)
  • 展開して微分（\(9x^2 + 6x + 1 \to 18x + 6\)）と一致 — 部品の微分を掛けるだけで、展開は要らなかった
  • この連鎖律だけで、NN の全パラメータの勾配を出せる

微分値は「少し動かしたときの変化量」

ある場所で \(dfrac{dy}{dx}=-3\) なら、\(x\) をほんの少し \(+0.01\) 動かすと：

\[\Delta y \approx \frac{dy}{dx}\Delta x=-3\times0.01=-0.03\]

  • 微分が正：入力を増やすと出力も増える
  • 微分が負：入力を増やすと出力は減る
  • 絶対値が大きい：わずかな変更でも出力が大きく変わる

ノート

\(\partial L/\partial w\) は「重み \(w\) を少し動かすと、損失 \(L\) がどちらへどれだけ変わるか」を表す

パラメータが複数なら偏微分する

損失 \(L\) は、5個すべてのパラメータに依存する：

\[L=L(\alpha_1,\alpha_2,b,w,c)\]

  • \(\dfrac{\partial L}{\partial \alpha_1}\)：ほかの4個を固定し、\(\alpha_1\) だけ少し動かしたときの変化
  • \(\dfrac{\partial L}{\partial w}\)：ほかの4個を固定し、\(w\) だけ少し動かしたときの変化
  • 5個をまとめたものが勾配 \(\nabla L\)

\[ \nabla L= \left( \frac{\partial L}{\partial \alpha_1}, \frac{\partial L}{\partial \alpha_2}, \frac{\partial L}{\partial b}, \frac{\partial L}{\partial w}, \frac{\partial L}{\partial c} \right) \]

NN は数珠つなぎそのもの

  • 「線形 → ReLU → 線形 → シグモイド → 損失」— NN は関数の数珠つなぎ

\[\frac{\partial L}{\partial \alpha_1} = \frac{\partial L}{\partial p} \cdot \frac{\partial p}{\partial u} \cdot \frac{\partial u}{\partial h} \cdot \frac{\partial h}{\partial z} \cdot \frac{\partial z}{\partial \alpha_1}\]

  • 各カケラはどれも1行で書ける簡単な微分
  • カケラを出力側から順に掛けて貯めていけば、途中の計算を使い回せる

計算グラフにすると順番が見える

  • 箱は計算した値、矢印は値どうしの依存関係
  • 往路は左から右、復路は右から左
  • 復路では各矢印の局所的な微分だけ計算すればよい

長い合成式を丸ごと見る代わりに、計算を小さな箱へ分解する

計算するネットワーク（前回と同じ5パラメータ）

\[x \xrightarrow{\;z = \alpha_1 x_1 + \alpha_2 x_2 + b\;} z \xrightarrow{\;\mathrm{ReLU}\;} h \xrightarrow{\;u = w h + c\;} u \xrightarrow{\;\sigma\;} p \xrightarrow{\;-\log\;} L\]

  • このネットワークを具体的な数値で1往復する：
記号 値
入力 \(x_1, x_2\) \(1.0,\; 0.5\)
正解 \(y\) \(1\)（Salmon）
\(\alpha_1, \alpha_2, b\) \(0.3,\; -0.2,\; 0.1\)
\(w, c\) \(0.5,\; -0.1\)

往路（Forward）：数値を流す

\[z = 0.3 \times 1.0 + (-0.2) \times 0.5 + 0.1 = 0.30\] \[h = \mathrm{ReLU}(0.30) = 0.30\] \[u = 0.5 \times 0.30 + (-0.1) = 0.05\] \[p = \sigma(0.05) = 0.5125\] \[L = -\log(0.5125) = 0.6685\]

  • 予測は 0.5125 —「ほぼコイン投げ」。正解は 1 なので、もっと上げたい
  • 途中の値（\(z, h, u, p\)）は捨てずに取っておく — 復路で全部使う

往路で保存する値は復路の材料

保存する値 今回の値 復路で何に使うか
入力 \(x_1,x_2\) \(1.0,0.5\) \(\alpha_1,\alpha_2\) の勾配
ReLU前 \(z\) \(0.30\) \(\mathrm{ReLU}'(z)\) が0か1か
ReLU後 \(h\) \(0.30\) \(w\) の勾配
出力スコア \(u\) \(0.05\) シグモイドを通った位置
確率 \(p\) \(0.5125\) \(\delta_{\rm out}=p-y\)
  • パラメータだけ保存しても復路は計算できない
  • 入力ごとの途中結果も必要なので、深いネットワークほど学習時のメモリを使う

復路は損失 \(L\) から始める

自分自身を自分で微分すると1：

\[\frac{\partial L}{\partial L}=1\]

ここから左へ1箱ずつ進む：

\[ 1 \times\frac{\partial L}{\partial p} \times\frac{\partial p}{\partial u} \times\frac{\partial u}{\partial h} \times\frac{\partial h}{\partial z} \times\frac{\partial z}{\partial\alpha_1} \]

  • 新しい箱を1つ通るたび、その箱の局所微分を掛ける
  • 途中まで掛けた値を \(\delta\) として保存し、次の計算で再利用する

復路：まず出力層の勾配

  • ロジスティック回帰で求めた \(\dfrac{\partial L}{\partial u}=p-y\) を再利用する：

\[\delta_{\text{out}} = \frac{\partial L}{\partial u} = p - y = 0.5125 - 1 = -0.4875\]

\[\frac{\partial L}{\partial w} = \delta_{\text{out}} \cdot h = -0.4875 \times 0.30 = -0.1463 \qquad \frac{\partial L}{\partial c} = \delta_{\text{out}} = -0.4875\]

  • \(u=wh+c\) なので \(\dfrac{\partial u}{\partial w}=h\)、\(\dfrac{\partial u}{\partial c}=1\)
  • 出力層の2つの勾配は、連鎖律の掛け算だけで求まった

勾配の符号から「動かす向き」を読める

今回の正解は \(y=1\)、予測は \(p=0.5125\)：

\[\frac{\partial L}{\partial c}=-0.4875\]

勾配降下法では負の勾配を引くため：

\[c\leftarrow c-\eta(-0.4875)=c+0.4875\eta\]

  • \(c\) は増える → \(u=wh+c\) も増える
  • \(u\) が増える → \(p=\sigma(u)\) も増える
  • 正解1へ近づく方向なので、損失は下がる

勾配は単なる計算結果ではなく、各パラメータをどちらへ動かすべきかを示す

ReLU の場所で復路が分かれる

中間へ戻るとき、必ず \(\mathrm{ReLU}'(z)\) を掛ける：

\[\delta_{\rm mid}=\delta_{\rm out}\cdot w\cdot\mathrm{ReLU}'(z)\]

往路の \(z\) \(\mathrm{ReLU}'(z)\) 中間より前へ届く勾配
\(z>0\) \(1\) そのまま通る
\(z<0\) \(0\) ここで0になる
  • 今回は \(z=0.30>0\) なので、微分は1
  • したがって \(\delta_{\rm out}\) に \(w=0.5\) を掛けた値が中間へ進む

復路：中間層まで連鎖律をつなぐ

  • \(u\) から \(z\) までの局所的な微分を掛ける：

\[\delta_{\text{mid}} = \delta_{\text{out}} \cdot w \cdot \mathrm{ReLU}'(z) = -0.4875 \times 0.5 \times 1 = -0.2438\]

  • \(z=\alpha_1x_1+\alpha_2x_2+b\) なので、最後に入力を掛ける：

\[\frac{\partial L}{\partial \alpha_1} = \delta_{\text{mid}} \cdot x_1 = -0.2438 \qquad \frac{\partial L}{\partial \alpha_2} = \delta_{\text{mid}} \cdot x_2 = -0.1219 \qquad \frac{\partial L}{\partial b} = \delta_{\text{mid}} = -0.2438\]

  • これで5個すべての勾配が出揃った

  • 黒い矢印が往路、赤い矢印が復路
  • \(\delta\) は「その場所まで戻ってきた損失の微分」。右から左へ連鎖律をつないだ値

5個の勾配を同じ表で見る

パラメータ 勾配 どの値を掛けたか
\(w\) \(-0.1463\) \(\delta_{\rm out}\,h\)
\(c\) \(-0.4875\) \(\delta_{\rm out}\cdot1\)
\(\alpha_1\) \(-0.2438\) \(\delta_{\rm mid}\,x_1\)
\(\alpha_2\) \(-0.1219\) \(\delta_{\rm mid}\,x_2\)
\(b\) \(-0.2438\) \(\delta_{\rm mid}\cdot1\)
  • 線形変換の重みの勾配は、いつも その場所の \(\delta\) × 往路で入ってきた値
  • バイアスへの入力は常に1なので、バイアスの勾配はその場所の \(\delta\) と同じ

出力層でも中間層でも、勾配を作る規則は同じ

勾配降下法で1ステップ更新する

  • 学習率 \(\eta=0.1\) で、\(\theta\leftarrow\theta-\eta\dfrac{\partial L}{\partial\theta}\) を実行：
パラメータ 更新前 勾配 更新後
\(\alpha_1\) \(0.3000\) \(-0.2438\) \(0.3244\)
\(\alpha_2\) \(-0.2000\) \(-0.1219\) \(-0.1878\)
\(b\) \(0.1000\) \(-0.2438\) \(0.1244\)
\(w\) \(0.5000\) \(-0.1463\) \(0.5146\)
\(c\) \(-0.1000\) \(-0.4875\) \(-0.0513\)
  • 更新後のパラメータでもう一度、往路を計算する：

\[p: 0.5125 \longrightarrow 0.5328, \qquad L: 0.6685 \longrightarrow 0.6296\]

backprop は勾配を求める手順。求めた勾配を使ってパラメータを動かすのは勾配降下法

5個は同じ時点の勾配で更新する

  • まず更新前のパラメータで、5個すべての勾配を計算する
  • その後、5個をまとめて更新する
  • \(\alpha_1\) を先に更新し、その新しい値で \(\alpha_2\) の勾配を計算し直すわけではない
更新前の θ
   ↓ forward
同じ θ で計算した L
   ↓ backward
同じ時点の勾配 ∇L
   ↓ θ ← θ − η∇L
更新後の θ

ノート

表の「更新前」列は全行で同じ時点、「更新後」列も全行で同じ時点

検算：機械に「微分の定義」でやらせる

  • 微分の定義 \(\dfrac{L(\theta + \varepsilon) - L(\theta)}{\varepsilon}\) で、手計算を検算できる（数値微分）
import numpy as np

x1, x2, y = 1.0, 0.5, 1.0

def loss(a1, a2, b, w, c):
    z = a1*x1 + a2*x2 + b
    h = max(0.0, z)
    u = w*h + c
    p = 1 / (1 + np.exp(-u))
    return -np.log(p)

params = dict(a1=0.3, a2=-0.2, b=0.1, w=0.5, c=-0.1)
base = loss(**params)
print(f"L = {base:.4f}")

eps = 1e-6
for name in params:
    shifted = dict(params)
    shifted[name] += eps
    grad = (loss(**shifted) - base) / eps
    print(f"∂L/∂{name} = {grad:.4f}")
L = 0.6685
∂L/∂a1 = -0.2438
∂L/∂a2 = -0.1219
∂L/∂b = -0.2438
∂L/∂w = -0.1463
∂L/∂c = -0.4875
  • 表示した小数第4位まで手計算と一致（a1: −0.2438, a2: −0.1219, b: −0.2438, w: −0.1463, c: −0.4875）
  • ではなぜ実用で数値微分を使わない？ — パラメータ100万個なら loss を100万回計算することになる。backprop は1往復で全部出る

数値微分と backprop は用途が違う

方法 全勾配を得る計算量の目安 得意な用途
数値微分 パラメータごとに往路を再計算 少数の勾配の検算
backprop 往路1回＋復路1回 実際の学習
  • パラメータが5個なら数値微分でも困らない
  • 100万個なら、1ステップごとに約100万回の往路は現実的でない
  • backprop は途中の計算を使い回すため、全パラメータを一度の復路で扱える

数値微分は「答え合わせ」、backprop は「毎回の学習」に使う

何層でも同じ漸化式を繰り返す

  • 1ユニットずつ書くと、復路は同じ形の繰り返し：

\[\delta^{(\ell)} = \delta^{(\ell+1)} \cdot w^{(\ell+1)} \cdot f'(z^{(\ell)})\]

  • 「次の層の \(\delta\) に、重みと活性化の微分を掛ける」
  • 各層のパラメータの勾配は \(\delta^{(\ell)} \times\)（その層への入力）
  • 行列でまとめた形は、次の NumPy 実装で対応させる

名前の由来

誤差（\(\delta\)）が出力から入力へ逆向きに伝播していく — 誤差逆伝播法（backpropagation）。仕組みの正体は連鎖律の使い回し。

枝分かれした勾配は合流すると足し算

中間の値 \(h\) が2つの計算に使われる場合：

\[u_1=w_1h,\qquad u_2=w_2h,\qquad L=L(u_1,u_2)\]

連鎖律は2経路ぶんを足す：

\[ \frac{\partial L}{\partial h} =\frac{\partial L}{\partial u_1}\frac{\partial u_1}{\partial h} +\frac{\partial L}{\partial u_2}\frac{\partial u_2}{\partial h} \]

  • 直列につながる経路では掛け算
  • 枝分かれして同じ値へ戻る経路では足し算
  • 複数ユニットや複雑なネットワークも、この2規則で処理できる

復路で効いてくる設計たち

  • 往路の途中の値（\(z, h\)）を保存しておくのは復路で使うため
    • ディープラーニングがメモリを食う理由のひとつ
  • \(\mathrm{ReLU}'(z)\) は 1 か 0。正側の経路では活性化関数による縮小がない
    • シグモイドを中間に使うと微分が最大 0.25 — 層を重ねるたびに勾配が薄まる（勾配消失（vanishing gradient））
    • 中間層に ReLU が選ばれる大きな理由

ヒント

右の図は活性化関数の微分だけを掛け続けた比較。実際の勾配には各層の重みも掛かる。 それでも、シグモイドを中間層で重ねると勾配が小さくなりやすいことが分かる。

まとめ

  • 勾配の計算は、連鎖律で出力側から掛けて貯める — 展開不要、微分は部品ごと
  • 手計算1往復：forward の値を保存 → \(\delta\) を逆流させて各勾配
  • 数値微分は検算には最高、実用には遅すぎる
  • 何層でも同じ漸化式 \(\delta^{(\ell)} = \delta^{(\ell+1)} w^{(\ell+1)} f'(z^{(\ell)})\) が回るだけ

次回予告

部品はすべて揃った。次回、NumPy だけで多層ネットワークを組み、 講義の初回に見せた「機械が自力で見つけた曲がる境界」を自分のコードで再現する。

練習問題

以下の問題を手計算で解き、数値微分で検算せよ。

ネットワークは本編と同じ5パラメータ。値だけ差し替える：

記号 値
入力 \(x_1, x_2\) \(0.5,\; 1.0\)
正解 \(y\) \(0\)（Sea bass）
\(\alpha_1, \alpha_2, b\) \(0.4,\; 0.3,\; -0.1\)
\(w, c\) \(-0.5,\; 0.2\)

問題1：1往復せよ

  1. 往路：\(z, h, u, p, L\) を順に求めよ（正解が \(y=0\) なので \(L = -\log(1-p)\)）
  2. 復路：\(\delta_{\text{out}}\) と \(\delta_{\text{mid}}\)、そして5つの勾配をすべて求めよ
  3. 本編の数値微分のコードに値を差し替えて、検算せよ

問題2：入力を \(x_1 = -1.0,\; x_2 = 0.5\) に変えて、もう1往復せよ

ヒント：\(\sigma(0) = 0.5\)、\(\sigma(0.2) \approx 0.5498\)。この2つしか使わない。

ヒント

手計算の答えは捨てないこと。PyTorch入門の練習問題で、この数値がそのまま再登場する。

問題1の解答例

往路

\[z = 0.4 \times 0.5 + 0.3 \times 1.0 - 0.1 = 0.4\] \[h = \mathrm{ReLU}(0.4) = 0.4, \qquad u = -0.5 \times 0.4 + 0.2 = 0\] \[p = \sigma(0) = 0.5, \qquad L = -\log(0.5) = 0.6931\]

ちょうどコイン投げ。正解は 0 なので、\(p\) をもっと下げたい。

復路

\[\delta_{\text{out}} = p - y = 0.5\] \[\frac{\partial L}{\partial w} = 0.5 \times 0.4 = 0.2, \qquad \frac{\partial L}{\partial c} = 0.5\]

\[\delta_{\text{mid}} = 0.5 \times (-0.5) \times 1 = -0.25\]

\[\frac{\partial L}{\partial \alpha_1} = -0.25 \times 0.5 = -0.125, \qquad \frac{\partial L}{\partial \alpha_2} = -0.25, \qquad \frac{\partial L}{\partial b} = -0.25\]

  • \(w\) が負なので、中間層へ戻る \(\delta\) は符号が反転する。重みが復路の向きと大きさも決める。

数値微分で検算

解答例を見る 
import numpy as np

x1, x2, y = 0.5, 1.0, 0.0

def loss(a1, a2, b, w, c):
    z = a1*x1 + a2*x2 + b
    h = max(0.0, z)
    u = w*h + c
    p = 1 / (1 + np.exp(-u))
    return -np.log(1 - p)   # 正解が y=0 のとき

params = dict(a1=0.4, a2=0.3, b=-0.1, w=-0.5, c=0.2)
base = loss(**params)
print(f"L = {base:.4f}")

eps = 1e-6
for name in params:
    shifted = dict(params)
    shifted[name] += eps
    grad = (loss(**shifted) - base) / eps
    print(f"∂L/∂{name} = {grad:.4f}")
L = 0.6931
∂L/∂a1 = -0.1250
∂L/∂a2 = -0.2500
∂L/∂b = -0.2500
∂L/∂w = 0.2000
∂L/∂c = 0.5000

問題2の解答例

往路

\[z = 0.4 \times (-1.0) + 0.3 \times 0.5 - 0.1 = -0.35\] \[h = \mathrm{ReLU}(-0.35) = 0, \qquad u = 0.2, \qquad p = \sigma(0.2) \approx 0.5498\]

復路

\[\delta_{\text{out}} = 0.5498, \qquad \frac{\partial L}{\partial w} = 0.5498 \times h = 0, \qquad \frac{\partial L}{\partial c} = 0.5498\]

\[\delta_{\text{mid}} = 0.5498 \times (-0.5) \times \mathrm{ReLU}'(-0.35) = 0\] \[\Rightarrow\quad \frac{\partial L}{\partial \alpha_1} = \frac{\partial L}{\partial \alpha_2} = \frac{\partial L}{\partial b} = 0\]

この魚は、ネットの左半分に何も教えない

重要

\(z < 0\) では \(\mathrm{ReLU}'(z) = 0\) なので、そこより前の勾配はすべて 0 になる。 勾配が届くのは \(c\) だけ（\(w\) も \(h = 0\) に掛けられて消えた）。
