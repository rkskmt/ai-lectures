ここまでの道具

  • 勾配降下法：傾きの逆方向に少しずつ進んで、損失が最小の場所を探す
  • ただしここまで最小化したのは、\(f(x) = x^2 - 4x + 3\) のような簡単な関数だった

今回の目的

勾配降下法でデータに合う直線を求める

モデルとは

  • これまでの「モデル」を、2つの部分に分けてみる：

  • 空欄の名前がパラメータ
  • 空欄をデータで埋めるのが学習
  • 今回もまず、人間が形を決める

回帰問題とは

回帰（Regression）

目的変数（target variable）\(t\) と説明変数（explanatory variable）\(x\) の関係を関数（モデル）で表し、その関数をデータから推定する手法

\[t = f(x) + \varepsilon \qquad (\varepsilon \text{：誤差})\]

  • 目的変数は通常、連続値（continuous value）
  • 統計的には、\(x\) が与えられたときの \(t\) の条件付き期待値（conditional expectation） \(E[t \mid x]\) を推定することにあたる（二乗誤差の場合）
分類 回帰
出力 グループ名 連続値
例 この魚は Salmon この魚は約 1900g

今回の問題：体長から重さを予測する

  • 魚の体長（cm）を、新しい特徴量として使う
  • 体長を測るだけで重さが分かれば、秤に乗せる手間が省ける
魚データの定義（クリックして展開） 
import numpy as np

要するに

  • 直線でいけそう
    • 直線のパラメータは傾き \(a\) と切片 \(b\) の2個
  • どの直線が「一番良い」かを測る物差しが要る

損失関数：二乗誤差（MSE）

  • MSE（Mean Squared Error / 平均二乗誤差）：各魚の「予測と実際のズレ」を二乗して平均した値

\[L(a, b) = \frac{1}{N} \sum_{i} \left( \underbrace{a x_i + b}_{\text{予測}} - \underbrace{t_i}_{\text{実際}} \right)^2\]

  • 誤差を 2 乗して集めた SSE を、点の数で割った平均
  • 全魚のズレを1本のベクトルと見ると、MSE はそのノルム（norm・ベクトルの長さ）の2乗を \(N\) で割ったもの

損失関数は MSE だけではない

  • ズレの絶対値の平均でも「小さいほど良い直線」は測れる
    • MAE（Mean Absolute Error / 平均絶対誤差）
  • ズレの4乗の平均でもよい
    • 「ズレが減るほど小さくなる」関数なら損失関数の候補になれる
  • 今回 MSE を選ぶ理由は微分のしやすさ
    • 絶対値は 0 のところで折れていて微分できない
    • 二乗なら微分がきれい
  • MAE を損失にした回帰は外れ値に強い回帰で扱う

勾配を手で出す

\(L\) を \(a\) と \(b\) でそれぞれ微分する（合成関数の微分）：

\[\frac{\partial L}{\partial a} = \frac{2}{N} \sum_i (a x_i + b - t_i) \, x_i \qquad \frac{\partial L}{\partial b} = \frac{2}{N} \sum_i (a x_i + b - t_i)\]

  • 構造は単純：「予測と正解の差」を入力の大きさに応じて配る
  • あとは勾配降下法に渡すだけ：

\[a \leftarrow a - \alpha \frac{\partial L}{\partial a}, \qquad b \leftarrow b - \alpha \frac{\partial L}{\partial b}\]

数式とコードの名前

  • 数式では学習率を \(\alpha\) と書く
  • コードでは、learning rateを略して lr と書く

勾配降下法で傾きと切片を求める

  • スケールを揃えてから更新する
    • 学習率を1つで済ませるため
x = (lengths - lengths.mean()) / lengths.std()   # 標準化した体長
t = (weights - weights.mean()) / weights.std()   # 標準化した重さ

a, b = 0.0, 0.0   # 直線はゼロからスタート
lr = 0.1          # Learning rate alpha in the equation

for i in range(1, 101):
    pred   = a * x + b
    grad_a = 2 * np.mean((pred - t) * x)
    grad_b = 2 * np.mean(pred - t)
    a -= lr * grad_a
    b -= lr * grad_b
    if i in (1, 3, 10, 50, 100):
        print(f"更新 {i:3d}回 | a={a:.4f} b={b:.4f} | MSE={np.mean((a*x+b - t)**2):.4f}")

答え合わせ：厳密解と比べる

  • np.polyfit(x, t, d)：二乗誤差が最小になる \(d\) 次式の係数を求める関数

モデルを複雑にしてみる

モデルを曲線にする

  • 回帰式は直線だけでなく、曲線でもよい：多項式回帰（polynomial regression）

\[\text{予測} = w_1 x + w_2 x^2 + \cdots + w_d x^d + b\]

  • \(x^2, x^3, \ldots\) を新しい特徴量として作れば、道具は線形回帰のまま
  • 次数 \(d\) がモデルの複雑さを決める

質問

次数を 1 → 3 → 9 と上げていくと、訓練誤差とテスト誤差はそれぞれどうなる？

# 体長を標準化してから多項式を当てはめる（そのまま9乗すると計算が不安定になる）

要するに

  • 訓練誤差は下がり続け、テスト誤差は桁違いに増える（縦軸は対数）
  • 決定木の深さで見た過学習が、回帰でもまったく同じ形で現れた
  • 深さを制限したように、複雑さを抑える道具が要る
    • 回帰では正則化

正則化：大きい係数に罰金を払わせる

  • 曲線が大きく振れる原因は、巨大な係数
coef1 = np.polyfit(z_train, t_train, 1)
coef9 = np.polyfit(z_train, t_train, 9)
print("次数1の係数の最大絶対値:", f"{np.abs(coef1[:-1]).max():,.0f}")   # [:-1] は切片を除く
print("次数9の係数の最大絶対値:", f"{np.abs(coef9[:-1]).max():,.0f}")
次数1の係数の最大絶対値: 336
次数9の係数の最大絶対値: 36,757
  • そこで、損失に「係数の大きさ」へのペナルティを課すことを考える：

\[L = \mathrm{MSE} + \lambda \sum_j w_j^2\]

  • 正則化（regularization）：モデルの複雑さを抑える罰則を損失に足す手法
  • MSE だけではなく、係数の大きさも loss に入れ込む
  • \(\lambda\)（ラムダ）：罰金の強さ
    • \(\lambda = 0\) なら今までどおりの MSE

正則化の実装：自作の勾配降下法に罰金を足す

  • 自作した勾配降下法に、罰金の項を足す
  • 罰金 \(\lambda \sum w^2\) の微分は \(2\lambda w\)
    • 各係数の勾配に足せばよい
# 特徴量 x, x², …, x⁹ も自分で作る（列が x^1 〜 x^9 の配列）
P_train = x_train.reshape(-1, 1) ** np.arange(1, 10)   # 形 (10, 9)
P_test  = x_test.reshape(-1, 1)  ** np.arange(1, 10)
mu, sd  = P_train.mean(axis=0), P_train.std(axis=0)
P_train = (P_train - mu) / sd                  # スケールを揃える（いつもの）
P_test  = (P_test  - mu) / sd
t_mean, t_std = t_train.mean(), t_train.std()
tt = (t_train - t_mean) / t_std                # 重さも標準化

lam  = 0.1        # 罰金の強さ λ
w, b = np.zeros(9), 0.0
lr   = 0.01
for i in range(10_000):
    pred   = P_train @ w + b
    grad_w = np.array([2 * np.mean((pred - tt) * P_train[:, d]) for d in range(9)]) \
             + 2 * lam * w                     # ← MSEの勾配 ＋ 罰金の勾配
    grad_b = 2 * np.mean(pred - tt)
    w -= lr * grad_w
    b -= lr * grad_b

test_pred = (P_test @ w + b) * t_std + t_mean  # 元の単位（g）に戻す
train_pred = (P_train @ w + b) * t_std + t_mean
coef_own = np.polyfit(z_train, train_pred, 9)  # 前のスライドと同じ多項式の係数に直す
print("係数の最大絶対値:", f"{np.abs(coef_own[:-1]).max():,.0f}")
print("テストMSE:", f"{np.mean((test_pred - t_test) ** 2):,.0f}")
係数の最大絶対値: 320
テストMSE: 3,427

結果

  • 係数の最大絶対値が桁違いに小さくなった
    • 罰金が係数の増大を抑えた
  • 勾配降下法のループは自作のコードと同じ形
    • 増えたのは + 2 * lam * w の項だけ

L2正則化とリッジ回帰

  • \(\lambda \sum_j w_j^2\) の形の罰金：L2正則化（L2 regularization）
  • L2正則化を加えた線形回帰は、歴史的な経緯でリッジ回帰（Ridge regression）と呼ばれる
    • モデルは線形回帰のままで、変わるのは損失だけ
  • NN でも同じ道具がそのまま使われる（NN での名前は weight decay）

深さの制限も、広い意味での正則化

  • 次数9の曲線の MSE を、罰金のあり・なしで比べる

罰金なし 0 \(4.4 \times 10^{14}\)

広い意味での正則化

  • 訓練誤差を犠牲にして、汎化誤差を下げる工夫
    • 罰金：訓練MSEは上がり、テストMSEは下がった
    • 決定木の深さの制限：訓練データでの成績は満点でなくなる

Tweak 罰金の強さで曲線が変わる

チェックポイント

  • 0.0：テストMSEは悪化する
    • ただし正則化なしの厳密解ほどは大きく外れない
    • 勾配降下法を1万回で打ち切ること自体が、係数の増大を抑える弱いブレーキになる
  • 10：曲線はほぼまっすぐ寝て、訓練MSEまで悪化する
    • 罰金が強すぎて、訓練データに合わなくなる
  • ちょうど良い \(\lambda\) は問題ごとに違う
    • 訓練MSEでは選べない（\(\lambda\) を小さくするほど下がるので、必ず \(\lambda = 0\) が選ばれる）
    • テストMSEでも選ばない（テストデータを確認してからモデルを調整しない）
    • 訓練データの中の交差検証で選ぶ（検証用に別のデータを用意しなくてよい）

まとめ

  • 回帰：\(t = f(x) + \varepsilon\) の \(f\) をデータから推定する手法
    • 損失は二乗誤差（MSE）（微分しやすさで選ぶ）
  • 勾配降下法で求めた傾きと切片は、最小二乗法の厳密解と一致
  • 多項式回帰：特徴量に \(x^2, x^3, \ldots\) を足せば道具は線形回帰のまま
  • 過学習は回帰でも起きる：次数を上げると訓練誤差は下がり、テスト誤差は桁違いに増える
  • 正則化（regularization）：大きい係数に罰金を課し、曲線の振れを抑える

練習問題：2点のデータから直線を求める

データは2点だけ：\((x_1, t_1) = (-1, 0)\)、\((x_2, t_2) = (1, 2)\)。 直線 \(ax + b\) を勾配降下法で求める。初期値 \(a = 0, b = 0\)、学習率 \(\alpha = 0.1\)。手計算とPythonコードの両方で解け。

  1. 勾配の式に代入して、\(\dfrac{\partial L}{\partial a}\) と \(\dfrac{\partial L}{\partial b}\) を求めよ
  2. 更新を3回、手計算で示せ
  3. 同じ更新をコードで100回繰り返し、np.polyfit の答えと比較せよ

ヒント：2点を通る直線は \(y = x + 1\)。つまり答えは \(a = 1, b = 1\) になるはず。

練習問題の解答例

準備（\(a = 0, b = 0\) での勾配）

予測は2点とも 0。差（予測 − 実際）は \((0 - 0, 0 - 2) = (0, -2)\)：

\[\frac{\partial L}{\partial a} = \frac{2}{2}\left[ 0 \times (-1) + (-2) \times 1 \right] = -2\] \[\frac{\partial L}{\partial b} = \frac{2}{2}\left[ 0 + (-2) \right] = -2\]

  • 反復1
  • 反復2
  • 反復3

\[a = 0 - 0.1 \times (-2) = 0.2, \qquad b = 0 - 0.1 \times (-2) = 0.2\]

差は \((b - a,\; a + b - 2) = (0, -1.6)\)：

\[\frac{\partial L}{\partial a} = \frac{2}{2}\left[0 + (-1.6)\right] = -1.6, \qquad a = 0.2 + 0.16 = 0.36\]

\(b\) もまったく同じ計算で \(b = 0.36\)。

差は \((0, -1.28)\)、勾配はどちらも \(-1.28\)：

\[a = 0.36 + 0.128 = 0.488, \qquad b = 0.488\]

\(a\) と \(b\) が揃って \(1\) に近づいていく。
