  • ではどの直線が「一番良い」？ — 良さを測る物差しが要る

損失関数：二乗誤差（MSE）

  • 各魚について「予測と実際のズレ」を測り、二乗して平均する

\[L(a, b) = \frac{1}{N} \sum_{i} \left( \underbrace{a x_i + b}_{\text{予測}} - \underbrace{t_i}_{\text{実際}} \right)^2\]

  • MSE（Mean Squared Error / 平均二乗誤差）と呼ぶ
  • 全魚のズレを1本のベクトルと見ると、MSE はそのノルム（norm・ベクトルの長さ）の2乗を \(N\) で割ったもの

損失関数は MSE だけではない

  • ズレの絶対値の平均でも「小さいほど良い直線」は測れる — MAE（Mean Absolute Error / 平均絶対誤差）
  • ズレの4乗の平均でもよい。「ズレが減るほど小さくなる」関数なら損失関数の候補になれる
  • 今回 MSE を選ぶ理由は微分のしやすさ：絶対値は 0 のところで折れていて微分できない。二乗なら微分がきれい

勾配を手で出す

\(L\) を \(a\) と \(b\) でそれぞれ微分する（合成関数の微分）：

\[\frac{\partial L}{\partial a} = \frac{2}{N} \sum_i (a x_i + b - t_i) \, x_i \qquad \frac{\partial L}{\partial b} = \frac{2}{N} \sum_i (a x_i + b - t_i)\]

  • 構造は単純：「予測と正解の差」を入力の大きさに応じて配る
  • あとは勾配降下法に渡すだけ：

\[a \leftarrow a - \alpha \frac{\partial L}{\partial a}, \qquad b \leftarrow b - \alpha \frac{\partial L}{\partial b}\]

数式とコードの名前

  • 数式では、勾配降下法の回と同じく学習率を \(\alpha\) と書く
  • コードでは、learning rateを略して lr と書く

勾配降下法で fit する

  • スケールを揃えてから（クラスタリングの回の教訓。学習率を1つで済ませるため）
x = (lengths - lengths.mean()) / lengths.std()   # 標準化した体長
t = (weights - weights.mean()) / weights.std()   # 標準化した重さ

a, b = 0.0, 0.0   # 直線はゼロからスタート
lr = 0.1          # Learning rate alpha in the equation

for i in range(1, 101):
    pred   = a * x + b
    grad_a = 2 * np.mean((pred - t) * x)
    grad_b = 2 * np.mean(pred - t)
    a -= lr * grad_a
    b -= lr * grad_b
    if i in (1, 3, 10, 50, 100):
        print(f"更新 {i:3d}回 | a={a:.4f} b={b:.4f} | MSE={np.mean((a*x+b - t)**2):.4f}")

モデルを複雑にしてみる

モデルを曲線にする

  • 回帰式は直線だけでなく、曲線でもよい：多項式回帰

\[\text{予測} = w_1 x + w_2 x^2 + \cdots + w_d x^d + b\]

  • \(x^2, x^3, \ldots\) を新しい特徴量として作れば、道具は線形回帰のまま
  • 次数 \(d\) がモデルの複雑さを決める

質問

次数を 1 → 3 → 9 と上げていくと、訓練誤差とテスト誤差はそれぞれどうなる？

  • 深さを制限したように、複雑さを抑える道具が要る — 回帰では正則化

正則化：大きい係数に罰金を払わせる

  • 暴れている曲線の正体は、巨大な係数
plain = make_pipeline(PolynomialFeatures(9), StandardScaler(), LinearRegression())
plain.fit(X_train, y_train)
print("次数9の係数の最大絶対値:", f"{np.abs(plain[-1].coef_).max():,.0f}")
次数9の係数の最大絶対値: 204,382
  • そこで、損失に「係数の大きさ」へのペナルティを課すことを考える：

\[L = \mathrm{MSE} + \lambda \sum_j w_j^2\]

  • このように、モデルの暴走を抑える罰則を損失に足す手法を正則化（regularization）という
  • MSE だけではなく、係数の大きさも loss に入れ込む
  • \(\lambda\)（ラムダ）が罰金の強さ。\(\lambda = 0\) なら今までどおりの MSE

正則化の実装：自作の勾配降下法に罰金を足す

  • sklearn には任せない。冒頭で自作した勾配降下法に、罰金の項を足すだけ
  • 罰金 \(\lambda \sum w^2\) の微分は \(2\lambda w\)。各係数の勾配に足せばよい
# 特徴量 x, x², …, x⁹ も自分で作る（列が x^1 〜 x^9 の配列）
P_train = X_train ** np.arange(1, 10)          # 形 (10, 9)
P_test  = X_test  ** np.arange(1, 10)
mu, sd  = P_train.mean(axis=0), P_train.std(axis=0)
P_train = (P_train - mu) / sd                  # スケールを揃える（いつもの）
P_test  = (P_test  - mu) / sd
t_mean, t_std = y_train.mean(), y_train.std()
tt = (y_train - t_mean) / t_std                # 重さも標準化

lam  = 0.1        # 罰金の強さ λ
w, b = np.zeros(9), 0.0
lr   = 0.01
for i in range(10_000):
    pred   = P_train @ w + b
    grad_w = np.array([2 * np.mean((pred - tt) * P_train[:, d]) for d in range(9)]) \
             + 2 * lam * w                     # ← MSEの勾配 ＋ 罰金の勾配
    grad_b = 2 * np.mean(pred - tt)
    w -= lr * grad_w
    b -= lr * grad_b

test_pred = (P_test @ w + b) * t_std + t_mean  # 元の単位（g）に戻す
print("係数の最大絶対値:", f"{np.abs(w * t_std).max():,.0f}")
print("テストMSE:", f"{np.mean((test_pred - y_test) ** 2):,.0f}")
係数の最大絶対値: 74
テストMSE: 3,427
  • 係数の最大絶対値は 204,382 → 74。罰金が係数の暴走を実際に止めた
  • 勾配降下法のループは冒頭の自作コードと同じ形。増えたのは + 2 * lam * w の1項だけ

（参考）世間での呼び名

\(\lambda \sum w^2\) 型の罰金は L2正則化、L2正則化つきの線形回帰はリッジ回帰（Ridge regression）と呼ばれる。sklearn にも Ridge として入っている。

過学習スレッド、完結

引き（決定木のあやしい満点）→ 正体（訓練とテストのギャップ）→ 対抗手段（複雑さの制御と正則化）。 NN でも同じ道具（L2正則化＝weight decay）がそのまま使われる。

ここで観察

  • 0.0：テストMSEは 3,427 → 21,721 と6倍以上悪化。ただし厳密解の大暴れ（929万）までは行かない。勾配降下法を1万回で打ち切ること自体が、暴走を途中で止める弱いブレーキになっているため
  • 10：曲線はほぼまっすぐ寝て、訓練MSEまで悪化する（3,585 → 35,665）。罰金が強すぎて、訓練データに合わせる力が負けた
  • ちょうど良い \(\lambda\) は問題ごとに違う。訓練データではなくテストデータの MSE で選ぶ

まとめ

  • 回帰：数値を予測する。損失は二乗誤差（MSE）— 微分しやすさで選ぶ
  • 勾配降下法で fit を自作 → sklearn と完全一致
  • 多項式回帰：特徴量に \(x^2, x^3, \ldots\) を足せば道具は線形回帰のまま
  • 過学習は回帰でも起きる：次数を上げると訓練誤差↓・テスト誤差爆発
  • 正則化（regularization）：大きい係数に罰金 → 暴れる曲線を手なずける

練習問題

以下の問題を手計算とPythonコードの両方で解け。

問題1：魚2匹だけの世界で fit する

データは2点だけ：\((x_1, t_1) = (-1, 0)\)、\((x_2, t_2) = (1, 2)\)。 直線 \(ax + b\) を勾配降下法で fit する。初期値 \(a = 0, b = 0\)、学習率 \(\alpha = 0.1\)。

  1. 勾配の式に代入して、\(\dfrac{\partial L}{\partial a}\) と \(\dfrac{\partial L}{\partial b}\) を求めよ
  2. 更新を3回、手計算で示せ
  3. 同じ更新をコードで100回繰り返し、sklearn の答えと比較せよ

ヒント：2点を通る直線は \(y = x + 1\)。つまり答えは \(a = 1, b = 1\) になるはず。

問題1の解答例

準備（\(a = 0, b = 0\) での勾配）

予測は2点とも 0。差（予測 − 実際）は \((0 - 0, 0 - 2) = (0, -2)\)：

\[\frac{\partial L}{\partial a} = \frac{2}{2}\left[ 0 \times (-1) + (-2) \times 1 \right] = -2\] \[\frac{\partial L}{\partial b} = \frac{2}{2}\left[ 0 + (-2) \right] = -2\]

  • 反復1
  • 反復2
  • 反復3

\[a = 0 - 0.1 \times (-2) = 0.2, \qquad b = 0 - 0.1 \times (-2) = 0.2\]

差は \((b - a,\; a + b - 2) = (0, -1.6)\)：

\[\frac{\partial L}{\partial a} = \frac{2}{2}\left[0 + (-1.6)\right] = -1.6, \qquad a = 0.2 + 0.16 = 0.36\]

\(b\) もまったく同じ計算で \(b = 0.36\)。

差は \((0, -1.28)\)、勾配はどちらも \(-1.28\)：

\[a = 0.36 + 0.128 = 0.488, \qquad b = 0.488\]

\(a\) と \(b\) が揃って \(1\) に近づいていく。
