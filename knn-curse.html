いちばん近い 1 匹で予測する

  • 新しい魚から、訓練データの全部の魚までの距離を測る
  • いちばん近い魚の種類を返す
def predict_nearest(Z_train, y_train, z):
    dist = np.sqrt(((Z_train - z) ** 2).sum(axis=1))    # 新しい魚 z から、訓練データ全部までの距離
    return y_train[dist.argmin()]                       # いちばん近い魚の種類（1=Salmon, 0=Sea bass）

pred = []
for z in Z_test:                                        # テストデータの 24 匹を、1 匹ずつ予測する

近い k 匹の多数決にする（k-NN）

  • いちばん近い 1 匹だけに聞くと、その 1 匹に答えが左右される
  • 近い順に k 匹を選び、多いほうの種類を答えにする
  • k-NN（k-nearest neighbors / k 近傍法）と呼ぶ
    • 最近傍法は、k = 1 の k-NN
def predict_knn(Z_train, y_train, z, k):
    dist    = np.sqrt(((Z_train - z) ** 2).sum(axis=1)) # 新しい魚 z から、訓練データ全部までの距離
    nearest = np.argsort(dist)[:k]                      # 距離が小さい順に並べた番号の、先頭 k 個
    votes   = y_train[nearest]                          # 近い k 匹の種類（1=Salmon, 0=Sea bass）
    return int(votes.sum() > k / 2)                     # Salmon が半分より多ければ 1

k = 5
pred = []
for z in Z_test:
    pred.append(predict_knn(Z_train, y_train, z, k))
pred = np.array(pred)

print(f"k = {k}: 当たった数 {np.sum(pred == y_test)} / {len(y_test)}")
print(f"5 匹目の予測: {predict_knn(Z_train, y_train, Z_test[4], k)}（正解は {y_test[4]}）")

特徴量の数を増やすのが最強か？

  • 重さだけでサーモンを分類すると、ある程度できた

質問

特徴量（次元）を増やし続けると何が起きるか？

次元の呪い

次元の呪い（Curse of Dimensionality）

  • データの次元が増えるにつれて、空間が指数的に広くなり、データがまばらになる現象
  • 2次元で十分だったサンプル数が、10次元では全く足りなくなる
  • 高次元空間は私たちの直感とは全く異なる振る舞いをする

ノート

名づけたのは Richard Bellman（動的計画法の発明者）。 現代機械学習でも最重要トピックの一つ。

準備

  • 各特徴量は 0〜1 に正規化してあるとする（各軸の長さ＝1）
  • そこに100個の点をランダムにばらまく
  • 点は「行＝点、列＝特徴量」の配列で持つ
  • まず特徴量2個（2次元）で、散布図に描く

距離を測る

  • 2点間の距離は、ユークリッド距離で測る
  • ある点から、ほかの99個の点までの距離をすべて測る
  • その中でいちばん小さいものが、いちばん近い点（最近傍, nearest neighbor）までの距離
def nearest_distance(P, i):
    dist = np.sqrt(((P - P[i]) ** 2).sum(axis=1))   # 点 i から全部の点までの距離
    dist[i] = np.inf                                # 自分自身は除外
    return dist.min()                               # いちばん近い点までの距離

print(f"点 0 からいちばん近い点まで: {nearest_distance(P, 0):.3f}")

nn = []
for i in range(len(P)):                             # 100個の点すべてで測る
    nn.append(nearest_distance(P, i))
print(f"100個の中央値: {np.median(nn):.3f}")
点 0 からいちばん近い点まで: 0.070
100個の中央値: 0.042

結果

  • 点 0 からいちばん近い点までの距離は 0.070（図の赤い線）
  • この距離は、100個の点それぞれに1つずつ決まる
    • その中央値 0.042 を、点の混み具合を表す値として使う
  • 軸の長さ 1 に対して 0.04 ほどなので、2次元ではすぐ隣に点がある

質問：いちばん近い点まで、どれくらい？

質問

特徴量を増やして 10次元 にしたら、いちばん近い点までの距離はいくつになると思う？

（各軸の長さは1のまま。点の数も100個のまま）

for d in [1, 2, 3, 5, 10, 20]:
    P  = rng.random((100, d))                   # 100個の点を d 次元にばらまく
    nn = []
    for i in range(len(P)):                     # 「距離を測る」と同じ測り方

    print(f"{d:2d}次元: いちばん近い点まで {np.median(nn):.3f}")

 2次元: いちばん近い点まで 0.042

結果

  • 10次元で 0.70、20次元では 1.2。もはや「お隣さん」は存在しない
  • 同じ100点なのに。なぜこんなことが起きるのか、2つの理由を見る

なぜ？　その1：真ん中に居続けられない

  • ある点が、ある軸で「中央寄り」（その軸の中央50%）に入る確率は \(\dfrac{1}{2}\)
  • \(d\) 次元で「全部の軸で中央寄り」でいられる確率は：

\[\left(\frac{1}{2}\right)^d \qquad \text{1次元: } 50\% \quad \text{3次元: } 12.5\% \quad \text{10次元: } 0.1\% \quad \text{20次元: } 100万分の1\]

要するに

  • ほぼすべての点が、どこかの軸では中央から外れている
  • 各軸を半分に切ると、空間は \(2^d\) 個の区画に分かれる（20次元で約105万個）
    • 100個の点は、ほぼ1個ずつ別の区画に入る
    • データは100万個の区画に散り散りになる

なぜ？　その2：「ご近所」の箱が各軸の大半にまたがる

  • 「近い点」を頼りにする手法のつもりで、周りのデータの1%を「ご近所」として集めたい
  • 各軸を割合 \(r\) だけ切り取った箱は、全体の体積の \(r^d\) を占める（点が一様なら、データの割合も \(r^d\)）。1% 集めるには：

\[r = 0.01^{1/d}\]

要するに

  • 10次元では、たった1%の「ご近所」を集めるのに各軸の63%を見渡す必要がある
  • それはもう「近所」ではない
    • 「近い点どうしは似ている」を前提にする手法（k-means など）は、前提が成り立ちにくくなる

「近い」と「遠い」の区別が弱くなる

  • k-means をはじめ、多くの手法は距離に依存している
  • 点を一様にばらまき、ある1点からほかの2000点までの距離を測る
  • 距離のばらつきを、変動係数（coefficient of variation）＝ 標準偏差 ÷ 平均 で比べる

dims    = [1, 2, 3, 5, 10, 20, 50, 100]

for d in dims:
    pts   = rng.random((2000, d))
    query = rng.random(d)
    dists = np.sqrt(((pts - query) ** 2).sum(axis=1))
    cv_list.append(dists.std() / dists.mean())

plt.figure(figsize=(7, 3.5))
plt.plot(dims, cv_list, "o-", color="#e74c3c")
plt.xlabel("次元数 d")

変動係数が 0 に近づく

  • 距離のばらつきが、平均距離に比べて小さくなる
  • 「最も近い点」と「最も遠い点」の距離の比が 1 に近づく
    • 差そのものは縮まらないが、距離全体が大きくなるので「近い」の意味が薄れる

データが疎になる（Sparsity）

  • 同じサンプル数でも、次元が増えると空間が広くなりすぎる

ノート

密度を保つには、次元数に対して指数的にサンプルを増やす必要がある。 1次元で10点あれば足りた密度を10次元で保つには、\(10^{10}\) 点が必要という計算になる。

ばらまいた点で、最近傍法を試す

  • 100個の点に、正解のラベルを付ける
    • 座標の合計が 1 より大きければ True、そうでなければ False（図の点線が境目）
  • 各点のラベルを、最近傍法で予測する
    • 訓練データとテストデータには分けず、自分以外の 99個の中から、いちばん近い点を探す
  • 100個の点すべてで予測し、当たった割合を出す
def nearest_index(P, i):
    dist = np.sqrt(((P - P[i]) ** 2).sum(axis=1))   # 点 i から全部の点までの距離
    dist[i] = np.inf                                # 自分自身は除外
    return dist.argmin()                            # いちばん近い点の番号

P     = rng.random((100, 2))                        # 100個の点を 2 次元にばらまく
label = P.sum(axis=1) > 1                           # 正解のラベル：座標の合計が 1 より大きいか

hit = []
for i in range(len(P)):                             # 100個の点すべてで予測する
    j = nearest_index(P, i)                         # 点 i にいちばん近い点

実用への影響

問題 原因
モデルの精度が上がらない データが疎でパターンが見えない
過学習しやすくなる データに比べてパラメータが多すぎる
計算コストが増大 距離計算などが次元数に比例して重くなる
可視化できない 4次元以上は図に描けない

次元の呪いへの対処

  1. 特徴量選択（feature selection）：重要な特徴量だけを残す
  2. 次元削減（dimensionality reduction）：情報を保ったまま次元を圧縮する
  3. 正則化（regularization）：過学習を防ぐ（線形回帰の回で扱う）

（参考）次元を減らす：PCA

  • 特徴量どうしが似た動きをしていれば、情報をほとんど失わずに、特徴量の数を減らせる
    • 例：魚の体長と重さは、ほぼ同じ情報
  • 主成分分析（PCA, Principal Component Analysis）：データのばらつきが大きい方向を、新しい軸に取り直す方法
  • 次元削減と PCAで扱う

まとめ

  • k-NN：近い k 匹の多数決で分類する
    • 学習では境界を作らず、訓練データをそのまま取っておく
    • 距離を使うので、先に標準化する
  • k はハイパパラメータ：k = 1 は訓練データで必ず当たるが、テストデータでは下がる（過学習）
  • 次元の呪い：次元が増えると空間が広くなり、「近い」と「遠い」の区別が弱くなる
    • いちばん近い点が遠くなり、最近傍法が当たらなくなる
    • 点を増やしても、次元が高いと追いつかない

練習問題：k で答えが変わる

種類の分かっている点が 5 個ある：\(A(3, 4)\) は Sea bass、\(B(1, 3)\) は Salmon、\(C(3, 1)\) は Salmon、\(D(6, 7)\) は Sea bass、\(E(7, 6)\) は Sea bass。新しい点 \(N(3, 3)\) の種類を k-NN で予測せよ。1〜3 は手計算、4 はPythonコードで解け。

  1. \(N\) から \(A\)〜\(E\) までの距離を、それぞれ求めよ
  2. \(k = 1\) のときの予測を答えよ
  3. \(k = 3\) と \(k = 5\) のときの予測を、それぞれ答えよ
  4. Python：本編の predict_knn で、\(k = 1, 3, 5\) の予測を表示せよ（標準化はしない）

練習問題の解答例

  • 距離は \(A\) が 1、\(B\) が 2、\(C\) が 2、\(D\) が 5、\(E\) が 5
    • 例：\(D\) は \(\sqrt{(6 - 3)^2 + (7 - 3)^2} = \sqrt{25} = 5\)
  • \(k = 1\)：いちばん近いのは \(A\) なので、Sea bass
  • \(k = 3\)：近い 3 個は \(A\)、\(B\)、\(C\)。Salmon が 2 個なので、Salmon
  • \(k = 5\)：5 個全部で多数決。Sea bass が 3 個なので、Sea bass
