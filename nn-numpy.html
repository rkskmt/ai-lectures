講義の初回に見せた「機械が自力で見つけた曲がる境界」を、 NNの計算をNumPyだけで書いたコードで再現する。 使う部品は、線形変換・ReLU・交差エントロピー・backprop・勾配降下法。

実装の見取り図

  1. データとパラメータの形を決める
  2. forward で200匹まとめて確率を出す
  3. 交差エントロピーで平均損失を計算する
  4. backward で同じ形の勾配を求める
  5. 勾配降下法でパラメータを更新する
  6. これを繰り返し、決定境界を観察する

まず1匹・中間1個なら前回の式

\[ \begin{aligned} z_i &= x_{i1}\alpha_1+x_{i2}\alpha_2+b\\ h_i &= \mathrm{ReLU}(z_i)\\ u_i &= h_iw+c\\ p_i &= \sigma(u_i) \end{aligned} \]

  • さらに中間の変換を1個ではなく16個並べたい
  • 二重ループでも書けるが、NumPyでは行列積にすると短く速く書ける

設計：ループを行列に畳む

Forward：4行

import numpy as np

def forward(X, W1, b1, w2, c2):
    Z = X @ W1 + b1          # 線形変換（全変換まとめて）
    H = np.maximum(0, Z)     # ReLU（折る）
    u = H @ w2 + c2          # 出力層（重み付きでまとめる）
    p = 1 / (1 + np.exp(-u)) # シグモイド（確率に）
    return Z, H, u, p
  • ロジスティック回帰の回の forward と見比べると、スカラーが行列になっただけ
  • \(Z, H\) も返すのは、復路（backprop）で使うから（前回の伏線）

Forward の各行で形を追う

コード 入力の形 出力の形
Z = X @ W1 + b1 (200,2) @ (2,16) (200,16)
H = np.maximum(0, Z) (200,16) (200,16)
u = H @ w2 + c2 (200,16) @ (16,) (200,)
p = sigmoid(u) (200,) (200,)
  • ReLUとシグモイドは要素ごとの計算なので、形を変えない
  • 出力層で16個を重み付きで足すため、最後は各魚1個の確率になる

ヒント

実装中に迷ったら、値より先に .shape を表示する。形の不一致は多くのバグを早く見つける

200匹の損失を平均する

1匹ごとの2クラス交差エントロピーを \(\ell_i\) とすると：

\[ \ell_i=-\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right],qquad L=\frac{1}{N}\sum_{i=1}^{N}\ell_i \]

たとえば2匹で、\((y_1,p_1)=(1,0.8)\)、\((y_2,p_2)=(0,0.3)\) なら：

\[L=\frac{-\log(0.8)-\log(0.7)}{2}\approx0.290\]

  • 正解1の魚は \(p\)、正解0の魚は \(1-p\) を評価する
  • 平均を取るため、backward の先頭にも / N が現れる

1匹の式を200匹・16変換へ広げる

計算 1匹・中間1個 行列でまとめたコード 出力の形
出力側の差 \(p-y\) (p - y) / N (200,)
出力重みの勾配 \(h\,\delta_{\rm out}\) H.T @ delta_out (16,)
中間へ戻る値 \(\delta_{\rm out}w\,\mathrm{ReLU}'(z)\) np.outer(delta_out, w2) * (Z > 0) (200, 16)
第1層の勾配 \(x\,\delta_{\rm mid}\) X.T @ D_mid (2, 16)
  • / N は、200匹の損失を平均したことに対応
  • np.outer は、各魚の \(\delta_{\rm out}\) と16個の重みを総当たりで掛ける

\[D_{\mathrm{mid}}[i,k] =\delta_{\mathrm{out}}[i]\,w_2[k],\mathbf{1}(Z[i,k]>0)\]

新しい微分ではない。前回のスカラー式を、全データ・全変換ぶん同時に計算している

Backward も出力側から順に計算する

  1. (p - y) / N で出力側の \(\delta\) を作る
  2. H を掛け、出力層の勾配を取り出す
  3. w2 と ReLU の微分を掛け、中間へ戻す
  4. X を掛け、第1層の勾配を取り出す

コードの上から下が、そのまま計算グラフを右から左へ戻る順番

Backward：前回の漸化式をそのまま書く

import numpy as np

def backward(X, y, Z, H, w2, p):
    N = len(X)
    delta_out = (p - y) / N                    # 出力層の誤差（p - y）
    g_w2 = H.T @ delta_out                     # ∂L/∂w2 = δ_out × 入力(H)
    g_c2 = delta_out.sum()                     # ∂L/∂c2 = δ_out
    D_mid = np.outer(delta_out, w2) * (Z > 0)  # δ_mid = δ_out・w2・ReLU'(Z)
    g_W1 = X.T @ D_mid                         # ∂L/∂W1 = δ_mid × 入力(X)
    g_b1 = D_mid.sum(axis=0)                   # ∂L/∂b1 = δ_mid
    return g_W1, g_b1, g_w2, g_c2
  • 1行ずつ、前回の手計算と完全に対応している
    • (p - y)：シグモイド＋交差エントロピーの打ち消し
    • * (Z > 0)：\(\mathrm{ReLU}'\) は 1 か 0
    • 「\(\delta\) × その層への入力」が各勾配

勾配の形はパラメータの形と一致する

パラメータ パラメータの形 対応する勾配 勾配の形
W1 (2,16) g_W1 (2,16)
b1 (16,) g_b1 (16,)
w2 (16,) g_w2 (16,)
c2 スカラー g_c2 スカラー

だから、すべて同じ形で更新できる：

W1 -= lr * g_W1
b1 -= lr * g_b1
w2 -= lr * g_w2
c2 -= lr * g_c2

ノート

形が一致しなければ、どこかの転置・axis・行列積が間違っている可能性が高い

学習ループ：あとは勾配降下法

rng = np.random.default_rng(0)
hidden = 16
W1 = rng.normal(0, 1.0, (2, hidden))   # ランダム初期化（対称性を破る）
b1 = np.zeros(hidden)
w2 = rng.normal(0, 1.0, hidden)
c2 = 0.0
lr = 0.5

for i in range(1, 4001):
    Z, H, u, p = forward(X, W1, b1, w2, c2)
    g_W1, g_b1, g_w2, g_c2 = backward(X, y, Z, H, w2, p)
    W1 -= lr * g_W1
    b1 -= lr * g_b1
    w2 -= lr * g_w2
    c2 -= lr * g_c2

    if i in (1, 100, 500, 2000, 4000):
        _, _, _, p_log = forward(X, W1, b1, w2, c2)
        eps  = 1e-10
        loss = -np.mean(y * np.log(np.clip(p_log, eps, 1)) +
                        (1 - y) * np.log(np.clip(1 - p_log, eps, 1)))
        acc  = np.mean((p_log >= 0.5) == y)
        print(f"更新 {i:5d}回 | Loss: {loss:.4f} | 正答率: {acc:.1%}")

問題1：自作 backward を数値微分で検品する

自分の書いた backward が正しい保証はまだない。前回の検算法（数値微分）を、行列版にも適用せよ。

  1. ランダム初期化した直後のパラメータで、backward が返す勾配 g_W1[0, 0] を表示せよ
  2. W1[0, 0] だけを \(\varepsilon = 10^{-6}\) ずらして損失を再計算し、数値微分 \(\dfrac{L(W_1[0,0]+\varepsilon) - L(W_1[0,0])}{\varepsilon}\) を求めよ
  3. 2つが一致することを確かめよ

ヒント：損失（交差エントロピー）の計算は学習ループの中にある。関数に切り出すと楽。

問題1の解答例

解答例を見る 
def cross_entropy(X, y, W1, b1, w2, c2):
    _, _, _, p = forward(X, W1, b1, w2, c2)
    eps = 1e-10
    return -np.mean(y * np.log(np.clip(p, eps, 1)) +
                    (1 - y) * np.log(np.clip(1 - p, eps, 1)))

# ランダム初期化（学習前）
rng_check = np.random.default_rng(0)
W1c = rng_check.normal(0, 1.0, (2, 16)); b1c = np.zeros(16)
w2c = rng_check.normal(0, 1.0, 16); c2c = 0.0

# backprop の答え
Z, H, u, p = forward(X, W1c, b1c, w2c, c2c)
g_W1, _, _, _ = backward(X, y, Z, H, w2c, p)
print(f"backprop:  ∂L/∂W1[0,0] = {g_W1[0, 0]:.6f}")

# 数値微分の答え
eps = 1e-6
base = cross_entropy(X, y, W1c, b1c, w2c, c2c)
W1_shifted = W1c.copy()
W1_shifted[0, 0] += eps
num = (cross_entropy(X, y, W1_shifted, b1c, w2c, c2c) - base) / eps
print(f"数値微分:  ∂L/∂W1[0,0] = {num:.6f}")
backprop:  ∂L/∂W1[0,0] = -0.003024
数値微分:  ∂L/∂W1[0,0] = -0.003024
  • 表示桁で近い値になれば、少なくともこの成分の backprop は正しい
  • 実務のライブラリ開発でも、autograd の実装はこうやって数値微分と突き合わせてテストされている
