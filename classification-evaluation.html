何が問題か

  • モデルは、学習データの特徴を見てパラメータを調整する
  • その同じデータで採点すると、成績は高めに出やすい
  • 知りたいのは「学習データでの成績」ではない
  • 知りたいのは「実際に分類したいデータ（今後の魚）で同様の性能か」

要するに

新しい魚にも通用するかは、学習に使っていないデータで測るしかない

汎化（Generalization）

  • テスト勉強では問題を決め打ちできない
方法 内容 本当の実力？
暗記 去年の問題を全部覚える ✗ 今年の問題は解けない
理解 解き方を身に付ける ✓ 未知の問題にも対応できる

汎化とは

  • モデルが学習していないデータにも通用する能力のこと

すべてのデータで学習するという発想が誤り

訓練データとテストデータに分けよう

  • すべてで学習せずに検証用データを置いておこう
    • 訓練データ（学習に使用）
    • テストデータ（学習には使わず、性能検証にだけ使用）

テストデータの鉄則

テストデータを確認してからモデルを調整しない

  • 調整：閾値や木の深さなどを変えて、見せかけの性能を上げようとすること
  • テストデータは「見たことのない問題」を模擬するために残しておく
    • 学習と調整がすべて終わってから、一度だけ採点に使う
  • テスト勉強にたとえると、今年の問題を先に見てから対策するのと同じ
    • 点は上がるが、新しい問題を解く実力は全くの不明
      • 何もしていないのと同じ

ホールドアウト法（Hold-Out）

  • データの一部を、最初から学習用と評価用に分割

    • 最初に試す評価方法としてよく使う

過学習

境界線はどう「学習」されていたのか

  • 深さを変えた木の決定境界を、訓練データと一緒に描いてみる

無制限の木の境界にテストデータを重ねる

過学習（Overfitting）

  • 訓練データの細部（たまたまの並び・ノイズ）まで覚え込み、新しいデータで性能が落ちること
  • 数字での証拠は訓練とテストの成績のギャップ
  • 図での証拠は数匹のためだけの回廊・飛び地だらけの決定境界
  • モデルが複雑なほど（深い木・多すぎるパラメータ）起きやすい
状態 訓練データでの成績 テストデータでの成績
未学習（underfitting） 低い 低い
ちょうど良い 高い 高い
過学習（overfitting） ほぼ満点 低い

対策

  • モデルの複雑さを抑える（決定木なら深さを制限）
  • データを増やす
  • 過学習していることを検知する道具：交差検証（cross-validation）

交差検証

ホールドアウト法の問題点

  • ホールドアウト法はランダムに分割する
  • どのデータがテスト側に入るかで、成績が変わる
tree = DecisionTreeClassifier(max_depth=None)
idx = np.arange(len(y))
for i in range(5):
    np.random.shuffle(idx)                # 毎回ちがう並べ替えで分割し直す
    Xtr, ytr = X[idx][:96], y[idx][:96]   # 先頭96匹を訓練に
    Xte, yte = X[idx][96:], y[idx][96:]   # 残り24匹をテストに
    pred = tree.fit(Xtr, ytr).predict(Xte)   # fit の戻り値は学習済みモデルなので、続けて predict できる
    print(f"split {i + 1}  Precision: {precision_score(yte, pred):.3f}  Recall: {recall_score(yte, pred):.3f}")

データが少ないほど揺れが大きい

  • テストデータは24匹で、そのうち Salmon は12匹前後
    • Salmon 1匹の見逃しで Recall が約 8% 変わる
  • 1回だけの分割結果を、強く信じすぎない

k-fold 交差検証

  • データを k 個のグループ（fold）に分割する
  • k 回繰り返す：1つをテスト、残りを訓練に使う
  • k 個の成績の平均を最終スコアとする

cross_val_score で交差検証（Cross-Validation）

from sklearn.model_selection import cross_val_score

deep_tree_cv = DecisionTreeClassifier(max_depth=None)

# cv=5 で 5-fold。scoring で測る指標を選ぶ
recalls    = cross_val_score(deep_tree_cv, X, y, cv=5, scoring="recall")
precisions = cross_val_score(deep_tree_cv, X, y, cv=5, scoring="precision")

print("各 fold の Recall:   ", recalls.round(3))
print("各 fold の Precision:", precisions.round(3))
print(f"平均 Recall:    {recalls.mean():.3f}  (fold ごとのばらつき ±{recalls.std():.3f})")
print(f"平均 Precision: {precisions.mean():.3f}  (fold ごとのばらつき ±{precisions.std():.3f})")
各 fold の Recall:    [0.75  0.917 0.583 0.5   0.583]
各 fold の Precision: [0.643 0.647 0.636 0.625 0.467]
平均 Recall:    0.667  (fold ごとのばらつき ±0.149)
平均 Precision: 0.604  (fold ごとのばらつき ±0.069)

結果

  • 平均しても、満点の木の成績は満点よりずっと低い
  • 5回の平均なので、1回の分割よりも偶然に左右されにくい

cross_val_score の引数

  • 第1引数：モデル（fit 前でOK。内部で k 回 fit してくれる）
  • cv=k：k-fold の k を指定（よく使うのは 5 か 10）
  • scoring="recall"：測る指標の名前（"precision" も同様）
  • 返り値は k 個の成績の配列 → .mean() で平均、.std() でばらつき（標準偏差）

深さを変えた場合の Precision と Recall

depths = list(range(1, 13))

This is 過学習

  • 訓練の成績は、深くするほど 1.000 に近づく
  • テストの成績は満点に届かず、深い木ほど2本の線の差（ギャップ）が広がる
    • 暗記が進んでいるサイン

深さを選ぶのに、テストデータは使えない

  • 深さの曲線では、テストの成績が最も高い深さを読み取れる
  • その深さを「採用」すると、テストデータを見てモデルを調整したことになる
    • テストデータの鉄則に反する
  • 何が起きるか
    • 24匹でたまたま良かった深さを選んだだけかもしれない
    • 選んだ木をそのテストデータで採点しても、もう「初見の問題」の成績ではない
    • テストデータは、深さを選ぶ材料として使った時点で「見たことのある問題」になる

ポイント

  • 深さなど、モデルの選択の判断は訓練データのみから
  • テストデータは、選び終えたあとに一度だけ使用

訓練データの中で交差検証して深さを選ぶ

  • 深さ（ハイパーパラメータ）は評価関数で決定（レストラン向けは Precision、缶詰工場向けは Recall）
  • ここでは高級レストラン向け（Sea bass の混入を避けたい）として、Precision で選ぶ
sel_depths = list(range(1, 11))
cv_precisions = []
for d in sel_depths:
    tree = DecisionTreeClassifier(max_depth=d)
    # 訓練データだけで 5-fold 交差検証し、平均 Precision を記録する
    cv_precisions.append(cross_val_score(tree, X_train, y_train, cv=5, scoring="precision").mean())

best_depth = sel_depths[int(np.argmax(cv_precisions))]   # 最大値の位置（0始まり）を深さ（1始まり）に直す
print(f"平均 Precision が最大の深さ: {best_depth}")
平均 Precision が最大の深さ: 3

選んだ深さでテストデータを採点

# 選んだ深さで、訓練データ全体を学習し直す
best_tree = DecisionTreeClassifier(max_depth=best_depth).fit(X_train, y_train)
pred_test = best_tree.predict(X_test)
print(f"Precision {precision_score(y_test, pred_test):.3f}  Recall {recall_score(y_test, pred_test):.3f}")

Tweak 分割を変えて成績の揺れを見る

  • ホールドアウトのコードと交差検証のコードを書き換えて実行（続きのセルも実行）
やりたいこと コード
分割をやり直せ 書き換えずにもう一度実行
テストに半分回せ n_train = 96 → 60
10-fold にせよ cv=5 → cv=10

チェックポイント

  • 実行し直すたびに、テストの Precision と Recall が変わる
    • 同じモデルなのに、分割だけで成績が変わる
    • 1回の分割の数字には偶然が乗っているので、交差検証で平均を取る
  • n_train = 60 は訓練が60匹に減る
    • テストの魚が増えるぶん、学習に使える魚が減る（訓練とテストの取り分のトレードオフ）
  • cv=10 は、fold ごとのばらつき（±）が cv=5 より大きい
    • 1 fold のテストが12匹（Salmon 6匹）しかなく、魚1匹の重みが大きい
    • fold は細かくすればいいものでもない

まとめ

  • 訓練データで評価した成績は楽観的
    • 満点はむしろ過学習の疑い
  • 過学習：訓練データを暗記して、新しいデータで性能が落ちること
    • 証拠は訓練とテストの成績のギャップ（深さ無制限の決定木は、訓練では満点でもテストでは満点にならない）
    • 決定境界で見ると、数匹のためだけの回廊・飛び地として現れる
  • 汎化：未知データへの対応能力を測ることが本来の目的
  • ホールドアウト法：手軽だが分割次第で成績が揺れる
  • k-fold 交差検証：k 回の平均で安定した評価が得られる
  • 深さなどの選択：訓練データの中の交差検証で選び、テストデータは最後に一度だけ使う
手法 特徴
ホールドアウト 手軽。データが多いときに有効
k-fold 交差検証 安定。データが少ないときに特に有効

問題2：Recall で深さを選び直す

缶詰工場向け（Salmon の取りこぼしを避けたい）として、本編の訓練データ X_train, y_train とテストデータ X_test, y_test を使い、深さを Recall で選び直せ：

  1. 深さ 1〜10 の決定木それぞれについて、訓練データでの 5-fold 交差検証の平均 Recall を求めよ（深さごとに表示）
  2. 平均 Recall が最大の深さで訓練データ全体を学習し、テストデータで一度だけ Precision と Recall を求めよ
  3. 本編で Precision を使って選んだ深さと比べよ（両方の深さを表示）

問題1の解答例

混同行列（行＝正解、列＝予測）:

Salmon と予測 Sea bass と予測
正解 Salmon 8（TP） 2（FN）
正解 Sea bass 1（FP） 9（TN）

Precision: TP / (TP + FP) = 8 / 9 ≈ 0.89　　Recall: TP / (TP + FN) = 8 / 10 = 0.80

import numpy as np
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import cross_val_score
from sklearn.metrics import precision_score, recall_score

def choose_depth(scoring):
    """訓練データの 5-fold 交差検証で、平均スコアが最大の深さを返す"""
    depths = list(range(1, 11))
    means = []
    for depth in depths:
        tree = DecisionTreeClassifier(max_depth=depth)
        means.append(cross_val_score(tree, X_train, y_train, cv=5, scoring=scoring).mean())
        print(f"  depth {depth:2d}: mean {scoring} {means[-1]:.3f}")
    return depths[int(np.argmax(means))]     # 最大値の位置（0始まり）を深さ（1始まり）に直す

for scoring in ["recall", "precision"]:
    print(f"[{scoring} で選ぶ]")
    best_depth = choose_depth(scoring)
    best_tree = DecisionTreeClassifier(max_depth=best_depth).fit(X_train, y_train)
    pred_test = best_tree.predict(X_test)
    print(f"  best depth: {best_depth}  ->  test Precision {precision_score(y_test, pred_test):.3f}"
          f"  Recall {recall_score(y_test, pred_test):.3f}\n")
