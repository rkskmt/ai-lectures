適当に深さを決めて決定木で決定境界を作成

深さ＝ハイパパラメータ

決め方 決定木の例
ハイパパラメータ（hyperparameter） 学習の前に人が決める 何段まで分けるか（深さ max_depth）
パラメータ（parameter） 学習（fit）がデータから決める どこで分けるか（特徴量と閾値）
  • 決定木における深さ
    • ある階層での分割する閾値は fit が決定
      • パラメータ
    • 何段まで分けるかは人が決めた
      • ハイパパラメータ
        • hyper：上の（パラメータより上位のパラメータ）

ハイパパラメータはどう決めるべきなのか

  • 経験的に決めてしまう
  • 一つ一つ深さの異なる決定木をつくっていき、それぞれ評価して一番良いものとする
    • ただし、決定木の場合、深さをMAXにすれば最強の評価を得られる

過学習（Overfitting）

  • 学習用データの細部（たまたまの並び・ノイズ）まで覚え込み、新しいデータで性能が落ちること
  • モデルが複雑なほど（深い木・多すぎるパラメータ）起きやすい
状態 学習用データでの成績 本番のデータでの成績
未学習（underfitting） 低い 低い
ちょうど良い 高い 高い
過学習（overfitting） ほぼ満点 低い

対策

  • モデルの複雑さを抑える（決定木なら深さを制限）
  • データを増やす

【そもそも】すべてのデータで学習するという発想が誤り

  • 学習に使ったデータで採点すると、成績は高めに出る
    • fit はそのデータに合わせてパラメータを決めている
    • 深い木ほど高く出る
  • これでは深さを選べない
  • 知りたいのは、これから獲る魚での成績

ホールドアウト法（Hold-Out）

  • データを訓練データとテストデータに分ける
    • 訓練データ：学習に使う
    • テストデータ：学習には使わず、採点だけに使う
  • hold out：取っておく

テストデータの鉄則

テストデータを確認してからモデルを調整しない

  • 調整：ハイパパラメータ（木の深さなど）を変えること
  • テストデータは、学習と調整がすべて終わってから一度だけ採点に使う
  • 試験でいえば、今年の問題を先に見てから対策するのと同じ
    • 点は上がるが、実力は分からない

深さを変えて、訓練データとテストデータで採点する

import matplotlib.pyplot as plt
import japanize_matplotlib
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import precision_score, recall_score

depths = list(range(1, 13))
train_p, train_r, test_p, test_r = [], [], [], []

for d in depths:
    m = DecisionTreeClassifier(max_depth=d).fit(X_train, y_train)   # 訓練データだけで学習
    pred_train, pred_test = m.predict(X_train), m.predict(X_test)
    train_p.append(precision_score(y_train, pred_train))
    train_r.append(recall_score(y_train, pred_train))
    test_p.append(precision_score(y_test, pred_test))
    test_r.append(recall_score(y_test, pred_test))

fig, axes = plt.subplots(1, 2, figsize=(11, 3.8), sharey=True)
for ax, name, tr, te in zip(axes, ["Precision", "Recall"], [train_p, train_r], [test_p, test_r]):
    ax.plot(depths, tr, "o-", color="#2980b9", label="訓練データ")
    ax.plot(depths, te, "s-", color="#e74c3c", label="テストデータ")

axes[0].set_ylabel("成績"); axes[0].legend()

結局どのハイパパラメータにすればいいのか

テストの成績が一番いい深さを選ぶだけで十分だろうか？

  • 曲線を見ると、テストの成績が一番いい深さを選びたくなる
  • しかし、それではテストデータを使って深さを決めたことになる
    • 24匹でたまたま良かった深さを選ぶので、その成績は高めに出る
    • 学習に使ったデータで採点すると高めに出るのと同じ理屈
  • テストデータは、もう本番のデータの代わりにならない

ポイント

  • ハイパパラメータは、テストデータを使わずに選ぶ

汎化（Generalization）

  • 過学習を直し、学習に使っていないデータにも通用させること
  • 通常はテストデータの成績で測るしかない
  • 本当は、本番データをどれだけ良い感じで分類できるか を狙いたい
方法 内容 本当の実力？
暗記 去年の問題を全部覚える ✗ 今年の問題は解けない
理解 解き方を身に付ける ✓ 未知の問題にも対応できる

交差検証

検証データ（Validation Data）

  • 訓練データをさらに分け、一部を検証データにする
    • ハイパパラメータの比較に使う
    • テストデータは最後の採点まで使わない
  • validation：検証、正しいと確かめること

1回分けるだけでは揺れる

  • 訓練データ96匹を、学習用76匹と検証データ20匹にランダムに分ける
  • 深さ3の木を検証データで採点し、分け方を変えて5回くり返す
tree = DecisionTreeClassifier(max_depth=3)
idx = np.arange(len(y_train))
for i in range(5):
    np.random.shuffle(idx)                                  # 毎回ちがう並べ替えで分け直す
    X_fit, y_fit = X_train[idx][:76], y_train[idx][:76]     # 先頭76匹で学習
    X_val, y_val = X_train[idx][76:], y_train[idx][76:]     # 残り20匹が検証データ
    pred = tree.fit(X_fit, y_fit).predict(X_val)   # fit の戻り値は学習済みモデルなので、続けて predict できる
    print(f"split {i + 1}  Precision: {precision_score(y_val, pred):.3f}  Recall: {recall_score(y_val, pred):.3f}")

  • これでは深さを変えて成績が変わっても、深さのせいか分け方のせいか分からない

k-fold 交差検証（k-fold Cross-Validation）

  • 訓練データを k 個のグループ（fold）に分割する
    • fold：〜重、〜個に分けた1組（twofold＝2重）
  • k 回繰り返す：1つを検証データ、残りを学習に使う
  • k 個の成績の平均を最終スコアとする
  • cross-validation：cross＝交差、validation＝検証

5-fold 交差検証で採点する

  • 訓練データに、順に 0〜4 のグループ番号を振る（訓練データはすでにランダムな順）
  • グループ i を検証データ、残りを学習に使い、5回採点する
  • 5回の成績を平均する
import numpy as np
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import precision_score, recall_score

k = 5
group = np.arange(len(y_train)) % k        # 0, 1, 2, 3, 4, 0, 1, ... と番号を振る

precisions, recalls = [], []
for i in range(k):
    tree = DecisionTreeClassifier(max_depth=3)
    tree.fit(X_train[group != i], y_train[group != i])     # グループ i 以外で学習
    pred = tree.predict(X_train[group == i])               # グループ i（検証データ）で採点
    precisions.append(precision_score(y_train[group == i], pred))
    recalls.append(recall_score(y_train[group == i], pred))
    print(f"group {i}  Precision: {precisions[-1]:.3f}  Recall: {recalls[-1]:.3f}")

print(f"平均 Precision: {np.mean(precisions):.3f}")
print(f"平均 Recall:    {np.mean(recalls):.3f}")

訓練データの中で交差検証して深さを選ぶ

  • 深さを比べる指標は用途で決める（レストラン向けは Precision、缶詰工場向けは Recall）
  • ここでは高級レストラン向け（Sea bass の混入を避けたい）として、Precision で選ぶ
  • 交差検証のコードを関数にまとめ、深さ 1〜10 で1回ずつ呼ぶ
def kfold_precision(depth, X, y, k):
    """深さ depth の木を k-fold 交差検証し、平均 Precision を返す"""
    group = np.arange(len(y)) % k      # 訓練データはすでにランダムな順なので、そのまま番号を振る
    precisions = []
    for i in range(k):
        tree = DecisionTreeClassifier(max_depth=depth)
        tree.fit(X[group != i], y[group != i])
        pred = tree.predict(X[group == i])
        precisions.append(precision_score(y[group == i], pred))
    return np.mean(precisions)

sel_depths = list(range(1, 11))
cv_precisions = []
for d in sel_depths:
    cv_precisions.append(kfold_precision(d, X_train, y_train, 5))   # 訓練データだけで交差検証

best_depth = sel_depths[int(np.argmax(cv_precisions))]   # 最大値の位置（0始まり）を深さ（1始まり）に直す
print(f"平均 Precision が最大の深さ: {best_depth}")
平均 Precision が最大の深さ: 4

  • ホールドアウトのコードと交差検証のコードを書き換えて実行（続きのセルも実行）

チェックポイント

  • 実行し直すたびに、テストの Precision と Recall が変わる
    • 同じモデルなのに、分割だけで成績が変わる
    • 1回の分割の数字には偶然が乗っているので、交差検証で平均を取る
  • n_train = 60 は訓練が60匹に減る
    • テストの魚が増えるぶん、学習に使える魚が減る（訓練とテストの取り分のトレードオフ）
  • k = 10 は、グループごとの成績の幅が k = 5 より広がることが多い
    • 1グループの検証データが9〜10匹（Salmon 5匹前後）しかなく、魚1匹の重みが大きい
    • グループは細かくすればいいものでもない

まとめ

  • 訓練データで評価した成績は楽観的
  • 汎化：学習に使っていないデータにも通用すること
  • 過学習：訓練データを暗記して、新しいデータで性能が落ちること
    • 証拠は訓練とテストの成績のギャップ
  • パラメータ：学習（fit）がデータから決める
  • ハイパパラメータ：学習の前に人が決める（決定木の深さなど）
  • ホールドアウト法：手軽だが分割次第で成績が揺れる
  • k-fold 交差検証：k 回の平均で揺れを抑える
  • ハイパパラメータの選択：訓練データの中の交差検証（検証データ）で選び、テストデータは最後に一度だけ使う

import numpy as np
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import precision_score, recall_score

def kfold_recall(depth, X, y, k):
    """深さ depth の木を k-fold 交差検証し、平均 Recall を返す"""
    group = np.arange(len(y)) % k      # 訓練データはすでにランダムな順なので、そのまま番号を振る
    recalls = []
    for i in range(k):
        tree = DecisionTreeClassifier(max_depth=depth)
        tree.fit(X[group != i], y[group != i])
        pred = tree.predict(X[group == i])
        recalls.append(recall_score(y[group == i], pred))
    return np.mean(recalls)

depths = list(range(1, 11))
cv_recalls = []
for d in depths:
    cv_recalls.append(kfold_recall(d, X_train, y_train, 5))
    print(f"depth {d:2d}: mean Recall {cv_recalls[-1]:.3f}")

best_depth_r = depths[int(np.argmax(cv_recalls))]
tree_r = DecisionTreeClassifier(max_depth=best_depth_r).fit(X_train, y_train)
pred_test = tree_r.predict(X_test)
print(f"test Precision {precision_score(y_test, pred_test):.3f}  Recall {recall_score(y_test, pred_test):.3f}")
print(f"Recall で選んだ深さ: {best_depth_r}")
print(f"Precision で選んだ深さ（本編）: {best_depth}")
