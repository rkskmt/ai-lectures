質問

ラベルなしのこの図、何個のグループに見える？

クラスタリング（clustering）とは

  • データを似たもの同士のグループ（クラスタ、cluster）にまとめる
  • 正解ラベルがなくても、データの分布から自然なグループを見つける
  • 用途の例
    • 顧客をグループに分けて施策を変える
    • 大量の文書を話題ごとに整理する
    • 「どのグループにも入らない点」を見つける（異常検知）

k-means アルゴリズム

k-means の手順

前提：クラスタ数 \(k\) を先に決めておく（ハイパーパラメータ）。今回は \(k = 2\) とする

入力：データ点の集合

出力：各点の所属クラスタの番号、重心 \(k\) 個

  1. \(k\) 個の重心（centroid）をランダムに配置（データ点から \(k\) 個選ぶ）
  2. 各データ点を最も近い重心のクラスタに割り当てる
  3. 各クラスタの重心を再計算（クラスタ内の平均点）
  4. 重心が変化しなくなるまで 2〜3 を繰り返す

ノート

「assign（割り当て）→ update（更新）→ 繰り返し」 たったこれだけのシンプルな構造。この4手順を順に自分で書いていく

パラメータとハイパーパラメータ

  • 手順を動かす前に人が決める値と、手順がデータから決める値を区別する
手順を動かす前に人が決める 手順がデータから決める
呼び方 ハイパーパラメータ（hyperparameter） パラメータ（parameter）
k-means クラスタ数 \(k\) 重心 \(k\) 個の位置
決定木（前回まで） 木の深さ 分岐の閾値
  • ハイパーパラメータの決め方は、手順の外で別に考える
    • 決定木の深さは訓練データの中で交差検証して選んだ
    • \(k\) の決め方は後半のエルボー法で扱う

    • 番号を並べ替えて先頭 \(k\) 個を取る

手順2：1つの点に一番近い重心を選ぶ

  • 「近い」を数で決める：2点間のユークリッド距離（Euclidean distance）

\[d = \sqrt{(\Delta \text{輝度})^2 + (\Delta \text{重さ})^2}\]

\(\Delta\) は点と重心の差。\(d\) がその点と重心の距離

  • 距離の計算を関数にし、まず0番目の点について \(k\) 個の重心までの距離を求める
  • 距離が最小の重心の番号が、この点の所属クラスタ
def distance(x1, y1, x2, y2):                      # 2点 (x1, y1) と (x2, y2) の距離
    return np.sqrt((x1 - x2)**2 + (y1 - y2)**2)    # np.sqrt は平方根

dists = []
for j in range(k):
    dists.append(distance(brightness[0], weights[0], cx[j], cy[j]))   # 0番目の点から重心 j まで
    print(f"重心 {j} までの距離: {dists[j]:.1f}")
print(f"一番近い重心: {np.argmin(dists)}")         # 最小値の位置（番号）

手順2：すべての点に一番近い重心の番号を付ける（assign）

  • 前ページの計算を80個の点すべてで繰り返し、点ごとに一番近い重心の番号を記録する
  • 手順4で何度も使うので関数にする
def assign(xs, ys, cx, cy):                                  # 点の座標 xs, ys と重心の座標 cx, cy
    labels = []
    for i in range(len(xs)):                                 # i 番目の点
        dists = []
        for j in range(len(cx)):
            dists.append(distance(xs[i], ys[i], cx[j], cy[j]))   # 重心 j までの距離
        labels.append(np.argmin(dists))                      # 一番近い重心の番号
    return np.array(labels)

手順3：重心をメンバーの平均の位置へ動かす（update）

  • クラスタごとにメンバーの点を取り出し、輝度の平均と重さの平均を新しい重心にする
  • メンバーが1つもないクラスタは平均が計算できないので、重心を動かさない
def update(xs, ys, labels, cx, cy):
    new_cx, new_cy = [], []
    for j in range(len(cx)):
        mask = labels == j                       # クラスタ j の点だけ True
        if np.sum(mask) > 0:
            new_cx.append(xs[mask].mean())       # メンバーの横の座標の平均
            new_cy.append(ys[mask].mean())       # メンバーの縦の座標の平均
        else:                                    # メンバーが1つもなければ動かさない
            new_cx.append(cx[j])
            new_cy.append(cy[j])
    return np.array(new_cx), np.array(new_cy)

new_cx, new_cy = update(brightness, weights, labels, cx, cy)
print("更新前 輝度:", cx.round(1), " 重さ:", cy.round(1))
print("更新後 輝度:", new_cx.round(1), " 重さ:", new_cy.round(1))

手順4：重心が動かなくなるまで繰り返す

  • 手順2（assign）と手順3（update）を交互に繰り返す
  • 更新しても重心が1つも動かなければ終了（念のため上限は100周）
for step in range(1, 101):
    labels = assign(brightness, weights, cx, cy)                    # 手順2
    new_cx, new_cy = update(brightness, weights, labels, cx, cy)    # 手順3
    if np.all(new_cx == cx) and np.all(new_cy == cy):               # 全要素が等しい → 重心が動かなかった
        print(f"{step} 周目で重心が動かなくなった")

これは失敗

  • 境界は横一直線で、重さだけで上下に輪切りにしている
  • 輝度は結果にまったく効いていない

上手くいかなかった理由（スケールの相違）

  • k-means は手順2の距離だけでグループを決める
  • 重さの差は数百 g、輝度の差はせいぜい数ポイント

\[\text{距離}^2 = \underbrace{(\Delta \text{輝度})^2}_{\sim 10} + \underbrace{(\Delta \text{重さ})^2}_{\sim 100{,}000}\]

  • 距離の計算が重さに支配され、輝度はあってもなくても同じだった

スケールの罠は常に存在

  • 単位もケタも違う特徴量をそのまま距離計算に入れてはいけない
  • 距離を使う手法（k-means、k-NN など）を使うときに起こる

単位がちがうものを比べる：基準化

  • スケールが違うデータ同士は比較しづらい
  • そこで、ユニバーサルなスケールにそろえる
  • これが標準化（standardization）（または基準化）

\[z = \frac{x - \text{平均}}{\rule{0pt}{1em}\text{標準偏差}}\]

  • \(x\) ：元データ
  • \(z\) ：単位のない z スコア（z-score）という値
  • 基準化するとデータも平均 0、標準偏差 1 になる
    • 平均を引くと、新しい平均は 0 になる
      • 全体の平行移動なので散らばりは変わらない
    • 標準偏差で割ると、散らばり（標準偏差）も同じ数で割られて 1 になる
      • （参考）標準偏差とは、同じ形の計算：画像の座標の正規化
  • 例えば、輝度の \(z = 1.5\) と重さの \(z = 1.5\) は、どちらも「平均より標準偏差 1.5 個分大きい」で同じ

身近な基準化：偏差値

  • テストの難易度は毎回ちがうので、素点は回をまたいで比べられない
  • 点を基準化し、見やすいように 10 倍して 50 を足したものが偏差値

\[\text{偏差値} = 50 + 10 \times \frac{\text{点} - \text{平均}}{\rule{0pt}{1em}\text{標準偏差}} = 50 + 10z\]

どの回も平均 50、標準偏差 10 になる

要するに

  • 点数の分布が正規分布（normal distribution）に近ければ、偏差値から「上位何%か」が決まる
    • 偏差値 60（\(z = 1\)）は上位 15.9%、およそ 6 人に 1 人
    • 偏差値 72（\(z = 2.2\)）は上位 1.4%、およそ 70 人に 1 人
  • この対応は回がちがっても変わらないので、回をまたいで比べられる

実際に標準化をしてみる

  • 輝度と重さのそれぞれで「平均を引いて、標準偏差で割る」（さっきの \(z\) を別々に計算）
  • どちらも平均 0、標準偏差 1 になる
z_brightness = (brightness - brightness.mean()) / brightness.std()   # 輝度の z

手順1〜4 を関数にまとめる

  • 標準化したデータでもう一度回すので、手順を関数にする
  • 手順1 と 手順2〜4 は別の関数にする
    • ランダムなのは手順1だけ
    • 手順2〜4 は、同じ初期重心から始めれば毎回同じ答えになる
def init_centroids(xs, ys, k):                             # 手順1：ランダムな k 個の点を初期重心に
    idx = np.arange(len(xs))
    np.random.shuffle(idx)
    return xs[idx[:k]], ys[idx[:k]]

def kmeans(xs, ys, cx, cy):                                # 手順2〜4：初期重心 cx, cy から始める
    for step in range(100):
        labels = assign(xs, ys, cx, cy)                    # 手順2
        new_cx, new_cy = update(xs, ys, labels, cx, cy)    # 手順3
        if np.all(new_cx == cx) and np.all(new_cy == cy):  # 手順4：動かなくなったら終了
            break
        cx, cy = new_cx, new_cy
    return labels, cx, cy

結果の良さを数で測る：SSE（誤差の二乗和）

  • 各点の誤差を 1 つの数にまとめる
  • 誤差を 2 乗して全部足す
    • 2 乗するのは、大きな誤差を重く数えるため（誤差 10 の点 1 個は、誤差 1 の点 100 個ぶん）
    • 小さいほど塊がきつい
  • この合計を SSE（Sum of Squared Errors / 誤差の二乗和） と呼ぶ（クラスタリングでは「クラスタ内二乗和」とも）

\[\text{SSE} = \sum_{\text{全点}} (\text{誤差})^2 = \sum_{\text{全点}} (\text{自分の重心までの距離})^2\]

def sse(xs, ys, labels, cx, cy):
    total = 0.0
    for j in range(len(cx)):
        mask = labels == j                                               # クラスタ j の点だけ True
        total += np.sum((xs[mask] - cx[j])**2 + (ys[mask] - cy[j])**2)  # 重心までの距離の2乗を合計
    return total

（参考）平均が誤差の二乗和を最小にする理由

1つのクラスタのメンバー \(x_1, \ldots, x_n\)（1次元で考える）と重心 \(m\) について、\(\sum_i (x_i - m)^2\) を \(m\) で微分して 0 と置く： \[-2\sum_i (x_i - m) = 0 \;\Rightarrow\; m = \frac{1}{n}\sum_i x_i\]

止まった所が全体で最小とは限らない：ローカルミニマム

ローカルミニマム

  • 手順2と手順3ではもう SSE が下がらないのに、別の所にもっと SSE の小さい答えがある点をローカルミニマム（local minimum / 局所的最小値）と呼ぶ
    • まわりでは一番小さいが、全体で一番小さいとは限らない
  • 全体で一番小さい所はグローバルミニマム（global minimum / 大域的最小値）

k-means が止まった所はローカルミニマムかもしれず、どこで止まるかは手順1の出発点しだい

  • 1回の k-means は初期値しだい。そこで初期値を変えて決めた回数だけ回し、SSE が最小の結果だけを残す
  • この作戦をランダムリスタート（random restart）と呼ぶ
def kmeans_best(xs, ys, k, n_init=10):
    best_score = None
    for trial in range(n_init):
        cx, cy = init_centroids(xs, ys, k)               # 毎回ちがうランダムな初期値
        labels, cx, cy = kmeans(xs, ys, cx, cy)
        score = sse(xs, ys, labels, cx, cy)
        if best_score is None or score < best_score:    # これまでの最小より小さければ入れ替え
            best_score, best_labels, best_cx, best_cy = score, labels, cx, cy
    return best_labels, best_cx, best_cy

def distance(x1, y1, x2, y2):
    return np.sqrt((x1 - x2)**2 + (y1 - y2)**2)

def assign(xs, ys, cx, cy):
    labels = []
    for i in range(len(xs)):
        dists = []
        for j in range(len(cx)):
            dists.append(distance(xs[i], ys[i], cx[j], cy[j]))
        labels.append(np.argmin(dists))
    return np.array(labels)

def update(xs, ys, labels, cx, cy):
    new_cx, new_cy = [], []
    for j in range(len(cx)):
        mask = labels == j
        if np.sum(mask) > 0:
            new_cx.append(xs[mask].mean())
            new_cy.append(ys[mask].mean())
        else:
            new_cx.append(cx[j])
            new_cy.append(cy[j])
    return np.array(new_cx), np.array(new_cy)

def init_centroids(xs, ys, k):
    idx = np.arange(len(xs))
    np.random.shuffle(idx)
    return xs[idx[:k]], ys[idx[:k]]

def kmeans(xs, ys, cx, cy):
    for step in range(100):
        labels = assign(xs, ys, cx, cy)
        new_cx, new_cy = update(xs, ys, labels, cx, cy)
        if np.all(new_cx == cx) and np.all(new_cy == cy):
            break
        cx, cy = new_cx, new_cy
    return labels, cx, cy

def sse(xs, ys, labels, cx, cy):
    total = 0.0
    for j in range(len(cx)):
        mask = labels == j
        total += np.sum((xs[mask] - cx[j])**2 + (ys[mask] - cy[j])**2)
    return total

def kmeans_best(xs, ys, k, n_init=10):
    best_score = None
    for trial in range(n_init):
        cx, cy = init_centroids(xs, ys, k)
        labels, cx, cy = kmeans(xs, ys, cx, cy)
        score = sse(xs, ys, labels, cx, cy)
        if best_score is None or score < best_score:
            best_score, best_labels, best_cx, best_cy = score, labels, cx, cy
    return best_labels, best_cx, best_cy

問題1：k-means を手で1周回す

4点だけの世界：\(A(0, 0)\)、\(B(0, 2)\)、\(C(4, 0)\)、\(D(4, 2)\)。\(k = 2\)、最初の重心を \(M_1 = (0, 0)\)、\(M_2 = (0, 2)\) に置く。手計算で解け。

  2. update：割り当てから新しい重心を計算せよ
  3. assign が変わらなくなるまで繰り返せ。最終的なクラスタ分けと SSE（各点から自分の重心までの二乗距離の合計）を求めよ
  4. このデータの「自然な」分け方 \(\{A, B\}\) と \(\{C, D\}\) の SSE も計算し、3.の結果と比較せよ

問題2：初期重心を変えて SSE を比べる

  2. 初期重心を \((0, 0)\)、\((0, 2)\) にして kmeans を回し、所属クラスタと SSE を表示（手計算と一致するか確認）
  3. 初期重心を \((0, 0)\)、\((4, 0)\) に変えて再実行し、SSE を比較

問題1の解答例

1周目 assign：\(A \to M_1\)（距離0）、\(B \to M_2\)（距離0）、\(C \to M_1\)（\(4 < \sqrt{20}\)）、\(D \to M_2\)（\(4 < \sqrt{20}\)）

1周目 update：\(M_1 = \text{mean}(A, C) = (2, 0)\)、\(M_2 = \text{mean}(B, D) = (2, 2)\)

2周目 assign：\(A \to M_1\)（\(2 < 2\sqrt{2}\)）、\(B \to M_2\)、\(C \to M_1\)、\(D \to M_2\)。変化なし、収束

結果：\(\{A, C\}\) と \(\{B, D\}\)（上下の分割）。各点は重心から距離2なので

\[\text{SSE} = 2^2 \times 4 = 16\]

自然な分け方 \(\{A, B\}, \{C, D\}\)：重心は \((0,1)\) と \((4,1)\)、各点は距離1なので SSE\(= 1^2 \times 4 = 4\)。

結果

k-means の手順を正しく回したのに、SSE16 の悪い答えで止まった（最適は 4）。 assign → update は SSE を減らすことしかできず、最初の重心の置き方が悪いと抜け出せない。 本編の「最初の重心しだいで、おかしな答えに落ち着くことがある」を、4点で再現できた。

（参考）標準偏差とは

  • 標準偏差（standard deviation）：データが平均のまわりにどれだけ散らばっているかを表す1つの数
  • 例：8個の輝度 2, 4, 4, 4, 5, 5, 7, 9 で求める（平均は 40 / 8 = 5）
データ 1 2 3 4 5 6 7 8 合計
輝度 2 4 4 4 5 5 7 9 40
偏差（輝度 − 5） −3 −1 −1 −1 0 0 2 4 0
偏差の2乗 9 1 1 1 0 0 4 16 32
  1. 各データの輝度から平均を引く：偏差（deviation）
    • 偏差の合計は必ず 0 になる（プラスとマイナスが打ち消し合う）ので、そのまま平均しても散らばりは測れない
  2. 偏差を2乗して、マイナスを消す
  3. 2乗の平均を取る：分散（variance）\(= 32 / 8 = 4\)
  4. 分散の平方根を取る：標準偏差 \(= \sqrt{4} = 2\)
    • 2乗で変わった単位を、元のデータの単位に戻す

\[\text{標準偏差} = \sqrt{\,\text{偏差の2乗の平均}\,}\]

（参考）画像の座標の正規化

  • 横幅のちがう画像では、ピクセル座標のままだと位置を比べられない
    • ある x = 480 の点を考える
      • 横幅 1920 px の画像では左寄り
      • 横幅 640 px の画像では右寄り
  • そこで x 座標から中心を引き、横幅で割る：正規化（normalization）
    • y 座標も同じく、縦の中心を引いて縦幅で割る
    • どの画像も中心が 0、横幅も縦幅も 1（端は −0.5 と 0.5）になる

\[\text{正規化した座標} = \frac{x - \text{中心}}{\rule{0pt}{1em}\text{横幅}}\]

画像の座標は左上が原点（y は下向き）。赤い点は左右で同じ点、点線は中心

  • 横幅 1920 px なら \((480 - 960) / 1920 = -0.25\)
  • 横幅 640 px なら \((480 - 320) / 640 = 0.25\)
