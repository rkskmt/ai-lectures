NumPy 逆引き

やりたいことから書き方を探す

rkskmt

この資料の使い方

  • 見出しが「やりたいこと」になっている
  • コードは、そのまま貼れば1枚だけで動く
  • コードの下が実行結果
  • 画面の 検索 ボタンで、関数名（argsort など）からも探せる

配列をつくる

関数のために x 軸の点列を用意したい（linspace）

import numpy as np

x = np.linspace(0, 1, 5)   # 0 から 1 までを、等間隔に 5 個
print(x)
[0.   0.25 0.5  0.75 1.  ]

ノート

なめらかな曲線を描くときは、個数を 100 以上にする

range のような数列を array で用意したい（arange）

import numpy as np

print(np.arange(5))                # range(5) と同じ並び
print(np.arange(2.0, 4.0, 0.5))    # 開始、終了（含まない）、きざみ
[0 1 2 3 4]
[2.  2.5 3.  3.5]

ノート

range と違い、きざみに小数を使える

重みのために、初期値 0 の array を準備したい（zeros）

import numpy as np

w = np.zeros(3)        # 要素 3 個
print(w)

M = np.zeros((2, 3))   # 2行3列
print(M)
[0. 0. 0.]
[[0. 0. 0.]
 [0. 0. 0.]]

ノート

2次元にするときは、形を (行数, 列数) と括弧でまとめて渡す

実験用のデータとして、乱数の array を用意したい（default_rng）

import numpy as np

rng = np.random.default_rng(42)
X = rng.random((3, 2))          # 0 以上 1 未満の乱数を、3行2列
print(X)
noise = rng.normal(0, 1, 3)     # 平均 0、標準偏差 1 の正規乱数を 3 個
print(noise)
[[0.77395605 0.43887844]
 [0.85859792 0.69736803]
 [0.09417735 0.97562235]]
[ 0.1278404  -0.31624259 -0.01680116]

ノート

  • 42 は乱数の種（seed）
    • 同じ種なら、何度実行しても同じ乱数になる

データの表をつくる

データの個数と特徴量の数を、array の形から確かめたい（shape）

import numpy as np

X = np.array([[1, 2],
              [3, 4],
              [5, 6]])
print(X.shape)   # (行数, 列数) = (データの個数, 特徴量の数)
print(len(X))    # データの個数
(3, 2)
3

特徴量ごとの array を横に並べて、1行＝1データの表にしたい（column_stack）

import numpy as np

length = np.array([1, 2, 3])
weight = np.array([10, 20, 30])
X = np.column_stack([length, weight])
print(X)
[[ 1 10]
 [ 2 20]
 [ 3 30]]

ノート

  • np.c_[length, weight] と書いても同じ結果になる
    • np.c_ は関数ではないので、( ) ではなく [ ] で囲む

クラスごとの array をつないで、1本の array にしたい（concatenate）

import numpy as np

class0 = np.array([1, 2, 3])
class1 = np.array([4, 5])
x = np.concatenate([class0, class1])
print(x)
[1 2 3 4 5]

scikit-learn に渡すために、1本の array を N行1列の表にしたい（reshape(-1, 1)）

import numpy as np
from sklearn.linear_model import LinearRegression

x = np.array([1, 2, 3])
t = np.array([2, 4, 6])
X = x.reshape(-1, 1)   # 列数は 1、行数は -1（自動で決まる）
print(X)

reg = LinearRegression().fit(X, t)
print(reg.predict(X))
[[1]
 [2]
 [3]]
[2. 4. 6.]

ノート

  • scikit-learn の fit と predict は「1行＝1個のデータ」の表を受け取る
  • -1 を書いた場所は、要素の数から自動で決まる

表示のために、N行1列の表を1本の array に戻したい（reshape(-1)）

import numpy as np

P = np.array([[0.51],
              [0.43],
              [0.54]])
print(P.reshape(-1))   # 1本の配列に並べ直す
[0.51 0.43 0.54]

取り出す

表から、特徴量1つ分の列を array で取り出したい（X[:, 0]）

import numpy as np

X = np.array([[1, 10],
              [2, 20],
              [3, 30]])
print(X[:, 0])   # すべての行の、0 列目
print(X[:, 1])   # すべての行の、1 列目
print(X[0])      # 0 行目
[1 2 3]
[10 20 30]
[ 1 10]

ノート

[行, 列] の順に書き、: は「すべて」を表す

しきい値以上の要素だけを array から取り出したい（x[x >= 5]）

import numpy as np

x = np.array([3, 8, 5, 9, 2])
# x >= 5 は [False, True, True, True, False]
print(x[x >= 5])
[8 5 9]

ノート

[ ] の中に True / False の配列を入れると、True の位置の要素だけが残る

ラベルを使って、あるクラスの行だけを表から取り出したい（X[y == 1]）

import numpy as np

X = np.array([[1, 10],
              [2, 20],
              [3, 30],
              [4, 40]])
y = np.array([0, 1, 0, 1])
# y == 1 は [False, True, False, True]
print(X[y == 1])      # ラベルが 1 の行
print(X[y == 1, 0])   # ラベルが 1 の行の、0 列目
[[ 2 20]
 [ 4 40]]
[2 4]

条件に合うインデックスだけを抽出したい（where）

import numpy as np

x = np.array([3, 8, 5, 9, 2])
# x >= 5 は [False, True, True, True, False]
idx = np.where(x >= 5)[0]
print(idx)
[1 2 3]

ノート

np.where は結果をタプルに入れて返すので、[0] で配列を取り出す

距離の array から、近い順に k 個のインデックスを取り出したい（argsort）

import numpy as np

dist = np.array([0.9, 0.2, 0.7, 0.1])   # 各データまでの距離
order = np.argsort(dist)   # 距離が小さい順に並べたときのインデックス
print(order)
print(order[:2])           # 近いほうから 2 個
[3 1 2 0]
[3 1]

ノート

距離そのものではなく、何番目のデータかが返る

誤差の array から、最小になる候補のインデックスを取り出したい（argmin）

import numpy as np

candidates = np.array([2.0, 2.5, 3.0, 3.5])
errors     = np.array([0.4, 0.1, 0.3, 0.6])   # 候補ごとの誤差
best_i = np.argmin(errors)   # 誤差が最小の位置
print(best_i)
print(candidates[best_i])
1
2.5

ノート

大きいほどよい指標のときは np.argmax を使う

ラベルの array から、クラスの種類を重複なしで取り出したい（unique）

import numpy as np

y = np.array([1, 0, 1, 1, 2, 0])
print(np.unique(y))
[0 1 2]

ノート

重複が除かれ、小さい順に並ぶ

条件で数える・判定する

条件に合う要素の個数を array から数えたい（sum）

import numpy as np

x = np.array([3, 8, 5, 9, 2])
# x >= 5 は [False, True, True, True, False]
print(np.sum(x >= 5))
3

ノート

np.sum は True を 1、False を 0 として足す

予測と正解の array から、正解率を計算したい（mean）

import numpy as np

y      = np.array([1, 0, 1, 1, 0])
y_pred = np.array([1, 0, 0, 1, 1])
# y_pred == y は [True, True, False, True, False]
print(np.mean(y_pred == y))
0.6

ノート

np.mean は True を 1、False を 0 として平均する

2つの条件を両方満たす要素の個数を数えたい（&）

import numpy as np

y      = np.array([1, 0, 1, 1, 0])
y_pred = np.array([1, 0, 0, 1, 1])
# (y == 1) & (y_pred == 1) は [True, False, False, True, False]
print(np.sum((y == 1) & (y_pred == 1)))
2

ノート

  • & の両側の条件は、それぞれ ( ) で囲む
  • 配列どうしでは and は使えない

1つの条件で、array を合う側と合わない側に分けたい（~）

import numpy as np

x = np.array([3, 8, 5, 9, 2])
left = x < 5
# left  は [True, False, False, False, True]
# ~left は [False, True, True, True, False]
print(x[left])
print(x[~left])
[3 2]
[8 5 9]

ノート

~ は True と False を入れ替える

2つの array が完全に同じか確かめたい（all）

import numpy as np

old = np.array([1, 2, 3])
new = np.array([1, 2, 4])
# new == old は [True, True, False]
print(np.all(new == old))   # すべて True のときだけ True
False

予測ラベルとして、True / False の array を 1 / 0 に直したい（astype）

import numpy as np

p = np.array([0.2, 0.7, 0.5, 0.9])
# p >= 0.5 は [False, True, True, True]
y_pred = (p >= 0.5).astype(int)   # True を 1、False を 0 に直す
print(y_pred)
[0 1 1 1]

計算する

for を書かずに、array の全要素に同じ演算をしたい（+ - * / **）

import numpy as np

x = np.array([1.0, 4.0, 9.0])
print(x * 2 + 1)
print(x ** 2)
print(np.sqrt(x))
[ 3.  9. 19.]
[ 1. 16. 81.]
[1. 2. 3.]

ノート

  • for を書かなくても、すべての要素に同じ計算がかかる
  • np.exp、np.log、np.abs も同じように使える

2つの array の差の2乗の平均を計算したい（mean）

import numpy as np

y      = np.array([1.0, 2.0, 3.0])
y_pred = np.array([1.5, 2.0, 2.0])
print(y_pred - y)                   # 同じ位置どうしの差
print((y_pred - y) ** 2)            # 差の 2 乗
print(np.mean((y_pred - y) ** 2))   # その平均
[ 0.5  0.  -1. ]
[0.25 0.   1.  ]
0.4166666666666667

表の列ごとの平均を計算したい（axis=）

import numpy as np

X = np.array([[1, 10],
              [2, 20],
              [3, 60]])
print(X.mean(axis=0))   # 列ごと（特徴量ごと）の平均
print(X.sum(axis=1))    # 行ごと（データごと）の合計
[ 2. 30.]
[11 22 63]

ノート

  • axis=0 は縦方向にまとめ、axis=1 は横方向にまとめる
  • axis を書かないと、全要素をまとめて計算する

表の全部の行に、重みを掛けた和を一度に計算したい（@）

import numpy as np

X = np.array([[1, 2],
              [3, 4],
              [5, 6]])     # 3個のデータ、特徴量は2つ
w = np.array([10, 1])      # 特徴量ごとの重み
print(X @ w)               # データごとに 1列目×10 + 2列目×1
[12 34 56]

ノート

  • * は同じ位置どうしの掛け算で、行列の積は @ で書く
  • 行と列を入れ替えた行列は X.T で得られる

array の要素のうち、負の値だけを 0 に置き換えたい（maximum）

import numpy as np

z = np.array([-2.0, -0.5, 0.0, 1.5])
print(np.maximum(0, z))   # 0 と比べて大きいほうを残す
[0.  0.  0.  1.5]

log に 0 を渡さないために、確率の array を範囲内に収めたい（clip）

import numpy as np

p = np.array([0.0, 0.3, 0.5])
p = np.clip(p, 0.001, 0.999)   # 0.001 から 0.999 の範囲に収める
print(p)
print(np.log(p).round(2))
[0.001 0.3   0.5  ]
[-6.91 -1.2  -0.69]

ノート

np.log(0) は負の無限大になり、そのあとの計算が続けられなくなる

for で、2つのリストの同じ位置の値を1組ずつ取り出したい（zip）

import numpy as np

names  = ["a", "b", "c"]
scores = np.array([70, 85, 60])
for name, score in zip(names, scores):

a 70
b 85

ノート

同じ位置の要素が、1組ずつ取り出される

for で、要素と一緒に「何番目か」も取り出したい（enumerate）

import numpy as np

関数の形を折れ線グラフで見たい（plot）

import numpy as np

x = np.linspace(-3, 3, 100)

ノート

label= で付けた名前が、plt.legend() で凡例として表示される

クラスごとに色を変えた散布図を描きたい（scatter）

import numpy as np
import matplotlib.pyplot as plt
import japanize_matplotlib

X = np.array([[1, 2], [2, 3], [3, 1], [6, 5], [7, 7], [8, 6]])
y = np.array([0, 0, 0, 1, 1, 1])
plt.scatter(X[y == 0, 0], X[y == 0, 1], c="red", marker="s", label="0")
plt.scatter(X[y == 1, 0], X[y == 1, 1], c="blue", marker="o", label="1")
plt.legend()
plt.show()

ノート

クラスごとにデータを取り出し、クラスの数だけ plt.scatter を呼ぶ

グラフに、しきい値を表す縦線・横線を引きたい（axvline / axhline）

import numpy as np
import matplotlib.pyplot as plt
import japanize_matplotlib

x = np.linspace(-3, 3, 100)
plt.plot(x, x ** 2)
plt.axvline(x=1, color="red", linestyle="--")    # x = 1 の縦線
plt.axhline(y=4, color="gray", linestyle=":")    # y = 4 の横線
plt.show()

比較のために、2つのグラフを横に並べたい（subplots）

import numpy as np
import matplotlib.pyplot as plt
import japanize_matplotlib

x = np.linspace(-3, 3, 100)
fig, axes = plt.subplots(1, 2, figsize=(8, 3))   # 1行2列
axes[0].plot(x, x ** 2)
axes[0].set_title("x ** 2")
axes[1].plot(x, np.abs(x))
axes[1].set_title("abs(x)")
plt.tight_layout()
plt.show()

ノート

  • 並べたグラフは axes[0]、axes[1] で1枚ずつ指定する
  • 1枚ずつ指定するときは、名前に set_ が付く
    • plt.title → set_title
    • plt.xlabel → set_xlabel

塗り分けのために、平面全体の格子点の座標を用意したい（meshgrid）

import numpy as np

xs = np.array([0, 1, 2])
ys = np.array([10, 20])
xx, yy = np.meshgrid(xs, ys)
print(xx)   # 各格子点の x 座標
print(yy)   # 各格子点の y 座標
[[0 1 2]
 [0 1 2]]
[[10 10 10]
 [20 20 20]]

ノート

xs の 3 個と ys の 2 個を組み合わせた、6 個の格子点ができる

決定境界を見るために、予測の値で平面を塗り分けたい（contourf）

import numpy as np
import matplotlib.pyplot as plt
import japanize_matplotlib

xx, yy = np.meshgrid(np.linspace(-2, 2, 200), np.linspace(-2, 2, 200))
grid = np.column_stack([xx.reshape(-1), yy.reshape(-1)])   # 1行＝1個の格子点
z = (grid[:, 0] + grid[:, 1] > 0).astype(int)              # 格子点ごとの予測（0 か 1）
Z = z.reshape(xx.shape)                                    # 格子の形に戻す

plt.contourf(xx, yy, Z, levels=1, colors=["lightcoral", "lightblue"])
plt.show()

ノート

  • 格子点を細かく取り、1点ずつ予測して、予測の値ごとに色を塗る
  • 予測の行を model.predict(grid) に置き換えると、分類器の決定境界の図になる
