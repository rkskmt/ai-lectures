scikit-learn 用にarray を N行1列にしたい（reshape(-1, 1)）

import numpy as np
from sklearn.linear_model import LinearRegression

# やりたいこと：入力 x から正解 t を予測する式を、fit で求める
x = np.array([1, 2, 3])    # 入力（データ 3 個）
t = np.array([2, 4, 6])    # それぞれの正解

X = x.reshape(-1, 1)       # fit が受け取れる [[1], [2], [3]] の形にする
print(X)

reg = LinearRegression().fit(X, t)
print(reg.predict(X))
print(reg.predict(np.array([4, 5]).reshape(-1, 1)))    # 新しい入力 4 と 5 も、同じ形にして渡す
[[1]
 [2]
 [3]]
[2. 4. 6.]
[ 8. 10.]

ノート

  • 特徴量が1つでも、[1, 2, 3] の形のままでは fit に渡せない（エラーになる）
  • reshape(-1, 1) の 1 は列の数で、-1 と書いた行の数は、要素の数から自動で決まる

2つの条件を両方満たす要素の個数を数えたい（&）

import numpy as np

y      = np.array([1, 0, 1, 1, 0])    # 正解
y_pred = np.array([1, 0, 0, 1, 1])    # 予測
# (y == 1) & (y_pred == 1) は [True, False, False, True, False]
print(np.sum((y == 1) & (y_pred == 1)))    # 正解が 1 で、予測も 1

表の全部の行に、重みを掛けた和を一度に計算したい（@）

import numpy as np

X = np.array([[1, 2],
              [3, 4],
              [5, 6]])
w = np.array([10, 1])    # 列ごとの重み（0 列目に 10、1 列目に 1）
print(X @ w)        # 行ごとに 0 列目×10 + 1 列目×1
print(X @ w + 5)    # その結果の全部に、定数 5 を足す
print(w @ w)        # w どうしなら 10×10 + 1×1

# for で 1 行ずつ、重みを掛けて足すようなもの
out = []
for row in X:
    out.append(row[0] * w[0] + row[1] * w[1])
print(np.array(out))   # 結果は X @ w と同一
[12 34 56]
[17 39 61]
101
[12 34 56]

ノート

  • * は同じ位置どうしの掛け算で、行列の積は @ で書く
  • 行と列を入れ替えた行列は X.T で得られる

予測の値で平面を塗り分けたい（contourf）

import numpy as np
import matplotlib.pyplot as plt
import japanize_matplotlib

xx, yy = np.meshgrid(np.linspace(-2, 2, 200), np.linspace(-2, 2, 200))
grid = np.column_stack([xx.reshape(-1), yy.reshape(-1)])   # 1行＝1個の格子点

# 分類器の代わりに「x + y が 0 より大きければ 1、そうでなければ 0」という規則で予測する
z = (grid[:, 0] + grid[:, 1] > 0).astype(int)              # 格子点ごとの予測
Z = z.reshape(xx.shape)                                    # 格子の形に戻す

plt.contourf(xx, yy, Z, levels=1, colors=["lightcoral", "lightblue"])
plt.show()

  • 格子点を細かく取り、1点ずつ予測して、予測の値ごとに色を塗る
  • z を求める行を z = model.predict(grid) に置き換えると、分類器の決定境界の図になる
