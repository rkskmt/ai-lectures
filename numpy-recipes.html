NumPy 逆引き

やりたいことから書き方を探す

rkskmt

この資料の使い方

  • 見出しが「やりたいこと」になっている
  • コードは、そのまま貼れば1枚だけで動く
  • コードの下が実行結果
  • 画面の 検索 ボタンで、関数名（argsort など）からも探せる

配列をつくる

等間隔の数列をつくりたい

import numpy as np

print(np.linspace(0, 1, 5))    # 0 から 1 までを 5 個に分ける
print(np.arange(0, 1, 0.25))   # 0 から 0.25 きざみ（1 は含まない）
print(np.arange(5))            # 0 から 4 までの整数
[0.   0.25 0.5  0.75 1.  ]
[0.   0.25 0.5  0.75]
[0 1 2 3 4]

ノート

  • linspace は個数を指定する
  • arange はきざみ幅を指定する

0 で埋めた配列をつくりたい

import numpy as np

w = np.zeros(3)        # 要素 3 個
print(w)

M = np.zeros((2, 3))   # 2行3列
print(M)
[0. 0. 0.]
[[0. 0. 0.]
 [0. 0. 0.]]

ノート

2次元にするときは、形を (行数, 列数) と括弧でまとめて渡す

乱数の配列をつくりたい

import numpy as np

rng = np.random.default_rng(42)
print(rng.uniform(0, 1, 3))   # 0 以上 1 未満の一様乱数を 3 個
print(rng.normal(0, 1, 3))    # 平均 0、標準偏差 1 の正規乱数を 3 個
[0.77395605 0.43887844 0.85859792]
[ 0.94056472 -1.95103519 -1.30217951]

ノート

  • 42 は乱数の種（seed）
    • 同じ種なら、何度実行しても同じ乱数になる

import numpy as np

x = np.array([1, 2, 3])
print(x.shape)

X = x.reshape(-1, 1)   # 列数は 1、行数は -1（自動で決まる）

ノート

  • scikit-learn の fit は「1行＝1個のデータ」の表を受け取る
    • 特徴量が1つだけのときに、この変換を使う

2つの列を横に並べて表にしたい

条件に合う要素だけ取り出したい

import numpy as np

ラベルが一致する行だけ取り出したい

import numpy as np

X = np.array([[1, 10],
              [2, 20],
              [3, 30],
              [4, 40]])
y = np.array([0, 1, 0, 1])
# y == 1 は [False, True, False, True]
print(X[y == 1])      # ラベルが 1 の行
print(X[y == 1, 0])   # ラベルが 1 の行の、0 列目
[[ 2 20]
 [ 4 40]]
[2 4]

条件に合うインデックスを知りたい

import numpy as np

x = np.array([3, 8, 5, 9, 2])
# x >= 5 は [False, True, True, True, False]
idx = np.where(x >= 5)[0]
print(idx)
[1 2 3]

ノート

np.where は結果をタプルに入れて返すので、[0] で配列を取り出す

小さい順に k 個のインデックスがほしい

import numpy as np

d = np.array([0.9, 0.2, 0.7, 0.1])
order = np.argsort(d)   # 小さい順に並べたときのインデックス

[3 1]

ノート

条件で数える・判定する

条件に合う個数を数えたい

import numpy as np

x = np.array([3, 8, 5, 9, 2])
# x >= 5 は [False, True, True, True, False]
print(np.sum(x >= 5))
3

ノート

np.sum は True を 1、False を 0 として足す

条件に合う割合を出したい

import numpy as np

y      = np.array([1, 0, 1, 1, 0])
y_pred = np.array([1, 0, 0, 1, 1])
# y_pred == y は [True, True, False, True, False]
print(np.mean(y_pred == y))
0.6

ノート

np.mean は True を 1、False を 0 として平均する

2つの条件を両方満たす個数を数えたい

import numpy as np

y      = np.array([1, 0, 1, 1, 0])
y_pred = np.array([1, 0, 0, 1, 1])
# (y == 1) & (y_pred == 1) は [True, False, False, True, False]
print(np.sum((y == 1) & (y_pred == 1)))
2

ノート

  • & の両側の条件は、それぞれ ( ) で囲む
  • 配列どうしでは and は使えない

条件を「または」「でない」で組み合わせたい

import numpy as np

x = np.array([3, 8, 5, 9, 2])
# (x < 3) | (x > 8) は [False, False, False, True, True]
print(x[(x < 3) | (x > 8)])

ok = x >= 5
# ~ok は [True, False, False, False, True]
print(x[~ok])
[9 2]
[3 2]

ノート

  • | は「または」
  • ~ は True と False を入れ替える

全部が条件を満たすか確かめたい

import numpy as np

a = np.array([1, 2, 3])
b = np.array([1, 2, 4])
# a == b は [True, True, False]
print(np.all(a == b))   # すべて True か
print(np.any(a == b))   # 1 つでも True があるか
False
True

条件で値を切り替えたい

import numpy as np

p = np.array([0.2, 0.7, 0.5, 0.9])
# p >= 0.5 は [False, True, True, True]
print(np.where(p >= 0.5, 1, 0))   # True の位置は 1、False の位置は 0
[0 1 1 1]

計算する

全要素に同じ計算をしたい

import numpy as np

x = np.array([1.0, 4.0, 9.0])
print(x * 2 + 1)
print(x ** 2)
print(np.sqrt(x))
[ 3.  9. 19.]
[ 1. 16. 81.]
[1. 2. 3.]

ノート

  • for を書かなくても、すべての要素に同じ計算がかかる
  • np.exp、np.log、np.abs も同じように使える

2つの配列の差を要素ごとに計算したい

import numpy as np

y      = np.array([1.0, 2.0, 3.0])
y_pred = np.array([1.5, 2.0, 2.0])
print(y_pred - y)                   # 同じ位置どうしの差
print((y_pred - y) ** 2)            # 差の 2 乗
print(np.mean((y_pred - y) ** 2))   # その平均
[ 0.5  0.  -1. ]
[0.25 0.   1.  ]
0.4166666666666667

行ごと・列ごとに合計を出したい

import numpy as np

X = np.array([[1, 2, 3],
              [4, 5, 6]])
print(np.sum(X))           # 全要素の合計
print(np.sum(X, axis=0))   # 列ごとの合計（縦方向に足す）
print(np.sum(X, axis=1))   # 行ごとの合計（横方向に足す）
21
[5 7 9]
[ 6 15]

ノート

  • np.mean でも axis の意味は同じ
  • X.sum(axis=0) と書いても同じ結果になる

行列の積を計算したい

import numpy as np

X = np.array([[1, 2],
              [3, 4],
              [5, 6]])     # 3行2列
w = np.array([10, 1])
print(X @ w)        # 行ごとに 1列目×10 + 2列目×1
print(X.T)          # .T は行と列を入れ替える
[12 34 56]
[[1 3 5]
 [2 4 6]]

ノート

* は同じ位置どうしの掛け算で、行列の積は @ で書く

0 未満を 0 にしたい

import numpy as np

z = np.array([-2.0, -0.5, 0.0, 1.5])

[0.  0.  0.  1.5]
[-1.  -0.5  0.   1. ]

しきい値の位置に線を引きたい

グラフを横に並べたい

import numpy as np
import matplotlib.pyplot as plt
import japanize_matplotlib

x = np.linspace(-3, 3, 100)
fig, axes = plt.subplots(1, 2, figsize=(8, 3))   # 1行2列
axes[0].plot(x, x ** 2)
axes[0].set_title("x ** 2")
axes[1].plot(x, np.abs(x))

ノート

  • 並べたグラフは axes[0]、axes[1] で1枚ずつ指定する
  • 1枚ずつ指定するときは、名前に set_ が付く

    • plt.xlabel → set_xlabel

格子点の座標をつくりたい

import numpy as np

xs = np.array([0, 1, 2])
ys = np.array([10, 20])
xx, yy = np.meshgrid(xs, ys)
print(xx)   # 各格子点の x 座標
print(yy)   # 各格子点の y 座標
[[0 1 2]
 [0 1 2]]
[[10 10 10]
 [20 20 20]]

ノート

xs の 3 個と ys の 2 個を組み合わせた、6 個の格子点ができる

領域を色で塗り分けたい

import numpy as np
import matplotlib.pyplot as plt
import japanize_matplotlib

xx, yy = np.meshgrid(np.linspace(-2, 2, 200), np.linspace(-2, 2, 200))
grid = np.column_stack([xx.reshape(-1), yy.reshape(-1)])   # 1行＝1個の格子点
z = np.where(grid[:, 0] + grid[:, 1] > 0, 1, 0)            # 格子点ごとの判定（0 か 1）
Z = z.reshape(xx.shape)                                    # 格子の形に戻す

plt.contourf(xx, yy, Z, levels=1, colors=["lightcoral", "lightblue"])
plt.show()

ノート

  • 格子点を細かく取り、1点ずつ判定して、結果の値ごとに色を塗る
  • 判定の行を分類器の予測に置き換えると、決定境界の図になる
