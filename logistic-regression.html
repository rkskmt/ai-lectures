モデルの構造

ロジスティック回帰（Logistic Regression）

  • ロジスティック回帰：直線のパラメータを最適化して分類
  • 中身は2ステップ
    • Step 1 ：直線
    • Step 2 ：確率

「回帰」なのに分類？

  • 予測対象が 0/1 のラベルではなく「Salmon である確率」という連続値だから
  • 確率として数値で回帰して、最後にしきい値 0.5 で分類している
    • とはいえこれは、苦しい言い訳で歴史的経緯で回帰とされているとしか言いようがない

Step 1：線形結合＋バイアス

\[z = \alpha_1 x_1 + \alpha_2 x_2 + b\]

  • \(x_1, x_2\)：入力（輝度、重さ）
  • \(\alpha_1, \alpha_2\)：重み（weight）（どの特徴量をどれだけ重視するか）
  • \(b\)：バイアス（bias）（全体のオフセット）

魚1匹の \(x_1, x_2\) を入力すると、\(z\) という1つの値にまとまる

見慣れた式

  • \(z = 0\) と置くと：

\[\underbrace{\alpha_1}_{a}\, x_1 + \underbrace{\alpha_2}_{b}\, x_2 + \underbrace{\;b\;}_{c} = 0\]

  • 直線の式 \(ax + by + c = 0\) そのもの — さっきの斜めの線の正体はこれ（決定境界）
  • \(z\) の符号が「線の上か下か」、大きさが線からの遠さ
  • 求めたいのは結局、この \(a, b, c\)（ここでは \(\alpha_1, \alpha_2, b\)）の3つの数 — これを機械に探させる

Step 2：\(z\) を「確率」にする — シグモイド（Sigmoid）

\[p = \sigma(z) = \frac{1}{1 + e^{-z}}\]

\[p = \sigma(\alpha_1 x_1 + \alpha_2 x_2 + b) = \frac{1}{1 + e^{-(\alpha_1 x_1 + \alpha_2 x_2 + b)}}\]

  • zの取りうる範囲である実数全体 \((-\infty, +\infty)\) を 0〜1 の範囲に押し込む
  • \(p \geq 0.5\) → Salmon、\(p < 0.5\) → Sea bass と判定
  • \(z = 0\)（＝決定境界の上）のとき、ちょうど \(p = 0.5\)
  • 判定だけなら \(z\) の符号で足りるが、\(p\) は「どれくらい自信があるか」まで持っている
    • これが後で学習の鍵になる

\(z = 1\) を実際に確率へ変換する

  • 実際に \(z = 1\) をシグモイドへ入れる：

\[p = \sigma(1) = \frac{1}{1 + e^{-1}} \approx 0.731\]

  • \(z=1\) の魚を、Salmon である確率 \(73.1\%\) と解釈できる

\(e^x\) は微分しても \(e^x\)

  • 一般の指数関数（exponential function）\(a^x\) を微分すると：

\[\frac{d}{dx}a^x=(\log a)a^x\]

  • \(\log a=1\) になる特別な底が \(e\approx2.718\)：

\[\frac{d}{dx}e^x=e^x\]

  • 指数が \(-z\) なら、連鎖律で内側の微分 \(-1\) が掛かる：

\[\frac{d}{dz}e^{-z}=e^{-z}\frac{d(-z)}{dz}=-e^{-z}\]

\(e\) は、指数関数の値と傾きが同じになるように選ばれた数

シグモイドを微分する

  • \(p=(1+e^{-z})^{-1}\) を \(z\) で微分する：

\[\begin{aligned} \frac{dp}{dz} &=\frac{d}{dz}(1+e^{-z})^{-1} \\ &=-(1+e^{-z})^{-2}(-e^{-z}) \\ &=\frac{e^{-z}}{(1+e^{-z})^2} \end{aligned}\]

  • 一方、\(p\) と \(1-p\) を掛けると同じ形になる：

\[p(1-p) =\frac{1}{1+e^{-z}} \left(1-\frac{1}{1+e^{-z}}\right) =\frac{e^{-z}}{(1+e^{-z})^2}\]

\[\therefore \qquad \frac{dp}{dz}=p(1-p)\]

  • \(z=1\)、\(p\approx0.731\) では \(\dfrac{dp}{dz}\approx0.731(1-0.731)\approx0.197\)

勾配降下法につなぐには

  • 学習では \(\alpha_j \to z \to p \to L\) を逆向きに微分する
  • シグモイドで分かるのは \(z \to p\) の傾き。パラメータをどちらへ動かすかには、予測の悪さを表す損失 \(L\) も必要

名前の由来 — 何が「ロジスティック」？

  • シグモイド（sigmoid）は「S字型の」という意味の総称
    • S字カーブの関数はみんなシグモイド
  • \(\dfrac{1}{1+e^{-z}}\) の正式名はロジスティック関数（logistic function）
    • シグモイドの代表選手
  • 出自は機械学習ではなく、19世紀の人口の成長モデル
    • 最初は勢いよく増え、資源の上限に近づくと頭打ちになる成長曲線がS字
  • ロジスティック関数で確率を出す回帰だからロジスティック回帰

勾配降下法でパラメータを学習する

ロジスティック回帰も勾配降下法で fit する

  • 前の回と同じ更新式。\(\eta\)（イータ）は学習率：

\[\alpha_j \leftarrow \alpha_j-\eta\frac{\partial L}{\partial \alpha_j}, \qquad b \leftarrow b-\eta\frac{\partial L}{\partial b}\]

  • ロジスティック回帰で必要なのは：
    • 予測をどう採点するか：損失 \(L\)
    • 損失を各パラメータでどう微分するか：勾配

このあとの微分は、勾配降下法の更新式に入れる勾配を作るため

2クラスの確率は \(p\) と \(1-p\)

  • \(p\)：Salmon（\(y=1\)）になる確率
  • 2クラスしかないので、Sea bass（\(y=0\)）になる確率は残りの \(1-p\)

\[P(y=1)=p, \qquad P(y=0)=1-p, \qquad p+(1-p)=1\]

  • 例えば \(p=0.4\) なら：
    • Salmon の確率は \(0.4\)
    • Sea bass の確率は \(1-0.4=0.6\)

1つの出力 \(p\) があれば、両方のクラスの確率 \((p,\,1-p)\) が分かる

正解クラスに出した確率を採点する

  • 正解クラスに出した確率を \(q\) と置く：
正解 採点する確率 \(q\) \(p=0.4\) のときの損失 \(-\log q\)
\(y=1\)（Salmon） \(q=p\) \(-\log(0.4)\approx0.92\)
\(y=0\)（Sea bass） \(q=1-p\) \(-\log(0.6)\approx0.51\)

\[\ell(y,p)=-\left[y\log p+(1-y)\log(1-p)\right]= -\log q\]

  • \(y\) と \(1-y\) は 0/1 のスイッチ。正解側の項だけが残る
  • つまり、全魚の損失 \(L=\dfrac{1}{N}\sum_i\ell(y_i,p_i)\)

Lを交差エントロピー（cross entropy）と言う

−log の形：外すほど急に効く

  • 正解クラスの確率が高い（\(q \to 1\)）ほど損失はほぼ 0
  • 外れるほど急カーブで跳ね上がる
  • \(q \to 0\)（自信満々の間違い）では青天井
    • 最も避けたいので急激に大きなlossとなる

2つの微分を掛けると約分される

  • シグモイドの微分は、どちらの正解でも同じ：

\[\frac{\partial p}{\partial z}=p(1-p)\]

  • 正解が \(y=1\) のときは、交差エントロピーの微分に \(1/p\) が現れる：

\[\frac{\partial \ell}{\partial z} =\underbrace{\left(-\frac{1}{p}\right)}_{\text{交差エントロピー}} \underbrace{p(1-p)}_{\text{シグモイド}} =-(1-p)=p-1\]

  • 正解が \(y=0\) のときは、\(1/(1-p)\) が現れる：

\[\frac{\partial \ell}{\partial z} =\underbrace{\frac{1}{1-p}}_{\text{交差エントロピー}} \underbrace{p(1-p)}_{\text{シグモイド}} =p\]

\(p\) または \(1-p\) が約分され、どちらの正解でも \(\dfrac{\partial \ell}{\partial z}=p-y\) になる

入力値が重みごとの勾配を決める

  • \(z=\alpha_1x_1+\alpha_2x_2+b\) なので：

\[\frac{\partial z}{\partial \alpha_j}=x_j, \qquad \frac{\partial z}{\partial b}=1\]

  • 連鎖律（chain rule）で各パラメータまで戻る：

\[\frac{\partial \ell}{\partial \alpha_j} =\frac{\partial \ell}{\partial z}\frac{\partial z}{\partial \alpha_j} =(p-y)x_j, \qquad \frac{\partial \ell}{\partial b}=p-y\]

  • 例：\(p-y=-0.4\)、\(x=(2,\,0.5)\) なら：
    • \(\dfrac{\partial \ell}{\partial \alpha_1}=-0.4\times2=-0.8\)
    • \(\dfrac{\partial \ell}{\partial \alpha_2}=-0.4\times0.5=-0.2\)
    • \(|x_1|\) が \(|x_2|\) の4倍なので、\(\alpha_1\) の勾配も4倍
  • 学習率 \(\eta\) を掛けて更新：

\[\alpha_j \leftarrow \alpha_j-\eta(p-y)x_j, \qquad b \leftarrow b-\eta(p-y)\]

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def forward(X, alpha, b):
    """線形結合＋バイアス → シグモイド"""
    return sigmoid(X @ alpha + b)

def loss_fn(y_true, p):
    """交差エントロピー"""
    eps = 1e-10
    p = np.clip(p, eps, 1 - eps)
    return -np.mean(y_true * np.log(p) + (1 - y_true) * np.log(1 - p))

def accuracy(y_true, p):
    return np.mean((p >= 0.5) == y_true)

「線形」の正体

この式、なんと呼ばれているか

\[z = \alpha_1 x_1 + \alpha_2 x_2 + b\]

  • 教科書や解説記事は、これを入力の線形結合（linear combination）と呼ぶ
  • ロジスティック回帰は線形分類器、前回のは線形回帰 — この先も「線形」だらけ

質問

この「線形」、直線（線の形）のことだと思う？

線形結合は線形ではない

  • 「線形」は直線のことではない — 実はこの式自体が「線形」の定義を満たしていない
  • その定義 — 線形性（linearity）＝「定数倍と足し算だけ」：

\[f(c\,x) = c\,f(x) \;\;\text{（斉次性）} \qquad f(x_1 + x_2) = f(x_1) + f(x_2) \;\;\text{（加法性）}\]

  • 斉次性（homogeneity）：先に定数倍しても後で定数倍しても同じ
  • 加法性（additivity）：先に足しても後で足しても同じ
  • 例：\(f(x) = 3x\) は線形。\(f(x) = x^2\) は \(f(1{+}1) = 4 \neq f(1) + f(1) = 2\) で失格
  • \(f(x) = ax + b\) も失格 — 足してから入れると \(+b\) は1回、入れてから足すと \(+2b\) と2回でズレる

一発の見破り方：\(f(0) = 0\)

  • 線形なら \(f(0) = f(0 \cdot x) = 0 \cdot f(x) = 0\) — 0 を入れたら必ず 0 が出る
  • 逆に言えば、\(f(0) \neq 0\) の関数はその場で線形失格
  • さっき地道に確かめた \(y = ax + b\) もこれなら一瞬：\(f(0) = b \neq 0\) → 失格。グラフは直線なのに、線形ではない

重要

「グラフが直線」（見た目）と「線形性」（性質）は別物。 一次関数を「線形」と呼ぶのは、高校までの見た目基準。

ノート

\(f(0) = 0\) は失格者を見つける検査。\(f(0) = 0\) でも \(x^2\) のように非線形なものはある（合格の証明にはならない）。

確かめる：\(z = \alpha_1 x_1 + \alpha_2 x_2 + b\)

質問

「線形結合」を名乗るこの式の、どこが線形の定義を破っているのか？ \(f(x_1, x_2) = \alpha_1 x_1 + \alpha_2 x_2 + b\) に、いまの \(f(0) = 0\) 検査を当てよ。

  • \(f(0, 0) = b \neq 0\) — 犯人は \(b\)。中身は「線形結合＋おまけの \(b\)」
  • さんざん「線形」と名乗りながら、\(b\) が定義を破っている
  • 世の中の教科書は、この \(b\) を平気な顔で足したまま「線形」と呼び続けている

\(+b\) がついていても線形にするトリック

  • \(b\) を「常に 1 が入っている入力 \(x_0\) への重み \(\alpha_0\)」と読み替える：

\[z = \alpha_0 \underbrace{x_0}_{=\,1} + \alpha_1 x_1 + \alpha_2 x_2\]

  • 入力を \((1, x_1, x_2)\) の3次元と見れば、\(f(0,0,0) = 0\) — 正真正銘の線形結合に戻る
  • 統計学ではデータ表に「全部 1 の列」を足す定番の手（切片項）。実装でも広く使われるトリック

用語メモ

\(+b\) 込みの形（線形＋平行移動）は、文献ではアフィン変換（affine transformation）と呼んで区別することがある。 世の中の説明の多くは \(+b\) 込みでも「線形」と書く — 頭の中で \(x_0 = 1\) を補えば、その呼び方でも辻褄が合う。

線形にこだわる理由

  • 「定数倍と足し算だけ」の計算は、行列のかけ算にそのまま乗る — 大量のデータを一括で計算できる（NumPy 実装の回で効いてくる）
  • 微分しても形が崩れない：\(\dfrac{\partial z}{\partial \alpha_1} = x_1\) — 勾配降下法と相性が最高
  • 「線形か、そうでないか」は、どの道具が使えるかを分ける最初の仕分けになっている

まとめ

  • ロジスティック回帰 ＝ 線形結合（＋バイアス）→ シグモイド。決定境界は \(z = 0\) の直線
  • 「線形」は直線の見た目ではなく「定数倍と足し算だけ」という性質 — \(f(0) \neq 0\) なら線形失格
  • \(+b\) は厳密には線形破り — 「常に 1 の入力 \(x_0\)」と読み替えれば線形結合に収まる（文献の呼び名：アフィン）
  • 学習 ＝ 交差エントロピーを勾配降下法で最小化
    • 勾配は \((p - y) x\) — シグモイド＋交差エントロピーの組み合わせの妙
  • fit() の中身は「予測 → 差を測る → 境界を少し動かす」の繰り返しだった

練習問題

以下の問題を手計算とPythonコードの両方で解け。

問題1：線形かどうかを見破る

次の関数が線形性（斉次性・加法性）を満たすか判定せよ。

\[\text{(a)}\; f(x) = 5x \qquad \text{(b)}\; f(x) = 3x + 2 \qquad \text{(c)}\; f(x) = x^2 \qquad \text{(d)}\; f(x_1, x_2) = 2x_1 - x_2\]

  1. まず \(f(0) = 0\) チェックで失格者を探せ
  2. 残った関数について、加法性 \(f(x_1 + x_2) = f(x_1) + f(x_2)\) が成り立つか確認せよ（破れるなら反例を1つ）
  3. コードで「先に足してから入れる」と「入れてから足す」を \(x_1 = 1, x_2 = 2\) で計算し、判定と一致することを確かめよ

問題2：ロジスティック回帰を2歩だけ学習させる

2匹だけのミニ世界。標準化済みの特徴量（輝度, 重さ）で、 1匹目 \(x^{(1)} = (2, 1)\) は Salmon（\(y=1\)）、2匹目 \(x^{(2)} = (-1, 1)\) は Sea bass（\(y=0\)）。 初期値 \(\alpha = (0, 0)\)、\(b = 0\)、学習率 \(\eta = 0.5\)。

  1. 1匹目を見せたときの \(z\)、\(p = \sigma(z)\)、差 \(\delta = p - y\) を求めよ
  2. 更新式 \(\alpha \leftarrow \alpha - \eta\,\delta\,x\)、\(b \leftarrow b - \eta\,\delta\) で更新せよ
  3. 続けて2匹目でもう1歩更新せよ
  4. 同じ計算をコードで実行し、手計算と一致することを確かめよ

ヒント：\(\sigma(0) = 0.5\)。実は \(\sigma\) の値はこれしか使わない。

問題1の解答例

  • f(0) チェック
  • 加法性チェック
    1. \(f(0) = 0\) — 通過
    1. \(f(0) = 2 \neq 0\) — その場で線形失格
    1. \(f(0) = 0\) — 通過（ただしまだ合格ではない）
    1. \(f(0, 0) = 0\) — 通過
    1. \(f(1+2) = 15 = f(1) + f(2) = 5 + 10\) — 成立。斉次性も \(f(cx) = 5cx = c f(x)\) で成立 → 線形
    1. \(f(1+2) = 9 \neq f(1) + f(2) = 1 + 4 = 5\) — 非線形。\(f(0)=0\) を通過しても安心できない
    1. \(2(x_1 + x_1') - (x_2 + x_2') = (2x_1 - x_2) + (2x_1' - x_2')\) — 成立 → 線形

問題2の解答例

  • 1匹目（\(x = (2, 1)\)、\(y = 1\)）
  • 2匹目（\(x = (-1, 1)\)、\(y = 0\)）

\[z = 0 \times 2 + 0 \times 1 + 0 = 0, \qquad p = \sigma(0) = 0.5, \qquad \delta = 0.5 - 1 = -0.5\]

更新: \[\alpha \leftarrow (0, 0) - 0.5 \times (-0.5) \times (2, 1) = (0.5,\; 0.25)\] \[b \leftarrow 0 + 0.25 = 0.25\]

まだ何も知らないので \(p = 0.5\)（五分五分）。Salmon と言い切れなかったぶん、境界が動いた。

\[z = 0.5 \times (-1) + 0.25 \times 1 + 0.25 = 0, \qquad p = 0.5, \qquad \delta = 0.5\]

偶然にも2匹目はちょうど境界の上（\(z = 0\)）に乗っていた。

更新: \[\alpha \leftarrow (0.5, 0.25) - 0.5 \times 0.5 \times (-1, 1) = (0.75,\; 0)\] \[b \leftarrow 0.25 - 0.25 = 0\]

コードで確認

解答例を見る 
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

alpha = np.array([0.0, 0.0])
b  = 0.0
lr = 0.5

fishes = [(np.array([2.0, 1.0]), 1),    # Salmon
          (np.array([-1.0, 1.0]), 0)]   # Sea bass

for i, (xi, yi) in enumerate(fishes, 1):
    z     = xi @ alpha + b
    p     = sigmoid(z)
    delta = p - yi
    alpha = alpha - lr * delta * xi
    b     = b - lr * delta
    print(f"{i}匹目: z={z:.2f}, p={p:.2f}, δ={delta:+.2f} → α={alpha}, b={b:.2f}")
1匹目: z=0.00, p=0.50, δ=-0.50 → α=[0.5  0.25], b=0.25
2匹目: z=0.00, p=0.50, δ=+0.50 → α=[0.75 0.  ], b=0.00

手計算どおり、\(\alpha = (0.5, 0.25) \to (0.75, 0)\)、\(b = 0.25 \to 0\) と動く。
