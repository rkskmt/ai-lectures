分類の損失を作る

\(f(x)\) を確率っぽいものに変換

  • \(f(x)\) は \(-\infty\) から \(+\infty\) まで値域があるため扱いにくい
  • そこで、この出力を 0〜1 に押し込む変換をする関数を導入
    • 0〜1 とした値を確率 \(p\) として扱う
      • 例えば、\(p\) は Salmon と判定してよい蓋然性が高い確率（のようなもの）
      • 逆に \(1-p\) は Salmon 以外
データ点の位置 \(f(x)\) \(p\)
Salmon の側で直線から遠い 大きい正の値 1 に近い
直線の上 0 0.5
Sea bass の側で直線から遠い 大きい負の値 0 に近い

ロジスティック関数（Logistic Function）

  • \(f(x)\) を確率っぽいものに変換できる関数に、シグモイド関数がある
    • S字の形をしている関数という意味
    • ロジスティック回帰では、シグモイド関数のうちロジスティック関数を使う

\[p=\sigma(f(x))=\frac{1}{1+e^{-f(x)}}\]

  • \(\sigma\)：ロジスティック関数（sigmoid の s に当たるギリシャ文字）
  • \(f(x)\)：ロジスティック関数への入力（データ点 \(x\) での値）
  • \(p\)：各クラスである確率（Salmon である確率）

\(f(x)\) と \(p\) の対応表と同じ

  • どんな \(f(x)\) でも \(e^{-f(x)} > 0\) なので、分母は 1 より大きく \(0 < p < 1\)
  • \(f(x) = 0\)
    • \(e^{0} = 1\) なので \(p = \dfrac{1}{2}\)
  • \(f(x) \to +\infty\)
    • \(e^{-f(x)} \to 0\) なので \(p \to 1\)
  • \(f(x) \to -\infty\)
    • \(e^{-f(x)} \to +\infty\) なので \(p \to 0\)

例：\(f(x) = 1\) の場合

\(f(x) = 1\) をロジスティック関数に代入

\[p = \sigma(1) = \frac{1}{1 + e^{-1}} \approx 0.731\]

今の気持ち

\(f(x)=1\) のデータ点は \(p\) が 0.731 であるから、Salmon である確率を \(73.1\%\) だと解釈してしまおう

\(p\) から Loss を作る準備

  • \(p\) はそのまま Loss にできない（方向が逆）
    • やりたい Loss 関数の挙動
      • \(p\) が高いなら Loss が低い
      • \(p\) が低いなら Loss が高い
  • おまけに正解ラベル以外（Sea bass）も \(p\) としてしまうと訳が分からなくなる
  • そこで「\(q\)：正解クラスに出した確率」を導入する
    • 2クラスの場合、片方の確率が \(p\) なら逆は \(1-p\)
      • 正解が Salmon なら \(q = p\)
      • 正解が Sea bass（Salmon 以外）なら \(q = 1-p\)

\(q\) が 1 に近いほど小さく、0 に近いほど大きい損失を作りたい

このような損失を \(-\log q\) で作ってみよう

  • \(q\) をいい感じにする関数として例えば以下が考えられる
    • \(1-q\)：外し方がひどくても（\(q \to 0\)）、損失は 1 で頭打ち
    • \(-\log q\)：外し方がひどいと（\(q \to 0\)）損失青天井
      • ※注 log は増加関数なのでマイナスをつけて良い感じに

\(\ell = -\log q\) を Loss 関数とする（ただし1データ分）

一旦、現状の損失を \(f(x)\) から見るとどのような形になるかチェック

  • 当初欲しかった損失は、\(f(x)\) が正しい側で 0 から離れるほど小さくなる関数
  • \(p = \sigma(f(x))\) を代入して、損失を \(f(x)\) の関数として描く
    • 正解が Salmon：\(\ell = -\log \sigma(f(x))\)
    • 正解が Sea bass：\(\ell = -\log\bigl(1-\sigma(f(x))\bigr)\)

結果

  • 正しい側で 0 から離れるほど、損失は 0 に近づく
  • 逆の側では、0 から離れるほど損失が大きくなる

分類の損失に求めた条件を満たす損失ができた

log は全データを一括で扱いやすい

  • 全データで、正解クラスの確率を同時に高めたい
    • 各データの \(q\) を掛けた積 \(q_1 q_2 \cdots q_N\) を大きくする
    • この積：全データの正解ラベルを、まとめて出す確率
  • log は積が和になり、1データずつの損失に分けられる

\[-\log(q_1 q_2 \cdots q_N) = -\log q_1 - \log q_2 - \cdots - \log q_N = \ell_1 + \ell_2 + \cdots + \ell_N\]

  • なのでデータ数で割って平均をとるといい感じになる

\[L = \frac{1}{N}\sum_{i} \left(-\log q_i\right)\]

\(L\) を Loss 関数とする

クロスエントロピー：正解ラベル \(y\) も Loss 関数に入れ込みたい

  • \(q\) は、正解によって場合分けで決めている
    • 正解が Salmon なら \(q = p\)
    • 正解が Sea bass なら \(q = 1-p\)
  • このままでは、○○ならごとに、別々に選ぶ必要がある
    • つまり、クロネッカーのデルタのように条件判定により使う項をスイッチしたい
  • そこで、正解ラベル \(y\)（0/1）を利用 \[\ell(y,p)=-\left[y\log p+(1-y)\log(1-p)\right]\]
    • \(y=1\)（Salmon）
      • 右の項が消えて \(\ell=-\log p\)（\(p=0.4\) なら \(\ell\approx0.92\)）
    • \(y=0\)（Sea bass）
      • 左の項が消えて \(\ell=-\log(1-p)\)

これが（二値）交差エントロピー（Binary Cross-Entropy）

クロスエントロピーは3値以上でも使える優れもの

多クラスの交差エントロピー

勾配降下法で学習する

\(f(x)\) はある。Loss も決まった。あとは学習

直線の係数を、学習するパラメータにする

\[z = w_1 x_1 + w_2 x_2 + b\]

  • 直線の \(f(x)\) の係数 \(w_1, w_2, b\) を、学習で求める
  • 機械学習では、\(b\) をバイアス（bias）と呼ぶことが多い
  • 確率は \(p = \sigma(z)\)

\(z\)：データ点 \(x\) での \(f(x)\)（\(z = 0\) の点の集合が決定境界）

勾配降下法で学習

  • 普通に勾配降下法を実行：回帰直線のときとまったく同じ

\[w_j \leftarrow w_j-\alpha\frac{\partial L}{\partial w_j}, \qquad b \leftarrow b-\alpha\frac{\partial L}{\partial b}\]

  • \(\alpha\)（アルファ）：学習率（learning rate、lr）
  • \(j\)：どの特徴量の係数かを表す添字
    • 例：魚データにおいては \(j=1\)（輝度）、\(j=2\)（重さ）

これで損失 \(L\) はできたので、残りは勾配（gradient）

ロジスティック関数の微分

損失 \(\ell\) は、\(z\) から2段で計算している

\[z \;\xrightarrow{\;\text{ロジスティック関数}\;}\; p \;\xrightarrow{\;\text{交差エントロピー}\;}\; \ell\]

  • 勾配のため、まず1段目のロジスティック関数を微分する
  • 準備：合成関数（composite function）の微分は外側の微分 × 内側の微分 \[ \frac{d}{dx}h(g(x))=h'(g(x))\,g'(x), \qquad \frac{dy}{dx}=\frac{dy}{du}\frac{du}{dx} \]
  • \(p=(1+e^{-z})^{-1}\) を合成関数として微分する
    • 外側：\((\;)^{-1}\)
    • 内側：\(1+e^{-z}\)（指数関数（exponential function）の微分）

\[\begin{aligned} \frac{dp}{dz} &=\underbrace{-(1+e^{-z})^{-2}}_{\text{外側の微分}} \underbrace{(-e^{-z})}_{\text{内側の微分}} \\ &=\frac{e^{-z}}{(1+e^{-z})^2} \end{aligned}\]

ここで朗報：微分せずとも \(p\) だけでロジスティック関数の微分は計算可能

  • ロジスティック関数の微分は以下の形

\[ \frac{dp}{dz}=\frac{e^{-z}}{(1+e^{-z})^2} \tag{1} \]

  • 一方、ロジスティック関数の出力は \(p=\dfrac{1}{1+e^{-z}}\)
  • \(p(1-p)\) を計算すると、

\[p(1-p) =\frac{1}{1+e^{-z}} \left(1-\frac{1}{1+e^{-z}}\right) =\frac{e^{-z}}{(1+e^{-z})^2} \tag{2}\]

  • (1)と(2)の右辺が同じなので、ロジスティック関数の微分は \(p\) だけで計算可能

\[\therefore \qquad \frac{dp}{dz}=p(1-p)\]

交差エントロピーを \(p\) で微分する

\(\dfrac{dp}{dz}\) はできたので、次は交差エントロピーの微分 \(\dfrac{\partial\ell}{\partial p}\) を求める

  • 正解が \(y=1\) のとき：\(\ell=-\log p\)

\[\frac{\partial\ell}{\partial p}=-\frac{1}{p}\]

  • 正解が \(y=0\) のとき：\(\ell=-\log(1-p)\)

\[\frac{\partial\ell}{\partial p}=\frac{1}{1-p}\]

2つの微分を掛けると \(p-y\) になる

  • \(p\) は \(z\) から計算されるので、連鎖律（chain rule）で2つの微分を掛ける \[ \frac{\partial\ell}{\partial z} =\frac{\partial\ell}{\partial p}\frac{dp}{dz} \]
    • \(\dfrac{\partial\ell}{\partial p}\)：ラベルにより2通りある（交差エントロピーの微分）
    • \(\dfrac{dp}{dz}=p(1-p)\)：ロジスティック関数だけで決まるので一意

ここで、ラベルごとに、2つの微分を掛けてみると…

  • ラベルが \(y=1\) のとき：

\[\frac{\partial \ell}{\partial z} =\underbrace{\left(-\frac{1}{p}\right)}_{\partial\ell/\partial p} \underbrace{p(1-p)}_{dp/dz} =-(1-p)=p-1=p-y \qquad (y=1)\]

  • ラベルが \(y=0\) のとき：

\[\frac{\partial \ell}{\partial z} =\underbrace{\frac{1}{1-p}}_{\partial\ell/\partial p} \underbrace{p(1-p)}_{dp/dz} =p=p-0=p-y \qquad (y=0)\]

どのラベルでも、\(z\) についての勾配は、単に \(p\) と正解ラベル \(y\) の差を計算するだけ \[\dfrac{\partial \ell}{\partial z}=p-y\]

1データ分の勾配のコード

delta = p - y
d_w = delta * x
d_b = delta
コード 数式 意味
delta \(p-y=\dfrac{\partial \ell}{\partial z}\) 1データ分の損失の、\(z\) に対する勾配
d_w[j] \((p-y)x_j=\dfrac{\partial \ell}{\partial w_j}\) 係数 \(w_j\) の勾配
d_b \(p-y=\dfrac{\partial \ell}{\partial b}\) バイアス \(b\) の勾配

\(z=w_1x_1+w_2x_2+b\) なので、\(w_j\) には \(x_j\)、\(b\) には 1 が掛かっていると解釈（後述）

  • log で和にしたので、\(L\) の勾配は1データ分の勾配の平均
    • だから、1データ分の勾配で少しずつ更新しても大丈夫
      • \(L\) で全データまとめて更新してもよいが、練習のため1データずつ進める

全データの Loss は行列で計算可能

  • 各データはそれぞれ独立しているため、X @ w + b の形で全データ分をまとめて計算できる
    • \(z\)：特徴量行列 \(X\) と係数 \(w\) の積 \[\begin{pmatrix} z^{(1)} \\ \vdots \\ z^{(N)} \end{pmatrix} =\begin{pmatrix} x^{(1)}_1 & x^{(1)}_2 \\ \vdots & \vdots \\ x^{(N)}_1 & x^{(N)}_2 \end{pmatrix} \begin{pmatrix} w_1 \\ w_2 \end{pmatrix} + b\]
    • 1行ごとが \(w_1x_1+w_2x_2+b\)
    • \(b\) は全行に同じ値を足すだけでよい
  • Loss：log で積を和にしたので、全データの \(L\) は1データ分の損失 \(\ell\) の平均
def predict(X, w, b):
    """全データの z を計算し、ロジスティック関数で確率 p にする"""
    return sigmoid(X @ w + b)

def binary_cross_entropy(y, p):
    """1データ分の損失 ℓ を、データの数だけまとめて計算する"""
    eps = 1e-10
    # log(0) は計算できないため、確率が厳密な 0 / 1 にならないようにする
    p = np.clip(p, eps, 1 - eps)
    return -(y * np.log(p) + (1 - y) * np.log(1 - p))

これがロジスティック回帰（Logistic Regression）

  • ロジスティック回帰：ここまでの部品をつないだ分類器
    • \(z\)：直線の係数をパラメータにした値
    • \(p\)：ロジスティック関数で変換した確率
    • \(\ell\)：二値交差エントロピーによる採点
    • 学習：勾配 \((p-y)x_j\) で \(w_1, w_2, b\) を更新

\[p = \sigma(w_1 x_1 + w_2 x_2 + b) = \frac{1}{1 + e^{-(w_1 x_1 + w_2 x_2 + b)}}\]

「回帰」なのに分類？

  • 統計では、\(x\) によってラベル \(y\) の平均（Salmon の割合）がどう変わるかを式で表すことを回帰と呼ぶ
    • ロジスティック回帰は、その割合を \(p=\sigma(w_1x_1+w_2x_2+b)\) で表す
  • 分類は、最後に \(p \geq 0.5\) で判定するひと手間

名前の由来：何が「ロジスティック」？

  • ロジスティック関数の出自は機械学習ではなく、19世紀の人口の成長モデル
    • 最初は勢いよく増え、資源の上限に近づくと頭打ちになる成長曲線がS字
  • ロジスティック関数で確率を出す回帰だからロジスティック回帰

（おまけ）「線形」とは

「線形」が付く用語

\[z = w_1 x_1 + w_2 x_2 + b\]

  • 上の式：線形結合（linear combination）
  • ロジスティック回帰：線形分類器（linear classifier）
  • 体長から重さを予測した直線：線形回帰（linear regression）

この「線形」とは何？直線のこと？

線形性（Linearity）：斉次性と加法性を満たすこと

  • 斉次性（homogeneity）：先に定数倍しても後で定数倍しても同じ
  • 加法性（additivity）：先に足しても後で足しても同じ

\[\;\;\text{斉次性：} f(c\,u) = c\,f(u) \qquad \qquad \] \[\;\text{加法性：}f(u + v) = f(u) + f(v) \]

例

  • \(f(x) = 3x\) は線形
  • \(f(x) = x^2\) は \(f(1{+}1) = 4 \neq f(1) + f(1) = 2\) で非線形

よって「線形結合＋バイアス」は厳密には線形ではない

  • \(f(x) = ax + b\) は、\(b\neq0\) なら非線形
    • 足してから入れる：\(f(u+v) = a(u+v) + b\)
    • 入れてから足す：\(f(u)+f(v) = (au+b) + (av+b) = a(u+v) + 2b\) → \(+b\)
  • 例：\(f(x)=3x+1\) なら
    • \(f(1{+}2) = 10\)
    • \(f(1)+f(2) = 4+7 = 11\)

\(b\) の分だけズレるので加法性を満たさない

線形の簡単チェック法：\(f(0) = 0\)

  • 線形なら \(f(0) = f(0 \cdot x) = 0 \cdot f(x) = 0\)
    • 入力 0 に対する出力は必ず 0
  • よって、\(f(0) \neq 0\) の関数は非線形

重要

  • 「グラフが直線」（見た目）と「線形性」（性質）は別物
  • 一次関数を「線形」と呼ぶのは、高校までの見た目基準

ノート

  • \(f(0) = 0\) は線形でないものを見つける検査
    • \(f(0) = 0\) でも \(x^2\) のように非線形なものはある（線形であることの証明にはならない）

\(+b\) を入力の1つと読み替えると線形になる

  • \(b\) を「常に 1 が入っている入力 \(x_0\) の係数 \(w_0\)」と読み替える

\[z = w_0 \underbrace{x_0}_{=\,1} + w_1 x_1 + w_2 x_2\]

  • 入力を \((1, x_1, x_2)\) の3次元と見れば、\(f(0,0,0) = 0\)
    • これは線形結合
  • 統計学では、データ表に「全部 1 の列」を足すのが定番の手法（切片項、intercept）
  • 実装でも広く使われる
  • アフィン変換（affine transformation）：\(+b\) の形（線形＋平行移動）

重要ポイント

  • 世の中の説明の多くは \(+b\) 込みでも「線形」と書く
    • \(x_0 = 1\) を補って読めば、その呼び方でも辻褄が合う

線形だと何かと都合がよい

  • 行列のかけ算 として計算可能
    • さらに何回掛け算しても線形のまま
  • 微分した結果に \(w\) が残らない：\(\dfrac{\partial z}{\partial w_1} = x_1\)、\(\dfrac{\partial z}{\partial b} = 1\)
    • （非線形の例）係数の2乗：\(z = w_1^2 x_1\) なら \(\dfrac{\partial z}{\partial w_1} = 2w_1x_1\) で、\(w_1\) 自身が残る
  • 線形代数の道具が使える：最小二乗（least squares）なら正規方程式（normal equation）で勾配降下法なしに解ける
  • 凸（convex）な損失と組めばローカルミニマム（local minimum）がない（ロジスティック回帰の交差エントロピーもこの例）

どの変数に対する「線形」か

  • ここでの変数はデータ \(x\) とパラメータ \(w\) の2種類
見方 固定 動かす 1次だと嬉しいこと
学習するとき \(x\)（データ） \(w\) 微分で \(w\) が残らない・正規方程式・ローカルミニマムなし
予測するとき \(w\) \(x\) 決定境界が直線・行列のかけ算・重ねても線形

\(z = w_1 x + w_2 x^2\)：曲がった境界を作れて、学習は今までどおり楽

  • \(x\) について曲線なので、境界を直線以外にできる
    • 例：\(b\) も入れて \(z = w_1x + w_2x^2 + b\) とし、\(w_2 < 0\) にすると、\(z > 0\) になるのは \(x\) が中くらいの範囲だけ
    • 「小さすぎず大きすぎないものだけ A」という、直線1本では分けられない分類が可能
  • \(w\) について1次なので、学習の仕方に変化なし
    • \(x^2\) を新しい入力の列としてデータ表に足す
      • \(x_0 = 1\) の列を足すのと同じ
    • 損失はお椀型のままで、ローカルミニマムがない
      • そのままロジスティック回帰で学習できる

\(z = w^2 x\)：表現力は増えないのに、学習だけ難しくなる

  • \(x\) について直線なので、表現力は \(z = wx\) と変わらない
    • むしろ \(w^2 \geq 0\) なので、傾きを負にできない分だけ狭い
  • \(w\) について1次でないので、学習が厄介になる
    • 勾配が \(2wx\) なので、\(w = 0\) から始めると勾配が 0 で、まったく動けない
    • \(w = 1\) と \(w = -1\) が同じモデルになるので、谷が2つできる

ノート

  • 統計の「線形モデル」：\(w\) について線形（多項式回帰も含む）
  • 「線形分類器」：\(x\) について線形

練習問題：線形かどうかを判定する

次の関数が線形性（斉次性・加法性）を満たすか、手計算とPythonコードの両方で判定せよ。

\[\begin{aligned} &\text{(a)}\; f(x) = 5x & \qquad &\text{(b)}\; f(x) = 3x + 2 \\ &\text{(c)}\; f(x) = x^2 & \qquad &\text{(d)}\; f(x_1, x_2) = 2x_1 - x_2 \end{aligned}\]

  1. \(f(0) = 0\) かどうかを確認し、線形でない関数を除外
  2. 残った関数で加法性 \(f(u + v) = f(u) + f(v)\) を確認（成り立たない場合は反例を1つ提示）
  3. 「先に足してから入れる」と「入れてから足す」をコードで比較（1変数の関数は \(u=1, v=2\)、(d) は \(u=(1,2), v=(3,1)\)）

解答例：線形かどうかを判定する

  • f(0) チェック
  • 加法性チェック
    1. \(f(0) = 0\)：通過
    1. \(f(0) = 2 \neq 0\)：線形ではない
    1. \(f(0) = 0\)：通過（線形とはまだ言えない）
    1. \(f(0, 0) = 0\)：通過
    1. \(f(1+2) = 15 = f(1) + f(2) = 5 + 10\)：成立
    • 斉次性も \(f(cx) = 5cx = c f(x)\) で成立するので線形
    1. \(f(1+2) = 9 \neq f(1) + f(2) = 1 + 4 = 5\)：非線形
    • \(f(0)=0\) を満たしても線形とは限らない
    1. \(f(u+v)=2(u_1+v_1)-(u_2+v_2)=f(u)+f(v)\)：成立
    • 斉次性も \(f(cu) = 2cu_1 - cu_2 = c f(u)\) で成立するので線形

結果

  • (b)：\(f(0) \neq 0\) なので線形ではない
  • (c)：加法性が成り立たないので線形ではない
  • (a)(d)：両辺が一致し、手計算と同じ結果

まとめ

  • 直線は、\(f(x) = w_1x_1 + w_2x_2 + b\) が 0 になる点の集合
    • 値の符号：直線のどちら側か
    • 値の大きさ：直線からの遠さ
  • 回帰と分類で、データ点での \(f(x)\) に求めることが逆
    • 回帰：0 に近づける（MSE）
    • 分類：正しい側で 0 から遠ざける
  • 分類の損失：二値交差エントロピー
    • 確率に変換：\(p = \sigma(f(x))\)
    • 採点：正解クラスの確率 \(q\) に \(-\log q\)
  • 学習：交差エントロピーを勾配降下法で最小化
    • 勾配は \((p - y) x\)（ロジスティック関数と交差エントロピーを組み合わせた結果）
  • 学習の中身は「予測 → 差を測る → 境界を少し動かす」の繰り返し
  • ロジスティック回帰：線形結合（＋バイアス）→ ロジスティック関数 → 交差エントロピー
    • 「線形結合 → ロジスティック関数」は、すでに最小構成のニューラルネットワーク
  • 「線形」は直線の見た目ではなく、「定数倍と足し算だけ」という性質
    • \(f(0) \neq 0\) なら線形ではない
  • \(+b\) があると厳密には線形ではない（アフィン）
    • 「常に 1 の入力 \(x_0\)」と読み替えれば線形結合に収まる

演習：ロジスティック回帰を2ステップ学習する

次の2件のデータで、ロジスティック回帰のパラメータを手計算で2回更新せよ。

  • 特徴量（標準化済み）：（輝度, 重さ）
  • 1件目：\(x^{(1)} = (2, 1)\)、Salmon（\(y=1\)）
  • 2件目：\(x^{(2)} = (-1, 1)\)、Sea bass（\(y=0\)）
  • 初期値：\(w = (0, 0)\)、\(b = 0\)
  • 学習率：\(\alpha = 0.5\)
  1. 1件目の \(z\)、\(p = \sigma(z)\)、勾配 \(\dfrac{\partial \ell}{\partial w_1}\)、\(\dfrac{\partial \ell}{\partial w_2}\)、\(\dfrac{\partial \ell}{\partial b}\) を計算
  2. 更新式 \(w_j \leftarrow w_j - \alpha\dfrac{\partial \ell}{\partial w_j}\)、\(b \leftarrow b - \alpha\dfrac{\partial \ell}{\partial b}\) で更新
  3. 続けて2件目でも、勾配を計算して更新

ヒント：\(\sigma(0) = 0.5\)（この問題で使う \(\sigma\) の値はこれだけ）

【参考】\(e^x\) は微分しても \(e^x\)

  • 一般の指数関数（exponential function）\(a^x\) を微分すると

\[\frac{d}{dx}a^x=(\log a)a^x\]

  • \(\log a=1\) になる特別な底が \(e\approx2.718\)

\[\frac{d}{dx}e^x=e^x\]

  • 指数が \(-z\) のときは、合成関数になっている
    • 内側 \(g\) で先に \(-z\) を作り、外側 \(h\) で \(e\) の右肩に乗せる

\[g(z) = -z, \qquad h(u) = e^{u} \qquad\Longrightarrow\qquad h(g(z)) = e^{g(z)} = e^{-z}\]

  • 連鎖律で、内側の微分 \(-1\) が掛かる

\[\frac{d}{dz}e^{-z}=e^{-z}\frac{d(-z)}{dz}=-e^{-z}\]

\(e\) は、指数関数の値と傾きが同じになるように選ばれた数

【参考】多クラスの交差エントロピー（Cross Entropy）

  • 3クラス以上の分類（手書き数字の 0〜9 など）で使う
  • クラス \(c\) ごとに、正解ラベル \(y_c\) と予測確率 \(p_c\) を用意する
    • 正解クラスだけ \(y_c=1\)、それ以外は \(y_c=0\)

\[\ell(\mathbf{y},\mathbf{p})=-\sum_c y_c\log p_c\]

  • \(y_c=0\) の項は消えるので、正解クラスの項 \(-\log q\) だけが残る
  • 2クラスで \(\mathbf{y}=(y,\,1-y)\)、\(\mathbf{p}=(p,\,1-p)\) とおくと、二値交差エントロピーになる

交差エントロピー：正解クラスに出した確率 \(q\) を \(-\log q\) で採点する損失関数（loss function）
