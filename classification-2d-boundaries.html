分割の良さを測る尺度：ジニ不純度

上手く切り分けられているかどうかの基準

ジニ不純度（Gini impurity）

\[\text{Gini} = 1 - (p_{\text{Salmon}}^2 + p_{\text{Sea bass}}^2)\]

  • Gini = 0: 完全に1クラスだけ（純粋）
  • Gini = 0.5: 50:50で混ざってる（不純）

例

  • データ10個：Salmon 10個、Sea bass 0個 → Gini = 1 - (1² + 0²) = 0
  • データ10個：Salmon 5個、Sea bass 5個 → Gini = 1 - (0.5² + 0.5²) = 0.5
  • データ10個：Salmon 8個、Sea bass 2個 → Gini = 1 - (0.8² + 0.2²) = 0.32

手で引いた縦線のジニ不純度

  • 縦線の左右それぞれに Salmon と Sea bass が何匹いるかは、性能評価で数えた TP, FP, FN, TN そのもの
    • 左側（輝度 < 閾値）：Salmon が TP 匹、Sea bass が FP 匹
    • 右側：Salmon が FN 匹、Sea bass が TN 匹
  • 左右それぞれのジニ不純度を匹数で重み付けして平均したもの（加重平均）が、この切り方の不純度
    • 小さいほどよく分かれている
def gini(n_salmon, n_seabass):
    """ジニ不純度。n_salmon, n_seabass はその領域にいる匹数"""
    n = n_salmon + n_seabass
    if n == 0:
        return 0
    p_salmon = n_salmon / n
    p_seabass = n_seabass / n
    return 1 - (p_salmon**2 + p_seabass**2)

print(f"分割前（Salmon 40, Sea bass 40）: Gini={gini(40, 40):.3f}")

# 縦線の左右それぞれに、Salmon と Sea bass が何匹いるか
left_salmon = np.sum(salmon_brightness < lightness_threshold)
left_seabass = np.sum(seabass_brightness < lightness_threshold)
right_salmon = np.sum(salmon_brightness >= lightness_threshold)
right_seabass = np.sum(seabass_brightness >= lightness_threshold)

gini_left = gini(left_salmon, left_seabass)
gini_right = gini(right_salmon, right_seabass)

# 左右のジニ不純度を匹数で重み付けして平均
n_left = left_salmon + left_seabass
n_right = right_salmon + right_seabass
weighted_gini = (n_left * gini_left + n_right * gini_right) / (n_left + n_right)

最適化：ジニ不純度が最小になる閾値を探索

【戦略】総当たりで候補をすべて試す
  • 閾値の候補ごとに、ジニ不純度を計算する
    • 分割すると、2つジニ不純度がでるので加重平均したものをその閾値候補の値とする
    • 閾値間で比較し、最小のものを採用する

\[\text{Gini}_{\text{加重平均}} = \frac{n_{\text{左}}}{n_{\text{左}} + n_{\text{右}}}\,\text{Gini}_{\text{左}} + \frac{n_{\text{右}}}{n_{\text{左}} + n_{\text{右}}}\,\text{Gini}_{\text{右}}\]

\(n_{\text{左}}, n_{\text{右}}\) は閾値で分けた左右それぞれの匹数（多い側の不純度が重く効く）

輝度に対する閾値の最適解を探索するコード

方針：輝度の範囲（2〜10）を 0.5 刻みで並べ、for 文で全部試す

# 輝度をthreshold で左右に分割したジニ不純度の加重平均
def weighted_gini_at(threshold): 
    left_salmon = np.sum(salmon_brightness < threshold)
    left_seabass = np.sum(seabass_brightness < threshold)
    right_salmon = np.sum(salmon_brightness >= threshold)
    right_seabass = np.sum(seabass_brightness >= threshold)
    n_left = left_salmon + left_seabass
    n_right = right_salmon + right_seabass
    return (n_left * gini(left_salmon, left_seabass)
            + n_right * gini(right_salmon, right_seabass)) / (n_left + n_right)

# 候補：2.0 から 10.0 の手前まで 0.5 刻み
candidates = np.arange(2.0, 10.0, 0.5)
print(f"候補の数: {len(candidates)}")

best_threshold = None
best_gini = 1.0
for threshold in candidates:
    g = weighted_gini_at(threshold)
    if g < best_gini:
        best_threshold = threshold
        best_gini = g
print(f"最適な閾値: {best_threshold:.2f}（weighted Gini {best_gini:.3f}）")
候補の数: 16
最適な閾値: 5.00（weighted Gini 0.167）

決定木のアルゴリズム（縦横交互バージョン）

この分割を、輝度と重さに対して適切に適用したのが決定木

  1. まず輝度に対して最適な閾値で分割
  2. できた左右それぞれに対して重さで分割（ここまでで4分割）
  3. これを繰り返して決めた深さで打ち切る
  4. 各領域は、その中の多数派クラスとする

【準備】データをまとめてラベル付きにする（特徴量行列）

  • 2回目は「1回目で左側に残った魚だけ」を対象に、重さの閾値を探す
    • 左側に残ったのは、輝度・重さ・種類がそろった魚の集まり
  • いまの4本の配列のままだと、分けるたびに4本を別々に絞り込むことになる
  • そこで、1匹を [輝度, 重さ] の配列 X と、ラベル y にまとめる
    • 左側の魚だけを、特徴量も種類もいっしょに取り出せる（次のセルで確かめる）
    • 「どの特徴量で切るか」は列番号で選べる（X[:, 0] = 輝度、X[:, 1] = 重さ）

決定木：最適な分割を探索

  • weighted_gini_at を、X の列番号で特徴量を指定できる形に書き直す
  • ついでに最適な閾値も返す
def find_best_split_for_feature(X, y, feature_idx):
    """指定した特徴量で最適な分割点を見つける"""
    best_gini = float("inf")
    best_threshold = None
    best_left_mask = None
    
    # この特徴量のユニークな値を試す
    values = np.unique(X[:, feature_idx])
    
    for threshold in values:
        # 分割
        left_mask = X[:, feature_idx] < threshold
        right_mask = ~left_mask
        
        # 左右が空でないことを確認
        if sum(left_mask) == 0 or sum(right_mask) == 0:
            continue
        
        # 左右のジニ不純度（y が 1 の行 = Salmon、0 の行 = Sea bass）
        gini_left = gini(np.sum(y[left_mask] == 1), np.sum(y[left_mask] == 0))
        gini_right = gini(np.sum(y[right_mask] == 1), np.sum(y[right_mask] == 0))

        # 加重平均
        n_left = sum(left_mask)
        n_right = sum(right_mask)
        weighted_gini = (n_left * gini_left + n_right * gini_right) / len(y)
        
        if weighted_gini < best_gini:
            best_gini = weighted_gini
            best_threshold = threshold
            best_left_mask = left_mask
    
    return best_threshold, best_gini, best_left_mask

# 簡易的な予測関数（1=Salmon, 0=Sea bass）
def predict_alternating(brightness, weight):
    """交互分割の決定木で予測"""
    if brightness < split1_threshold:
        # 左側（暗い方＝Salmon寄り）：重ければ Salmon
        return 1 if weight >= split2_left_threshold else 0
    else:
        # 右側（明るい方＝Sea bass寄り）：重ければ Salmon
        return 1 if weight >= split2_right_threshold else 0

# 全データで予測
y_pred_alternating = np.array([predict_alternating(X[i, 0], X[i, 1]) for i in range(len(X))])

# 混同行列（縦線のときと同じ手数え）
TP = np.sum((y == 1) & (y_pred_alternating == 1))
TN = np.sum((y == 0) & (y_pred_alternating == 0))
FP = np.sum((y == 0) & (y_pred_alternating == 1))
FN = np.sum((y == 1) & (y_pred_alternating == 0))

# 評価指標
accuracy_alt = (TP + TN) / (TP + TN + FP + FN)
precision_alt = TP / (TP + FP) if (TP + FP) > 0 else 0
recall_alt = TP / (TP + FN) if (TP + FN) > 0 else 0

print(f"交互分割決定木の性能 (深さ2):")
print(f"  TP={TP}, FP={FP}, FN={FN}, TN={TN}")
print(f"  Accuracy:  {accuracy_alt:.3f}")
print(f"  Precision: {precision_alt:.3f}")
print(f"  Recall:    {recall_alt:.3f}")

疑問

  • 深さ無制限なら、ついに正答率 100%
  • これが「最強のモデル」といえる？

正答率 100% の歪さ

  • 数匹を救うためだけの細長い回廊（飛び地）ができている
  • 実際に学習されたルールを読むと「輝度が 5.35〜5.70 でも、重さが 2205g を超えるなら Salmon」のような異様に具体的な条件が入っている

Tweak 木の深さを変える

  • 深さの実験のコードを書き換えて実行（続きのセルも実行）
やりたいこと コード
木を浅くせよ for depth in [1, 3, None] → [2, 3, None]
満点が出る深さはどこ？ [1, 3, None] → [3, 4, 5, 6]

結果

  • 深さ3では 97.5%。深さ6で初めて100% に届く
    • 満点までに増えた3段の if が何をしているかは、深さ無制限の境界の図に現れている

まとめ

重要なポイント

  1. 2次元にすることで分類精度が向上
    • 重さ + 輝度の組み合わせで、より正確に分類
  2. 決定境界は手でも、アルゴリズムでも決められる
    • 手動の直線：目で見て引く
    • 決定木：ジニ不純度で自動最適化
  3. 手法によって決定境界が異なる
    • 手動: 縦線（しきい値の2次元版）
    • 決定木: 階段状（軸に平行）
  4. トレードオフを理解する
    • シンプル vs 複雑
    • 解釈しやすさ vs 性能
    • 深さ無制限で満点が出たが、採点したのは学習に使った80匹。本物かは次回

練習問題

本編の80匹のデータ X, y について、以下の1〜4を実行して境界を比較せよ

  1. 散布図を見て自分で輝度の閾値を1つ決め、その縦線での TP, FP, FN, TN を計算せよ（Accuracy も表示）

  2. DecisionTreeClassifier を深さ 1, 2, 3, 4, 5 で学習し、それぞれの Accuracy, Precision, Recall を表示せよ

  3. 2.の結果から、どの深さを選ぶかを理由とともに答えよ

  4. 1.の縦線と 2.の決定木を比較し、1次元（重さだけ）のときと比べて何が改善したかを述べよ

from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import accuracy_score, precision_score, recall_score

# 1. 自分の縦線（例：輝度 5.0）
t = 5.0
y_pred = (X[:, 0] < t).astype(int)    # 1=Salmon, 0=Sea bass
TP = np.sum((y == 1) & (y_pred == 1))
TN = np.sum((y == 0) & (y_pred == 0))
FP = np.sum((y == 0) & (y_pred == 1))
FN = np.sum((y == 1) & (y_pred == 0))
print(f"threshold={t}: TP={TP}, FP={FP}, FN={FN}, TN={TN}, Accuracy={(TP + TN) / len(y):.3f}")

# 2. 深さ 1〜5 の決定木
for depth in [1, 2, 3, 4, 5]:
    model = DecisionTreeClassifier(max_depth=depth, random_state=42).fit(X, y)
    p = model.predict(X)
    print(f"max_depth={depth}: Accuracy={accuracy_score(y, p):.3f}, "
          f"Precision={precision_score(y, p):.3f}, Recall={recall_score(y, p):.3f}")

  • 3.：深くするほど同じデータでの精度は上がる。ただし採点に使ったのが学習データなので、深いほど良いとは言えない
    • どの深さが本当に良いかは、学習に使っていないデータで採点しないと決められない
  • 4.：縦線は輝度だけを使う。決定木は重さも使って階段状に切るので、誤分類が減る
    • 1次元（重さだけ）より精度が上がった

次回

  • 深さ無制限の決定木は、学習に使った同じデータで採点して満点だった
  • 次回は新しい魚で採点し、この満点が本物かを確かめる
    • この現象には名前がある：過学習（overfitting）
  • 散布図で見えた斜めの直線はまだ引けていない
    • 直線を数式で最適化する道具は、線形回帰・ロジスティック回帰の回で扱う
