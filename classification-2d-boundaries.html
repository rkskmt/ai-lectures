決定木

決定木（Decision Tree）

決定木とは
  • 条件分岐を木のような樹形図で表し、データの分類や予測を行う機械学習・データ分析の手法
  • 要するに「多段のif文でいい感じに切り分ける」
    • （参考）枝刈りといえば「オッカムの剃刀」

上手く切り分けられているかどうかの基準

ジニ不純度（Gini impurity）

\[\text{Gini} = 1 - (p_{\text{Salmon}}^2 + p_{\text{Sea bass}}^2)\]

  • Gini = 0: 完全に1クラスだけ（純粋）
  • Gini = 0.5: 50:50で混ざってる（不純）

例

  • データ10個：Salmon 10個、Sea bass 0個 → Gini = 1 - (1² + 0²) = 0
  • データ10個：Salmon 5個、Sea bass 5個 → Gini = 1 - (0.5² + 0.5²) = 0.5
  • データ10個：Salmon 8個、Sea bass 2個 → Gini = 1 - (0.8² + 0.2²) = 0.32

ジニ不純度を計算してみる

def gini_impurity(labels):
    """ジニ不純度を計算"""
    if len(labels) == 0:
        return 0
    p_salmon = sum(labels) / len(labels)  # 1=Salmon, 0=Sea bass
    p_seabass = 1 - p_salmon
    return 1 - (p_salmon**2 + p_seabass**2)

# 全データのジニ不純度
initial_gini = gini_impurity(y)
print(f"初期状態（分割前）のジニ不純度: {initial_gini:.3f}")
print(f"Salmon: {sum(y)}個")
print(f"Sea bass: {len(y)-sum(y)}個")

最良の閾値をどう探す？

最も単純な方法は総当たり
  • 候補の閾値をすべて試して、分割後の左右の加重平均ジニ不純度を比べる — 最小のものを採用する
  • 特徴量は2つあるが、まずは輝度だけでジニ不純度を最小化してみる

閾値の候補は「データの値」だけで十分

データとデータの間なら、どこで切っても分かれ方は同じ。

例：データが [2.1, 3.5, 5.8] のとき（輝度 < 閾値 で左右に分ける）

  • 2.1 と 3.5 の間のどこで切っても、閾値 3.5 と同じ分かれ方
  • 3.5 と 5.8 の間のどこで切っても、閾値 5.8 と同じ分かれ方

→ 試すべき候補は、データの値そのものだけ

いくつかの閾値を試してみる

code 
# 輝度でいくつかの閾値を試す
test_thresholds = [3.0, 4.0, 5.0, 6.0, 7.0]
results = []

for threshold in test_thresholds:
    # 分割
    left_mask = X[:, 0] < threshold # 輝度
    right_mask = ~left_mask
    
    if sum(left_mask) == 0 or sum(right_mask) == 0:
        continue
    
    # 左右のジニ不純度
    gini_left = gini_impurity(y[left_mask])
    gini_right = gini_impurity(y[right_mask])
    
    # 加重平均
    n_left = sum(left_mask)
    n_right = sum(right_mask)
    weighted_gini = (n_left * gini_left + n_right * gini_right) / len(y)
    
    results.append({
        '閾値': f"{threshold:.1f}",
        '左側': f"{sum(y[left_mask])}/{n_left}",
        '右側': f"{sum(y[right_mask])}/{n_right}",
        'Gini_left': f"{gini_left:.3f}",
        'Gini_right': f"{gini_right:.3f}",
        '加重平均': f"{weighted_gini:.3f}"
    })

results_df = pd.DataFrame(results)
print("いくつかの閾値でのジニ不純度:")
print(results_df.to_string(index=False))
print("\n→ 加重平均が最小の閾値を選ぶ")

決定木のアルゴリズム（縦横交互）

自作版は簡単のため、使う特徴量を輝度→重さの交互に固定する（縦・横の分割を重ねて、階段状の境界を作る）。

  1. 全データを対象に、輝度のユニーク値を閾値候補として総当たりし、加重平均ジニ不純度が最小の閾値で左右に分割
  2. できた左右それぞれの領域のデータだけで、こんどは重さの閾値を同じ方法で探して分割
  3. 決めた深さで打ち切り。各領域は、その中の多数派クラスで判定する

code 
def find_best_split_for_feature(X, y, feature_idx):
    """指定した特徴量で最良の分割点を見つける"""
    best_gini = float('inf')
    best_threshold = None
    best_left_mask = None
    
    # この特徴量のユニークな値を試す
    values = np.unique(X[:, feature_idx])
    
    for threshold in values:
        # 分割
        left_mask = X[:, feature_idx] < threshold
        right_mask = ~left_mask
        
        # 左右が空でないことを確認
        if sum(left_mask) == 0 or sum(right_mask) == 0:
            continue
        
        # 左右のジニ不純度
        gini_left = gini_impurity(y[left_mask])
        gini_right = gini_impurity(y[right_mask])
        
        # 加重平均
        n_left = sum(left_mask)
        n_right = sum(right_mask)
        weighted_gini = (n_left * gini_left + n_right * gini_right) / len(y)
        
        if weighted_gini < best_gini:
            best_gini = weighted_gini
            best_threshold = threshold
            best_left_mask = left_mask
    
    return best_threshold, best_gini, best_left_mask

# 1回目の分割: 輝度（feature 0）
feature_names = ["Lightness", "Weight"]
split1_feature = 0  # Lightness
split1_threshold, split1_gini, split1_left_mask = find_best_split_for_feature(X, y, split1_feature)

print(f"1回目の分割:")
print(f"  特徴量: {feature_names[split1_feature]}")
print(f"  閾値: {split1_threshold:.2f}")
print(f"  ジニ不純度: {split1_gini:.3f}")
print(f"  左側: {sum(split1_left_mask)}個, 右側: {sum(~split1_left_mask)}個")

# 簡易的な予測関数
def predict_alternating(brightness, weight):
    """交互分割の決定木で予測"""
    if brightness < split1_threshold:
        # 左側（暗い方＝Salmon寄り）
        if split2_left_threshold is not None:
            if weight >= split2_left_threshold:
                return 1  # Salmon（重い）
            else:
                return 0  # Sea bass（軽い）
        else:
            return 1  # Salmon (分割なし)
    else:
        # 右側（明るい方＝Sea bass寄り）
        if split2_right_threshold is not None:
            if weight >= split2_right_threshold:
                return 1  # Salmon（重い）
            else:
                return 0  # Sea bass（軽い）
        else:
            return 0  # Sea bass (分割なし)

# 全データで予測
y_pred_alternating = np.array([predict_alternating(X[i, 0], X[i, 1]) for i in range(len(X))])

# 混同行列（縦線のときと同じ手数え）
TP = np.sum((y == 1) & (y_pred_alternating == 1))
TN = np.sum((y == 0) & (y_pred_alternating == 0))
FP = np.sum((y == 0) & (y_pred_alternating == 1))
FN = np.sum((y == 1) & (y_pred_alternating == 0))

# 評価指標
accuracy_alt = (TP + TN) / (TP + TN + FP + FN)
precision_alt = TP / (TP + FP) if (TP + FP) > 0 else 0
recall_alt = TP / (TP + FN) if (TP + FN) > 0 else 0

print(f"交互分割決定木の性能 (深さ2):")
print(f"  TP={TP}, FP={FP}, FN={FN}, TN={TN}")
print(f"  Accuracy:  {accuracy_alt:.3f}")
print(f"  Precision: {precision_alt:.3f}")
print(f"  Recall:    {recall_alt:.3f}")

ノート

  • 決定境界が階段状（水平・垂直の線の組み合わせ）
  • if-thenルールの結果がこの形になる

手動 vs 決定木

手動の直線 決定木
境界の決め方 目で見て引く（データを眺める過程が入る） ジニ不純度で自動最適化
説明のしやすさ 単純で、理由を説明しやすい if-then ルールとして読める
特徴量が3つ以上 目で見えなくなる そのまま扱える
弱点 最適の保証がない・自動化できない 過学習（overfitting）しやすい・境界は階段状のみ

for depth in [1, 3, None]:
    model = DecisionTreeClassifier(max_depth=depth, random_state=42)
    model.fit(X, y)
    acc = accuracy_score(y, model.predict(X))
    label = "無制限" if depth is None else f"深さ{depth}　"
    print(f"{label}: Accuracy = {acc:.3f}")

質問

深さ無制限なら、ついに正答率 100%。 これは「最強のモデルが完成した」ということでいい？

深さ無制限の境界を見てみる

  • 無制限の木には、数匹を救うためだけの細長い回廊（飛び地）ができている
  • 実際に学習されたルールを読むと「輝度が 5.35〜5.70 でも、重さが 2205g を超えるなら Salmon」のような異様に具体的な条項が入っている

この満点、信用できるのか

  • 採点に使ったのは、学習に使った80匹
  • 過去問を丸暗記すれば、過去問のテストは満点になる
  • 「まだ見ぬ魚」にも通用するかはわからない
    • おそらくダメ（飛び地は無理がある）

警告

精度は、どのデータで採点したかが重要

まとめ

重要なポイント

  1. 2次元にすることで分類精度が向上
    • 重さ + 輝度の組み合わせで、より正確に分類
  2. まず目で見て、次にアルゴリズム
    • 手動の直線 → 決定木
    • 段階的に理解を深める
  3. 手法によって決定境界が異なる
    • 手動: 縦線（しきい値の2次元版）
    • 決定木: 階段状（軸に平行）
  4. トレードオフを理解する
    • シンプル vs 複雑
    • 解釈しやすさ vs 性能
    • 満点に見えても信用できない場合がある（深さ無制限の決定木）

練習問題

  1. 手動で境界線を決める
    • グラフを見て、自分で境界線を決める
    • その境界線でのTP, FP, FN, TNを計算
  2. 決定木を実装
    • 提供されたデータで学習
  3. 決定木の深さを1, 2, 3, 4, 5で試す
    • それぞれのAccuracy, Precision, Recallを比較
    • どの深さが最適か考察
  4. 考察
    • 手動の境界線 vs 決定木
    • どちらが良かったか？その理由は？
    • 2次元にすることで、1次元と比べてどう改善したか？

次回予告

  • 深さ無制限の決定木は「同じデータで採点」して満点だった
  • 次回、このあやしい満点の正体を、新しい魚で採点することで暴く
  • 正体には名前がある — 過学習（overfitting）
  • そしてもう1つの宿題：観察で見えた斜めの直線は、まだ引けていない。数式で最適な直線を fit する道具は、fit() の中身を開ける流れで自作する
